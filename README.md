# 酷态科 AP01 固件制作与刷机工具 使用说明

刷机有风险，请勿轻易尝试。

## 克隆本项目到本地

直接对AI说：克隆这个仓库到电脑桌面https://github.com/andy-JustSayWhen/cuktech-ap01-firmware-tools

## 如何刷机

直接对AI说：帮我刷机，按照SOP/如何刷机.md

## 如何救砖

直接对AI说：帮我刷机，按照SOP/如何刷机.md，刷入固件artifacts/firmware/original/ap01-1.0.2_0031.bin

## 如何制作固件

直接对AI说：帮我制作固件，按照SOP/如何制作固件.md

本项目目前提供1个第三方固件，名为artifacts/firmware/ap01-1.0.2_0031-opt.bin。

* 固件简介见artifacts/firmware/README.md,这个文档里面，你可以看到该固件相对于原版的官方固件做了哪些优化和改动；
* 技术细节见reference/DESIGN/ap01-1.0.2_0031-opt.bin技术实现
