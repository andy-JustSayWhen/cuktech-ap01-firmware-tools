# ap01-1.0.2_0031-opt 刷机流程


## 1. 收集并写入服务端地址

请用户直接发送 1 至 10 个服务端地址；地址顺序就是设备尝试连接的优先顺序。未特别说明端口时，使用项目默认端口 18765。

从 `env/agents-dashboard.env.example` 创建 `env/agents-dashboard.env`，将真实地址写入 `AP01_AGENTS_HOSTS`，将端口写入 `AP01_AGENTS_PORT`。真实地址只允许存在于 `env/` 与随后生成的个人固件中，不得写入文档或提交到代码仓库。

## 2. 生成新的个人固件

Windows：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\ap01-opt-personalize.ps1
```

macOS：

```bash
tools/ap01-opt-personalize.sh
```

脚本读取第 1 步的地址，生成新的个人固件、构建清单和交互模拟报告。输出目录为 `artifacts/build/personalized/fast-<时间>/`；其中 `ap01-1.0.2_0031-opt-personalized.bin` 是下一步唯一允许刷入的固件。脚本失败，或构建清单、交互模拟报告未通过时停止。

## 3. 刷入设备

确认目标 AP01 在线、账号内恰好一台 AP01 且更新状态为空闲。用第 2 步生成的个人固件启动临时固件服务：

Windows：

```powershell
.venv\Scripts\python.exe tools\ota_https_serve.py --firmware "<第2步个人固件路径>"
```

macOS：

```bash
.venv/bin/python tools/ota_https_serve.py --firmware "<第2步个人固件路径>"
```

保持该终端运行，另开终端下发安装。`<本机局域网地址>` 是运行临时固件服务的当前电脑地址， `<个人固件文件名>` 不含目录。

Windows：

```powershell
New-Item -ItemType Directory -Force artifacts\install-records | Out-Null
$record = "artifacts\install-records\ap01-install-$(Get-Date -Format yyyyMMdd-HHmmss)-opt.json"
.venv\Scripts\python.exe app\ap01_firmware.py firmware-install `
  --firmware "<第2步个人固件路径>" `
  --env-file env\mi-cloud.env `
  --ota-url "https://<本机局域网地址>/miio_fw/<个人固件文件名>" `
  --self-signed-ota | Tee-Object -FilePath $record
```

macOS：

```bash
mkdir -p artifacts/install-records
record="artifacts/install-records/ap01-install-$(date +%Y%m%d-%H%M%S)-opt.json"
.venv/bin/python app/ap01_firmware.py firmware-install \
  --firmware "<第2步个人固件路径>" \
  --env-file env/mi-cloud.env \
  --ota-url "https://<本机局域网地址>/miio_fw/<个人固件文件名>" \
  --self-signed-ota | tee "$record"
```

安装记录必须显示临时服务读回文件与本地个人固件一致、设备接受安装、已观察到安装和重启、最终状态为空闲；否则停止并按 [`刷机失败案例及解决办法`](../knowledge/刷机失败案例及解决办法.md) 处理。完成后停止临时固件服务。

## 4. 部署服务端

在当前服务电脑按 [`如何部署服务端`](如何部署服务端.md) 执行对应系统的一键部署。该文档的健康检查通过，且设备能取得四页看板数据，即本流程完成。若用户一次性粘贴了多个服务端地址，最后告诉用户：如需在其他服务端部署AGENTS看板的后端，请直接对AI说：设备端已刷入ap01-1.0.2_0031-opt.bin固件，现在，帮我在本机部署 AGENTS看板的后端，按照 SOP/如何部署服务端.md
