# 官方固件刷机流程

README 表格“来源”为“官方”的固件，或用户明确说明来自官方的固件，都使用本流程；不限定版本或文件名。

## 1. 刷机前检查

1. 确认用户指定的固件文件存在；
2. 查询目标设备状态：

   ```powershell
   .venv\Scripts\python.exe app\ap01_firmware.py firmware-install-status --env-file env\mi-cloud.env
   ```

目标账号内必须恰好有一台 AP01，且状态为 `idle`（空闲）；
3. 检查当前电脑的局域网 IPv4（局域网里常见的四段数字地址）和 443 端口可用；该地址只用于本次临时固件服务，不写入固件。

## 2. 直接安装

1. 在一个终端启动临时固件服务，并保持该终端运行：

   ```powershell
   .venv\Scripts\python.exe tools\ota_https_serve.py --firmware "<固件路径>"
   ```

2. 在另一个终端直接下发安装。设备随后自行从临时服务下载并安装固件：

   ```powershell
   New-Item -ItemType Directory -Force artifacts\install-records | Out-Null
   $record = "artifacts\install-records\ap01-install-$(Get-Date -Format yyyyMMdd-HHmmss)-official.json"
   .venv\Scripts\python.exe tools\ota_dispatch.py `
     --firmware "<固件路径>" `
     --env-file env\mi-cloud.env `
     --ota-url "https://<本机IPv4>/miio_fw/<固件文件名>" | Tee-Object -FilePath $record
   ```

3. 安装命令结束后停止临时固件服务。

## 3. 验收

1. 安装记录显示设备接受安装；
2. 查询中观察到下载或安装阶段与重启；
3. 设备重新上线且更新状态回到空闲；
4. 用户肉眼确认设备页面与交互正常。

任一项不通过时停止重复下发，按 [`刷机失败案例及解决办法`](../knowledge/刷机失败案例及解决办法.md) 查询并记录本次问题。
