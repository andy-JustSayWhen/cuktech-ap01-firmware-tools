## 官方原版固件获取流程

官方原版固件必须从本项目命令获取：

```bash
python3 app/ap01_firmware.py official-firmware-info
python3 app/ap01_firmware.py official-firmware-download
```

查询和下载流程详见 [`如何查询和下载 AP01 的最新官方固件`](../../SOP/如何查询和下载AP01的最新官方固件.md)。文件名只用于定位材料，不能作为身份判断；必须通过型号、版本、字节数、MD5、SHA-256、文件头和文件尾恢复校验共同确认。

## `第三方固件/AGENTS看板/ap01-1.0.2_0031-opt.bin` 简介

该文件基于 `第三方固件/物理旋钮交互优化/ap01-1.0.2_0031-opt-setting.bin` 制作。它保留全部界面功能，但不包含用户的服务地址。用户必须按 [`如何制作固件`](../../SOP/如何制作固件.md) 填写本机配置并二次制作个人固件，不能直接安装本文件。

### 1. 设置页旋钮支持循环切换

旋钮在系统设置列表的第一项继续向左旋转时，会从第一项跳到最后一项；在最后一项继续向右旋转时，会回到第一项。

### 2. 隐藏了部分一级界面

隐藏日历、天气和萌宠页面

### 3. 新增一个一级界面—— AGENTS 看板
本固件仅推出了Codex的AGENTS看板，Claude等其他Agents暂未规划。

具体包括： 1个一级界面：概览； 3个二级界面：周剩余额度、今日消耗、近30天消耗。

按下旋钮后，左右旋转，在3个二级界面之间循环切换：

- 概览：显示本周剩余额度、今日消耗、近 30 天消耗和近 7 天趋势曲线。
- 周剩余额度：显示剩余比例、下次重置倒计时、重置时间和可用重置次数。
- 今日消耗：显示总消耗、请求数、接口费用、输入、输出、缓存命中和缓存命中率。
- 近 30 天消耗：显示累计消耗、最长任务时长、活动洞察、常用插件和任务总数。


#### 看板数据自动更新

公开固件不发起看板取包。个人固件怎样跨服务端获取数据，只见 [`技术实现第 9.4 节`](../../reference/DESIGN/ap01-1.0.2_0031-opt.bin技术实现/ap01-1.0.2_0031-opt.bin技术实现.md#94-设备端如何跨服务端取数据)。
