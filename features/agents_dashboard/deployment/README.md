# AGENTS 看板常驻模板

运行参数与数据来源只见
[`优化固件 DESIGN` 第 7.4.5 节](../../../reference/DESIGN/AP01-1.0.2_0031-opt.bin.md)。

- `macos/`：登录后常驻任务模板；替换双花括号字段后再加载。
- `windows/`：可放入当前用户启动目录的启动文件；路径通过环境参数传入。
- `linux/`：Linux、NAS 和云服务器的系统服务模板；替换双花括号字段后再启用。

模板不包含登录态、设备信息、固定用户目录或本机网络地址。每台机器必须使用自己的 Codex
登录状态和本地会话目录。云服务器入口在固件完成证书校验复用证据前不得启用。
