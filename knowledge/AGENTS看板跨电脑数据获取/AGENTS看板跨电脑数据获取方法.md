# AGENTS 看板跨电脑数据获取方法

## 1. 这份文档管什么

本文只说明如何让设备按固定顺序在多台服务电脑之间切换。单台电脑启动服务见 [`如何部署服务端`](../../SOP/如何部署服务端.md)，制作个人固件和固定文件见 [`如何制作固件`](../../SOP/如何制作固件.md)。

设备跨服务端取数的技术定义只见 [`ap01-1.0.2_0031-opt.bin 技术实现第 9.4 节`](../../reference/DESIGN/ap01-1.0.2_0031-opt.bin技术实现/ap01-1.0.2_0031-opt.bin技术实现.md#94-设备端如何跨服务端取数)。

## 2. 先准备每台电脑

每台电脑都先按基础操作文档完成以下内容：

1. 准备字体运行副本；
2. 确认这台电脑的数据目录；
3. 启动这台电脑的看板服务；
4. 确认这台电脑能独立返回完整数据。

不得复制另一台电脑的登录文件、会话原文或采集缓存代替本机数据。

## 3. 统一多地址配置

所有服务电脑的 `env/agents-dashboard.env` 使用相同配置：

- `AP01_AGENTS_HOSTS` 按设备访问优先级填写 2～10 个局域网地址；
- 地址之间用英文逗号分隔；
- `AP01_AGENTS_PORT` 在所有电脑上使用同一个端口。

修改地址顺序、增加或删除服务电脑后，必须重新按基础操作文档制作个人固件并运行页面操作模拟。

## 4. 刷前检查至少一个服务

读取配置后执行：

```shell
set -a
source env/agents-dashboard.env
set +a

printf '%s\n' "$AP01_AGENTS_HOSTS" | tr ',' '\n' | while IFS= read -r host; do
  host="$(printf '%s' "$host" | xargs)"
  curl --fail --silent --show-error \
    "http://$host:$AP01_AGENTS_PORT/health"
  printf '\n'
done
```

刷机前仍要逐个尝试配置中的地址并记录结果，但只要求至少一个服务满足：`ok` 是 `true`、 `degraded` 是 `false`、`error` 是 `null`，并且 `quota`、`reset_cards`、`profile`、 `local_sessions` 都是 `true`。这个服务的 `/a` 数据包还必须能通过 [`AGENTS 看板的数据生成与拉取`](../AGENTS看板的数据生成与拉取.md#44-启动服务端并生成设备结果包)中的解码检查。

其余地址暂时无法连接或检查失败时，记录失败结果并保留原有优先级，不阻止刷机。所有地址都没有同时通过健康状态检查和数据包解码时，才停止刷机。

## 5. 检查设备是否真的跨服务端取数

1. 准备验证的服务都在线时，确认设备访问地址表中第一个可以正常返回数据的服务；
2. 从地址表第一项开始依次停止服务，每次等待下一轮，确认设备继续访问下一个地址并取得新画面；
3. 恢复地址表中的第一个服务，再等待下一轮，确认请求重新回到第一个地址；
4. 停止所有服务，确认设备保留本次开机期间最后一次成功画面。

没有完成以上四步，不能写“跨服务端自动切换已经验证”。
