# 1.0.2_0041 页面与旋钮接入分析

## 是什么

本文记录 `ap01-1.0.2_0041.bin` 中供 AGENTS 看板继续使用的原厂页面、萌宠旋钮和跳转填充区事实。它只用于确定可以继续使用的原厂入口和可修改字节，不替代真机验收。

## 为什么

0041 新增了插件屏保类型、夜间屏幕模式、蜂鸣器开关和设备按键快速返回。看板构建只接入原有一级页面切换、萌宠局部旋钮和功率确认保护位置；新增功能所在的原厂分支、数据和资源不在修改范围内。

## 已验证的原厂事实

0041 原厂文件大小为 6,769,704 字节，文件摘要为 `972db4c136c7ed9e24a83c07c1a7fd62040ca018b08ca285216d26b1fee3c6b9`。恢复尾位于文件偏移 `0x674c00`，尾部校验值为 `0x47fb9315`，按原厂算法复算结果相同。

第一张原厂动图数据从文件偏移 `0x1c5a6c` 开始，声明长度位于 `0x1c5a5c`。其前 385,834 字节与 0031 的同一输入逐字节相同，摘要为 `5e656788665f7f0022b0b5500d569a8aae07f4a46b080d033b3cacfa4abc940d`，因此可以继续使用既有无损压缩方法；载荷只能写入压缩后腾出的区域。

原厂萌宠左旋、右旋和确认三个局部入口分别位于运行地址 `0xa00b0108`、`0xa00b03c2` 和 `0xa00b17ea`，其待替换原字节依次为 `9d452685`、`9d452685` 和 `26859d45`。它们的原厂继续地址分别为 `0xa00b010c`、`0xa00b03c6` 和 `0xa00b17ee`。一级页面切换调用位于 `0xa00afd2c`，该处调用原厂切页函数 `0xa00b3106`；构建前必须同时断言调用前寄存器准备指令仍保持原字节。

0041 原厂页面定时回调的运行地址为 `0xa00af262`。页面初始化在文件偏移 `0x5e0f2` 以 `lui a0,0xa00af` 装入高位、在 `0x5e0fc` 以 `addi a0,a0,610` 补齐地址，随后连同原厂页面对象和 1,000 毫秒延迟传给原厂定时注册函数。个人看板只能将这两条地址装入指令改为自己的包装回调；包装回调必须先启动自身定时器，再无条件调用 `0xa00af262`，不能替换或停止原厂页面刷新。

0041 原厂独立定时器初始化和重新调度入口分别为 `0xa009d106` 与 `0xa009d146`。原厂已初始化的天气定时器管理对象位于 `0x62fc9520`：初始化路径先写入新定时器句柄，再把该对象作为第一个参数传给初始化入口。个人看板只读取该对象的原厂循环指针和已有定时器链表，以避免重复创建自身刷新定时器；不得改写原厂天气定时器、网络回调或位置回调。

文件偏移 `0x1c108` 至 `0x1c1ff` 是两个原厂函数之间的 248 字节全零对齐填充区。完整反汇编没有任何跳转目标落入该区间；本次可把其中的八字节块作为短跳转中继。每个中继先由局部入口跳入，再无返回地转至压缩动图后方的看板载荷。构建器必须断言每个选用块仍为全零，并验证所有局部入口到中继的距离都在处理器短跳转可达范围内。

## 可以安全继续使用的范围

可以继续使用原厂萌宠对象、原厂萌宠状态分配、原厂一级页面切换、原厂功率页离线切回入口和原厂恢复尾算法。看板只附加独立状态尾部和看板画面，不覆盖原厂插件设置、新增夜间模式、新增蜂鸣器开关或按键快速返回实现。

## 怎样算完成

每次构建必须断言上述原字节、动图摘要、填充区全零和恢复尾结构；输出与 0041 原厂基线的差异只能位于批准修改区间及恢复校验字节。随后必须通过连续页面事件模拟和构建后的回读校验，才可以冻结只读成品。
