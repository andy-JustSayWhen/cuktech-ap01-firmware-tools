# 2026-07-29 AGENTS 原厂萌宠控件复用静态定位

## 1. 目的

在不新增任何界面对象的前提下，为 AGENTS 看板复用原厂萌宠页既有动图控件。

## 2. 原厂直接证据

1. 原厂萌宠页位于一级窗口序号 7；
2. 运行地址 `0xa00b40c8` 装入原厂动图描述地址 `0xa01f7090`；
3. 运行地址 `0xa00b40d4` 调用动图创建入口 `0xa01930fe`；
4. 返回的动图对象保存到萌宠状态偏移 `0`；
5. 原厂包装数据类型为 10，包装偏移 `4` 指向萌宠状态。

## 3. 参考项目成功证据

参考项目从一级窗口序号 7 取得萌宠根对象，沿根对象偏移 `16`、包装偏移 `4`、状态偏移 `0`
取得同一动图对象，并只调用动图数据源切换入口。该实现没有创建新页面或新图片对象。

## 4. 失败方案排除

- 增加第十个一级对象会破坏原厂确认路径；
- 在萌宠根对象内新增子覆盖层仍会使菜单“返回”触发重启；
- 后续实现不得改变原厂对象树或用户数据关系。
