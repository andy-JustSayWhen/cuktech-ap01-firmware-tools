# 2026-07-29 AGENTS 原厂萌宠控件复用静态定位

返回主文档：[`AP01 官方固件分析`](../AP01-官方固件分析.md)

## 1. 目的

在不新增任何界面对象的前提下，为 AGENTS 看板复用原厂萌宠页既有动图控件。

## 2. 原厂对象与状态直接证据

原厂萌宠页位于一级窗口序号 7。其创建路径的直接证据如下：

| 运行地址 | 文件偏移 | 直接行为 |
| --- | --- | --- |
| `0xa00b402c` | `0x0b502c` | 申请 16 字节萌宠状态 |
| `0xa00b40c8` | `0x0b50c8` | 装入原厂动图描述地址 `0xa01f7090` |
| `0xa00b40d4` | `0x0b50d4` | 调用动图创建入口 `0xa01930fe` |
| `0xa00b40d8` | `0x0b50d8` | 把动图对象写入萌宠状态偏移 `0` |
| `0xa00b40dc` | `0x0b50dc` | 把萌宠状态偏移 `12` 的 32 位值清零 |
| `0xa00b411a` | `0x0b511a` | 把另一原厂对象写入状态偏移 `4` |
| `0xa00b415a` | `0x0b515a` | 把另一原厂对象写入状态偏移 `8` |
| `0xa00b4172` | `0x0b5172` | 把包装类型写为 10 |
| `0xa00b4178` | `0x0b5178` | 把萌宠状态指针写入包装偏移 `4` |
| `0xa00b4180` | `0x0b5180` | 把包装写入萌宠根对象偏移 `16` |

删除回调 `0xa00b75f8` 沿根对象偏移 `16` 和包装偏移 `4` 取得该状态，清空状态偏移
`0`、`4`、`8` 后释放状态。该回调没有给偏移 `12` 建立可供第三方复用的语义。

## 3. 参考项目成功证据

参考项目从一级窗口序号 7 取得萌宠根对象，沿根对象偏移 `16`、包装偏移 `4`、状态偏移 `0`
取得同一动图对象，并只调用动图数据源切换入口。该实现没有创建新页面或新图片对象，也没有
读取或写入萌宠状态偏移 `12`。

参考项目已在真机证明 `/tmp` 临时文件中的画面槽、元数据和应用确认记录可由后台下载路径与
界面定时回调共同使用。该成功证据只支持复用既有动图对象和独立临时记录，不支持占用原厂
萌宠状态字段。

## 4. 状态字段能力边界

`0xa00b40dc` 只能证明偏移 `12` 在创建时被整体清零。当前没有该字段的完整读写引用、位级
含义或高位空闲证明，因此不得把其高 3 位或任何其他位用于 AGENTS 状态。

AGENTS 只可读取包装类型、萌宠状态指针和状态偏移 `0` 的动图对象指针；不得写入状态偏移
`0`、`4`、`8`、`12`，不得改变根对象偏移 `16` 的包装关系。界面活动状态与四页索引必须
保存在经过校验的独立临时记录中，具体格式只见 DESIGN 第 6.1 节。

## 5. 复查方法

1. 对原厂文件与 `opt-setting.bin` 分别反汇编 `0xa00b402c` 至 `0xa00b4194`；
2. 核对状态申请大小、四个字段写入、包装类型和两级指针关系；
3. 反汇编删除回调 `0xa00b75f8`，区分事件对象偏移与萌宠状态偏移；
4. 两份输入在文件偏移 `0x0b4f00` 至 `0x0b5300` 必须逐字节一致。
