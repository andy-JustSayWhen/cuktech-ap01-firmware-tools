# 2026-08-01 原厂天气任务首次取数前置条件静态定位

## 1. 证据范围

本记录只适用于已校验的官方 `1.0.2_0031` 固件。它解释原厂天气后台任务从首次
定时调度到实际网络调用之前的直接条件，不定义 AGENTS 页面或物理旋钮逻辑。

## 2. 首次调度调用链

| 位置 | 直接行为 |
| --- | --- |
| `0xa00b13fe` | 先取消 `0x62fca9a8` 上的原有任务，再以 `2000` 毫秒调用首次调度入口 |
| `0xa01aa812` | 把回调 `0xa00b6ca6` 与传入延时写入原厂定时任务 |
| `0xa00b6ca6` | 原厂天气取数任务；成功或失败后继续通过 `0xa009b3b6` 预约自身 |

`0xa00b13fe` 被定位到多个原厂网络或位置状态更新分支，因此参考项目仅替换网络
执行点并不等于已绕过首次取数的位置前置条件。

## 3. 位置前置条件

`0xa00b6dd4` 调用 `0xa00acbea` 把位置编号写入任务栈缓冲区。该入口成功时返回
`1`，原厂立即继续组装请求；失败时返回 `0`，转入 `0xa00b7022` 的城市后备分支。

后备分支必须同时满足：

1. `0x62fca650 + 196` 的运行毫秒数大于 `100000`；
2. `0x62fca650 + 68` 或 `0x62fca650 + 132` 至少一个首字节非零。

第 2 项通过后，原厂分别从 `0x62fca694` 和 `0x62fca6d4` 复制两个最长 `64`
字节的文本字段，再进入城市天气请求分支。不满足时跳到 `0xa00b71ac`，本轮
不创建网络请求，而是按原厂失败间隔再次预约自身。

## 4. 当前设备证据

2026-08-01 实时读取中，当前设备的 `0.1.5` 属性返回错误，`0.3.5` 至 `0.3.7`
返回空文本。这些运行证据与上述静态分支和参考项目原版探针未发起请求的结果
一致。属性的业务名称尚未从官方属性规格取得，因此本记录不为它们擅自命名。

## 5. 复用边界

AGENTS 局域网取包不需要天气位置，但如果继续复用原厂天气任务，就必须在进入
原厂请求组装前提供一个有终止字节的九位数字文本，并返回原厂成功值 `1`。
只允许替换 `0xa00b6dd4` 的位置取得调用；定时任务、网络上下文、执行入口、失败
重试和运行状态不重写。占位文本因请求格式固定为 `%s` 而不会进入局域网请求。
