# 2026-08-01 基座离线功率页残留与确认路径静态定位

返回主文档：[`AP01 官方固件分析`](../AP01-官方固件分析.md)

## 1. 输入身份与问题

本次只读复查小米云当前官方 `njcuk.enstor.ap01` `1.0.2_0031` 固件：

| 项目 | 值 |
| --- | --- |
| 长度 | `6,804,520` 字节 |
| SHA-256 | `8a721fc8ef25458d415b2460e4a251e0503a82f7743fdff85b12612190e5c1cb` |
| MD5 | `469a7329d496f81ae8625c4d76ccf56d` |
| 运行地址换算 | 文件偏移加 `0x9ffff000` |

要回答的问题是：未吸附到基座时功率页为什么偶尔仍可见，以及此时按下旋钮是否可能进入
失效数据路径。

## 2. 功率页对象与基座状态不是同一生命周期

显示初始化无条件在 `0xa00b2602` 创建序号 `0` 的功率页对象。是否把功率页作为当前页或
一级导航目标，则另外读取设备端口数：

1. `0xa00b16a4` 把设备端口数写到 `0x62fc4cd8`；固件字符串把该入口标识为
   `lv_set_dev_port_num`；
2. 显示初始化 `0xa00b27be..0xa00b27e0` 在端口数非零时以功率页为初始页，端口数为零时
   以时钟页为初始页；
3. 一级导航也按同一个端口数决定是否允许到达功率页。

因此，“对象已经创建”不等于“当前允许显示”。屏幕刚离开基座后仍短暂保留功率页，不能据此
推断基座仍然在线。

## 3. 离线识别存在明确的延迟窗口

触点通信路径 `0xa00ab684..0xa00ab6be` 在一次读取失败后只增加失败计数。计数大于 `5` 时才：

1. 记录 `ID Pin is Offline`；
2. 调用 `0xa00aa798` 释放功率汇总数据；
3. 把位于 `0x62fcaa00` 的功率汇总数据指针清零；
4. 进入后续离线通知。

界面离线回调 `0xa00b9248..0xa00b92a6` 随后调用 `0xa00b16a4` 把设备端口数写为零。如果
一级窗口当时的交互分派序号恰好为 `0`，回调复用原厂 `0xa0193862` 切到时钟页；原厂设置
状态不允许时改切设置页。

这条链路解释了未吸附时偶尔仍看到功率页：从物理断开到第六次失败成立、数据释放、离线回调
完成之间存在窗口。它不是页面被随机创建，也不是导航规则随机变化。

## 4. 原厂功率确认存在失效指针窗口

功率确认从 `0xa00bc8c6` 进入。原厂路径先取得功率页对象和页面状态；需要创建功率详情时，
在 `0xa00bc9b0` 从 `0x62fcaa00` 读取功率汇总数据指针到 `s8`，随后在 `0xa00bc9cc`
直接读取 `0(s8)`，中间没有判空。

同一固件另有 `0xa00b1646` 安全读取入口：它先检查 `0x62fcaa00`，为空时记录
`Get UiFace TotalInfo is NULL` 并返回零。功率确认分支没有复用这项判空。

因此可以确认：功率页仍残留、离线路径已经把功率汇总数据释放并清零时，按下旋钮会进入空
指针读取风险。该静态事实与“界面卡住或重启”相容，但没有当时的基座状态、异常地址或复位
原因，不能把历史每一次卡住都归因于这一条路径。

## 5. 当前能力边界

已确认：

- 基座在线状态决定功率页的初始选择和一级导航资格，不决定功率页对象是否创建；
- 离线判定至少经过六次失败，页面可能在窗口内短暂残留；
- 离线处理会释放并清零功率汇总数据；
- 原厂功率确认创建详情时没有检查该指针是否为空。

尚未确认：

- 六次失败对应的固定墙钟时长；
- 历史 `FW-AGENTS-006`、`FW-AGENTS-007` 功率确认故障发生时是否吸附基座；既有案例没有
  记录这一现场条件；
- 指针非空但后台恰好并发释放时的线程互斥边界；当前固件没有提供足以证明该竞态安全性的
  直接证据。

下一版只能把确认事件到达时的端口数和功率汇总数据有效性检查作为局部保护；保护通过后必须
回到 `0xa00bc8ca` 继续原厂功率确认，保护失败时必须复用原厂离线切页入口并从一级回调公共
出口返回。该保护不能被写成整板仿真已经证明，也不能替代带电基座上的功率详情真机验收。

## 6. 复查入口

使用固定工具链的反汇编程序，按 32 位 RISC-V 指令读取以下区间：

```text
0xa00ab660..0xa00ab700  触点离线计数、数据释放与通知
0xa00b1640..0xa00b1700  功率汇总数据安全读取与端口数写入
0xa00b9200..0xa00b92d0  界面离线回调与离开功率页
0xa00bc870..0xa00bca20  一级确认分支与功率详情数据读取
```

官方固件安装、来源和完整文件身份只见
[`2026-08-01 原厂固件功率页对照安装`](2026-08-01-原厂固件功率页对照安装.md)。
