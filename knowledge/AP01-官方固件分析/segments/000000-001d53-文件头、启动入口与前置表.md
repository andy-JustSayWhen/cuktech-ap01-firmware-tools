# `0x000000..0x001d53` 文件头、启动入口与前置表

## 1. 覆盖结论

本段从文件第一个字节开始，到 `0x001d53` 结束，共 `7,508` 字节。区间连续且无空洞：

| 文件偏移 | 分类 | 逐字节结论 |
| --- | --- | --- |
| `0x000000..0x0000ff` | 芯片启动文件头 | 按官方结构逐字段解析，见第 2 节 |
| `0x000100..0x000fff` | 填充 | `3,840` 字节全部为 `0x00` |
| `0x001000..0x001051` | 启动入口 | 共 `82` 字节、`21` 条指令，见第 3 节 |
| `0x001052..0x0013ff` | 填充 | `942` 字节全部为 `0x00` |
| `0x001400..0x001578` | 射频参数 | 16 字节标记加 30 条记录，见第 4 节 |
| `0x001579..0x001bff` | 填充 | `1,671` 字节全部为 `0x00` |
| `0x001c00..0x001d53` | 版本标记和入口表 | 16 字节标记、1 个入口地址、80 个相同表项，见第 5 节 |

## 2. `0x000000..0x0000ff` 启动文件头

结构字段取自 Bouffalo SDK（博流智能官方芯片开发包）提交 `f7b74e7` 的
`bsp/board/bl616dk/fw_header.h` 和
`examples/boot2_isp/port/bl616/bflb_port_boot2.h`。官方结构与本段字节偏移逐项一致。

## 3. `0x001000..0x001051` 启动入口逐指令解释

运行地址为 `0xa0000000..0xa0000051`。21 条指令按执行顺序如下：

| 运行地址 | 指令原文 | 作用 |
| --- | --- | --- |
| `0xa0000000` | `auipc sp,0xc2fdc` | 以当前地址为基准生成栈地址高位 |
| `0xa0000004` | `addi sp,sp,-1904` | 把栈指针确定为 `0x62fdb890` |
| `0xa0000008` | `csrw mscratch,sp` | 把同一栈地址写入机器态暂存寄存器 |
| `0xa000000c` | `auipc gp,0xc2fc3` | 以当前地址为基准生成全局数据地址高位 |
| `0xa0000010` | `addi gp,gp,1204` | 把全局指针确定为 `0x62fc34c0` |
| `0xa0000014` | `csrw mstatus,zero` | 清零机器态状态寄存器 |
| `0xa0000018` | `csrr t0,0x7c5` | 读取芯片专用控制寄存器 `0x7c5`；精确名称尚未取得直接证据 |
| `0xa000001c` | `lui t1,0x100` | 生成位值 `0x00100000` |
| `0xa0000020` | `or t0,t0,t1` | 在原控制值中置位 `0x00100000` |
| `0xa0000024` | `csrw 0x7c5,t0` | 把置位后的值写回芯片专用控制寄存器 |
| `0xa0000028` | `auipc t0,0xc2fc2` | 生成异常入口地址高位 |
| `0xa000002c` | `addi t0,t0,1240` | 得到异常入口基址 `0x62fc2500` |
| `0xa0000030` | `auipc t1,0xc2fc1` | 生成另一入口表地址高位 |
| `0xa0000034` | `addi t1,t1,208` | 得到入口表地址 `0x62fc1100` |
| `0xa0000038` | `ori t0,t0,3` | 给异常入口基址加入模式值 `3` |
| `0xa000003c` | `csrw mtvec,t0` | 把 `0x62fc2503` 写入机器态异常入口寄存器 |
| `0xa0000040` | `csrw 0x307,t1` | 把 `0x62fc1100` 写入芯片扩展入口寄存器；精确名称尚未取得直接证据 |
| `0xa0000044` | `auipc t0,0x2a` | 生成下一阶段初始化函数地址高位 |
| `0xa0000048` | `addi t0,t0,-1574` | 得到调用目标 `0xa0029a1e` |
| `0xa000004c` | `jalr t0` | 调用 `0xa0029a1e`，并把返回地址写入 `ra` |
| `0xa0000050` | `ret` | 下一阶段初始化函数返回后，返回入口调用者 |

本段能直接证明入口建立栈、全局指针和异常入口后调用 `0xa0029a1e`。目标函数尚未顺序通读
完成，不在本段提前概括其完整作用。

## 5. `0x001c00..0x001d53` 版本标记与入口表

| 偏移 | 字节 | 结论 |
| --- | --- | --- |
| `0x1c00..0x1c0f` | `BLFBVERFBLFBVERF` | 两个相同的 8 字节版本标记 |
| `0x1c10..0x1c13` | `b2 ae 01 a0` | 32 位地址 `0xa001aeb2`；其调用身份需在后续控制流中确认 |
| `0x1c14..0x1d53` | 80 次 `00 25 fc 62` | 80 个表项全部为地址 `0x62fc2500`，与启动入口写入异常入口基址的值一致 |

`0x1d54` 紧接新的非零字节并可解码为函数序言，因此它属于下一连续代码段，不计入本段完成
范围。
