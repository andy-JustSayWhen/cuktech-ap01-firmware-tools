# `0x001eb4..0x001ef7` 闪存环绕读取设置

返回总账：[`原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 68 字节、1 个完整函数、28 条指令，没有数据或填充。函数与 Bouffalo SDK
（博流智能官方芯片开发包）中的 `flash_set_l1c_wrap`（设置一级缓存和闪存环绕读取的内部函数）
一致，但本固件所用版本比当前公开源码多执行一步一级缓存环绕状态设置。

官方芯片只读函数表证明三个间接调用目标：

| 函数表地址 | 目标 |
| --- | --- |
| `0x90015c94` | 设置一级缓存环绕读取状态 |
| `0x90015e24` | 关闭闪存环绕突发读取 |
| `0x90015e48` | 开启闪存环绕突发读取 |

## 3. 能力边界

该函数只根据闪存配置低五位是否等于 4，同步设置一级缓存与闪存芯片的环绕读取状态。它不
判断闪存型号、不读写用户数据，也不进入 AP01 业务程序。
