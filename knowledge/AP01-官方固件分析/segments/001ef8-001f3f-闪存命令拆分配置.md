# `0x001ef8..0x001f3f` 闪存命令拆分配置

返回总账：[`原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 72 字节、1 个完整函数、25 条指令，没有数据或填充。函数与 Bouffalo SDK
（博流智能官方芯片开发包）的 `bflb_flash_set_cmds`（设置闪存控制器命令拆分参数的内部函数）
完全一致。

函数在栈上构造 5 字节配置：默认值依次为 `1, 1, 1, 1, 9`；闪存连线模式低五位等于 4
时，后两项改为 `2, 2`。最后把配置地址和闪存组号 0 传给 `0x90015d70`，官方芯片只读函数表
把该表项定义为“设置闪存控制器命令拆分参数”。

## 3. 能力边界

该函数只写闪存控制器的命令拆分配置，不发送业务数据，也不改变原厂文件头或用户设置。
