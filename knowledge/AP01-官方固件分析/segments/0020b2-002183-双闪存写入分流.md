# `0x0020b2..0x002183` 双闪存写入分流

返回总账：[`原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 210 字节、1 个完整函数、72 条指令，没有数据或填充。函数与 Bouffalo SDK
（博流智能官方芯片开发包）的 `bflb_flash_write`（按绝对地址写入闪存）完全一致，并编入了
双闪存控制器路径。

| 全局位置 | 本函数用途 |
| --- | --- |
| `gp-80` | 第一颗闪存容量 |
| `gp-76` | 第二颗闪存容量 |
| `gp-28` | 第二颗闪存配置结构 |

写入末地址超过两颗闪存总容量时返回 `-12`。完全位于第一颗闪存时走带锁写入；完全位于第二
颗闪存时切换第二总线后写入；跨越两颗闪存边界时先写第一段，成功后再写第二段。

## 3. 能力边界

本函数只负责地址校验、两颗闪存之间的写入分流和结果传递。第一颗闪存的带锁写入函数位于
后续地址 `0xa0001ab6`，必须顺序读到该位置后才算掌握其内部写入时序。
