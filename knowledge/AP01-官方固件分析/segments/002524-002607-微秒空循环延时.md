# `0x002524..0x002607` 微秒空循环延时

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 228 字节、1 个完整函数、77 条指令，没有数据或填充。

函数是 `arch_delay_us`（按微秒做处理器空循环延时），输入 `a0` 是微秒数，没有返回值。
实际路径为：

1. 读取 `0x7c1` 缓存控制寄存器，根据指令缓存和数据缓存状态，将每轮折算耗时设为
   3、4 或 24 个处理器时钟；
2. 调用 `a0002730`，以类型 1 读取主处理器时钟；查询结果为 0 时使用 32,000,000 赫兹；
3. 用时钟频率、微秒数和每轮耗时计算空循环次数；
4. 计算结果非零时，执行由比较、加一和回跳组成的空循环。

## 2. 原厂源码对应

官方仓库 `V2.0.0` 的 `drivers/soc/bl616/std/src/bl616_common.c` 中，`arch_delay_us`
和其调用的 `ASM_Delay_Us`（按处理器时钟换算循环次数）与这 77 条指令逐项一致。
`drivers/lhal/src/flash/bflb_sflash.c` 也直接证明后续闪存擦除路径以 `500` 为参数调用该函数。

## 4. 能力边界

这是根据当前时钟和缓存状态估算的忙等延时，不是由硬件计时器截止的精确延时。整数除法会向下取整，
换算出的循环次数为 0 时会立即返回。输入微秒数和中间乘法都只有 32 位，本函数没有溢出检查。
