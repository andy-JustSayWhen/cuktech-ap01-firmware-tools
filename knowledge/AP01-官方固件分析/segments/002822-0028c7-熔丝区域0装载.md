# `0x002822..0x0028c7` 熔丝区域 0 装载

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 166 字节、2 个完整函数、56 条指令，没有数据或填充：

| 运行地址 | 函数 | 作用 |
| --- | --- | --- |
| `0xa0001822..0xa000185d` | `bflb_ef_ctrl_switch_ahb_clk_r0`（把熔丝区域 0 切到系统总线时钟） | 最多等待控制器空闲 160,000 次，写入控制值 `0x0024bf00`，再等待 4 微秒 |
| `0xa000185e..0xa00018c7` | `bflb_ef_ctrl_load_efuse_r0`（装载熔丝区域 0） | 调用前一函数，清零 512 字节暂存区，触发读取，最多轮询 160,000 次后恢复系统总线时钟 |

两个函数都不根据超时结果返回错误码。

## 2. 原厂源码和寄存器对应

官方仓库 `V2.0.0` 的 `drivers/lhal/src/bflb_ef_ctrl.c` 直接对应这两个函数：

- 熔丝控制器基地址为 `0x20056000`，区域 0 暂存区大小为 512 字节；
- 控制寄存器地址为 `0x20056800`，位 2 表示忙，位 1 表示自动装载完成；
- `0x0024bf00` 是系统总线时钟和清中断状态，`0x0024bf10` 在此基础上增加触发位；
- 默认轮询上限 `160 * 1000` 与指令常量 `0x27100` 相同。

## 4. 能力边界

两个函数都在轮询到上限后继续向下执行，没有返回布尔状态或错误码。因此“函数返回”不能单独证明
熔丝数据已成功装载；上层若需确认，必须检查装载完成位或校验读出数据。
