# `0x0028c8..0x002a07` 按名称读取熔丝校准值

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 320 字节、1 个完整函数、109 条指令，没有数据或填充。

函数行为与 `bflb_ef_ctrl_read_common_trim`（按名称读取通用熔丝校准值）一致，
但这份二进制只接收两个实际参数：`a0` 是名称字符串，`a1` 是 8 字节输出结构指针。
设备参数未使用，装载路径无条件执行。

描述表从 `0xa0551190` 开始，到 `0xa0551328` 结束，共 408 字节、34 项，每项 12 字节：

| 记录偏移 | 字段 |
| --- | --- |
| `+0` | 名称指针 |
| `+4` | 使能位地址 |
| `+6` | 奇偶位地址 |
| `+8` | 数值起始位地址 |
| `+10` | 数值位数 |

输出结构依次是 1 字节使能、1 字节奇偶、1 字节空值标记、1 字节长度和 4 字节数值。

## 2. 原厂源码对应

官方仓库 `V2.0.0` 的 `drivers/lhal/include/bflb_ef_ctrl.h` 给出两个结构的精确字段顺序，
`drivers/lhal/src/bflb_ef_ctrl.c` 给出名称比较、使能/奇偶位读取、单字和跨字提取、空值判定的完整原文。

这份二进制的跨字路径通过两个外部 64 位移位辅助函数实现：先生成 `(1 << 长度) - 1`
的 64 位遮罩，再将相邻两个 32 位字拼成 64 位值后右移。

## 4. 能力边界

名称比较使用输入名称的长度，因此输入是表内名称前缀时也会命中；空字符串会直接命中第一项。
单字路径使用 32 位数值 1 生成长度遮罩，数值长度等于 32 时不能仅凭数学式假定结果正确。
函数只返回结构，不计算并验证数值与奇偶位是否一致。
