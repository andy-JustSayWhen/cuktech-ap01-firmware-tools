# `0x002c06..0x002c47` 单字熔丝重新装载读取

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 66 字节、26 条指令，是一个固定读取 1 个 32 位字并强制重新装载熔丝区域 0
的专用入口：

- `a0` 是熔丝暂存区内的字节偏移；
- `a1` 是 32 位输出地址；
- 只接受 `0..508`，保证从该偏移读取的 4 字节不超过 512 字节区域；
- 合法时关闭可屏蔽中断，重新装载熔丝区域 0，读取一个 32 位字，再恢复中断状态；
- 越界时不读取、不写输出地址，直接返回。

## 2. 原厂源码证据

官方仓库 `V2.0.0` 的 `drivers/lhal/src/bflb_ef_ctrl.c` 中，
`bflb_ef_ctrl_read_direct` 给出了相同的总长度检查、重新装载、暂存区读取和中断保护顺序。
本机二进制把设备、读取数量 1 和重新装载开关 1 固化，并把单字复制收缩成一次读和一次写。

`0xa0001c26` 调用的 `0xa000185e` 已在前文确认为熔丝区域 0 重新装载函数；
`0x20056000` 是该芯片熔丝区域 0 暂存区基址。

## 4. 能力边界

本段没有检查输出地址是否为空，也没有返回成功或失败状态；调用者只能通过保证参数有效来
使用它。偏移按字节计算，指令本身也没有要求 4 字节对齐，因此是否允许非对齐读取取决于
芯片这条成对地址读取指令的硬件行为，不能由本段扩大解释。
