# `0x002c48..0x002d7b` 串行外设轮询发送

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 308 字节、100 条指令，包含两个串行外设发送函数：

| 文件偏移 | 内容 | 指令数 |
| --- | --- | ---: |
| `0x002c48..0x002d4b` | 按 1、2 或 4 字节帧批量填充发送队列，同时读取并丢弃接收队列以推进全双工传输 | 83 |
| `0x002d4c..0x002d7b` | 写入单帧，等待对应字节数进入接收队列，再读出并丢弃该帧 | 17 |

两函数的 `a0` 都是串行外设寄存器基址。批量函数的 `a1` 是发送缓冲区，允许为空；
`a2` 是字节数。单帧函数的 `a1` 是待发数据。

## 2. 原厂源码和寄存器证据

官方仓库 `V2.0.0` 的 `drivers/lhal/src/bflb_spi.c` 中，`bflb_spi_poll_exchange` 和
`bflb_spi_poll_send` 与本段控制流逐项对应。二进制把接收缓冲区固定为空，因此接收值只用于
腾空队列；同时把设备结构收缩为已经取出的寄存器基址。

`drivers/lhal/include/hardware/spi_reg.h` 证明本段所有偏移：

| 基址偏移 | 寄存器用途 |
| --- | --- |
| `0x00` | 帧宽配置，位 2 至位 3 编码 1、2、3、4 字节帧，其中 3 按 4 处理 |
| `0x80` | 发送和接收队列控制，置位 `0x0c` 清空两侧队列 |
| `0x84` | 位 0 至位 5 是发送队列可写字节数，位 8 至位 13 是接收队列已有字节数 |
| `0x88` | 发送数据入口 |
| `0x8c` | 接收数据出口 |

## 4. 能力边界

1. 批量函数按整数除法把字节数换算成帧数，不处理不足一帧的尾部字节。
2. 发送缓冲区为空时仍会完成指定帧数的时钟传输，发送内容固定为全 1。
3. 两函数都以无限轮询等待接收队列，没有超时或错误返回路径。
4. 接收数据一律丢弃；本段只能证明发送侧用途，不能作为双向数据交换入口复用。
