# `0x002d7c..0x002dbf` 快速内存复制

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 68 字节、24 条指令，对应官方 `arch_memcpy_fast`：

- `a0` 是目标地址，函数返回时仍是该地址；
- `a1` 是源地址；
- `a2` 是复制字节数；
- 源或目标任一地址未按 4 字节对齐时，调用前文已经通读的逐字节复制函数；
- 两地址都对齐时，先按 32 位字复制，再逐字节复制不足 4 字节的尾部。

## 2. 原厂源码证据

官方仓库 `V2.0.0` 的 `drivers/lhal/src/bflb_common.c` 中 `arch_memcpy_fast` 的对齐判断、
整字数量、尾部数量和回退路径与本段完全一致。`0xa0001d90` 调用的 `0xa0001184` 已在
[`002184-0021e1 字节复制与 CRC32`](002184-0021e1-字节复制与CRC32.md) 中逐条确认为
`arch_memcpy`。

## 3. 24 条指令逐条解释

| 运行地址 | 指令原文 | 作用 |
| --- | --- | --- |
| `0xa0001d7c` | `or a5,a0,a1` | 合并源地址和目标地址的低位对齐信息 |
| `0xa0001d80` | `andi a5,a5,3` | 检查任一地址低 2 位是否非零 |
| `0xa0001d82` | `srli a4,a2,0x2` | 计算可以复制的 32 位字数量 |
| `0xa0001d86` | `beqz a5,a0001da6` | 两地址都按 4 字节对齐时进入整字复制循环 |
| `0xa0001d88` | `addi sp,sp,-16` | 为未对齐回退路径分配栈空间 |
| `0xa0001d8a` | `sw s0,8(sp)` | 保存旧帧指针 |
| `0xa0001d8c` | `sw ra,12(sp)` | 保存返回地址 |
| `0xa0001d8e` | `addi s0,sp,16` | 建立当前帧指针 |
| `0xa0001d90` | `jal a0001184` | 未对齐时调用逐字节复制函数 |
| `0xa0001d94` | `lw ra,12(sp)` | 恢复返回地址 |
| `0xa0001d96` | `lw s0,8(sp)` | 恢复旧帧指针 |
| `0xa0001d98` | `addi sp,sp,16` | 释放栈空间 |
| `0xa0001d9a` | `ret` | 返回逐字节复制结果 |
| `0xa0001d9c` | `th.lrw a3,a1,a5,2` | 从源地址加 `索引×4` 处读取一个 32 位字 |
| `0xa0001da0` | `th.srw a3,a0,a5,2` | 将该 32 位字写到目标地址加 `索引×4` 处 |
| `0xa0001da4` | `addi a5,a5,1` | 整字索引增加 1 |
| `0xa0001da6` | `bne a4,a5,a0001d9c` | 尚未复制完全部整字时继续循环 |
| `0xa0001daa` | `andi a5,a2,-4` | 计算整字复制已经覆盖的字节数 |
| `0xa0001dae` | `bne a5,a2,a0001db4` | 仍有尾部字节时进入逐字节尾部循环 |
| `0xa0001db2` | `ret` | 没有尾部字节时直接返回目标地址 |
| `0xa0001db4` | `th.lrbu a4,a1,a5,0` | 从源地址加尾部索引处读取一个字节 |
| `0xa0001db8` | `th.srb a4,a0,a5,0` | 将该字节写到目标地址加尾部索引处 |
| `0xa0001dbc` | `addi a5,a5,1` | 尾部索引增加 1 |
| `0xa0001dbe` | `j a0001dae` | 继续检查并复制剩余尾部字节 |

## 4. 能力边界

本函数只复制，不处理源与目标内存重叠；重叠时的行为不能按安全搬移函数理解。它也不检查
空地址和可访问范围，参数有效性由调用者保证。
