# `0x003014..0x0030c1` 机器异常现场入口

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 174 字节、77 条指令，是机器异常与中断进入汇编入口：

1. 在当前栈上建立 132 字节寄存器现场；
2. 保存除固定全局指针外的全部通用寄存器，并另存原栈指针、异常返回地址和机器状态；
3. 把异常原因和现场地址传给前文已通读的异常与中断分发函数；
4. 调用前切换到固定异常栈顶 `0xa001aba4`；
5. 使用分发函数返回的现场地址恢复异常返回地址、机器状态和全部寄存器；
6. 恢复该现场记录的栈指针并执行机器异常返回。

分发函数可以返回另一份寄存器现场，因此这段入口同时承载中断中的任务切换恢复。

## 2. 原厂源码和调用链证据

本段寄存器现场布局与原厂固件中的 NuttX 异常分发实现成对：`0xa0002070` 调用的
`0xa0000fa8` 已在 [`001fa8-00207d 异常与中断分发`](001fa8-00207d-异常与中断分发.md)
中逐条确认。分发函数接收异常原因和现场地址，并返回最终应恢复的现场地址。

博流智能官方开发包的启动汇编也采用“保存通用寄存器、读取 `mepc`、`mstatus`、`mcause`、
调用上层分发、恢复现场、执行 `mret`”的同一约定；但本段的 132 字节布局和固定异常栈地址
以产品二进制为唯一依据。

## 4. 能力边界

本入口本身不判定具体异常原因，也不直接调用设备回调；全部策略都交给 `0xa0000fa8`。它不
保存全局指针寄存器，因为产品运行时把该寄存器作为固定全局基址。固定异常栈的实际可用范围
和防溢出机制不在本段内，不能从栈顶地址单独推断。
