# `0x00364e..0x003691` 晶振频率查询

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 68 字节、23 条指令，对应官方源码中的
`Clock_Xtal_Output`（取得晶振输出频率）函数：

- 先通过芯片只读函数表取得晶振类型；
- 查询成功且类型为 0～6 时，以类型为下标从频率表取值；
- 表中七项依次是 0、24000000、32000000、38400000、40000000、26000000、32000000
  赫兹，与官方类型顺序完全一致；
- 查询成功但类型大于 6 时返回查询函数留下的成功值 0；
- 查询失败时按官方既定回退值返回 40000000 赫兹。

## 2. 直接数据证据

索引表位于运行地址 `0xa01b8798`，对应文件偏移 `0x001b9798..0x001b97b3`。逐个读取七个
32 位小端值后，得到下表：

| 晶振类型值 | 表内频率 |
| --- | ---: |
| 0 | 0 |
| 1 | 24000000 |
| 2 | 32000000 |
| 3 | 38400000 |
| 4 | 40000000 |
| 5 | 26000000 |
| 6 | 32000000 |

这些表内字节仍位于总账后续未连续通读区；本段只把它作为本函数间接读取目标的直接证据，等
顺序端点到达该处时还要再次纳入连续覆盖。

## 4. 能力边界

该函数不测量晶振，也不核验晶振是否真的在振荡；它只把系统保存的晶振类型转换成固定频率。
查询失败并不返回错误码，而是直接假定为 40 兆赫，因此调用者无法仅凭返回值区分“实际为
40 兆赫”和“类型查询失败”两种情况。
