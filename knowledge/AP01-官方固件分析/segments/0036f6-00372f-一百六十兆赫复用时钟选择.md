# `0x0036f6..0x00372f` 一百六十兆赫复用时钟选择

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖结论

本段连续覆盖 58 字节、24 条指令，对应官方源码中的
`Clock_160M_Clk_Mux_Output`（取得一百六十兆赫复用时钟频率）函数：

| 输入选择值 | 实际返回路径 |
| --- | --- |
| 0 | 固定返回 160000000 赫兹 |
| 1 | 查询音频锁相环三分频 |
| 2 | 查询音频锁相环二分频 |
| 3 | 查询音频锁相环五分之二 |
| 其他 | 返回 0 |

## 2. 原厂源码对应关系

官方仓库 `V2.0.0` 的 `drivers/soc/bl616/std/src/bl616_clock.c` 中同名函数，与四个选择值和
三种音频锁相环分频参数逐项一致。源码中的选择 0 写成无线锁相环 160 兆赫查询；本机编译
结果把该查询折叠成常量 `160000000`，没有留下额外函数调用。

## 4. 能力边界

函数名表示这组来源用于名义 160 兆赫时钟，但三个音频锁相环路径返回的是当前配置及其分频
结果，并不强制等于 160000000。选择 0 的固定值也只是软件计算结果，不证明对应硬件已经锁定。
