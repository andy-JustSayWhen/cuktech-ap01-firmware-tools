# `0x0041c8..0x00429f` 串口 1 静态对象

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

字段定义原文：[`0x0040f0..0x0041c7` 串口 0 控制台静态对象](0040f0-0041c7-串口0控制台静态对象.md)

## 1. 覆盖结论

本段连续覆盖 216 字节，由串口 1 的 28 字节芯片私有配置和 188 字节通用串口设备组成。
它注册为 `/dev/ttyS1`，不是系统控制台；初始通信参数为每秒 115200 位、8 位数据、1 位停止、
无奇偶校验。接收直接存储器搬运已启用，发送直接存储器搬运未启用；发送循环缓冲为 1024
字节，接收循环缓冲为 1025 字节。

| 项目 | 值 |
| --- | --- |
| 文件范围 | `0x0041c8..0x00429f` |
| 复制后的运行内存范围 | `0x62fc36b4..0x62fc378b` |
| 芯片私有配置 | `0x0041c8..0x0041e3`，28 字节 |
| 通用串口设备 | `0x0041e4..0x00429f`，188 字节 |
| 未解释字节 | 0 |

两个结构中每个字段的定义只保存在上方字段定义原文；本文只沉淀串口 1 的实际值、差异和
独有证据，避免产生第二份结构定义。

## 5. 启动与设备注册

- `0xa002a32e..0xa002a332` 把 `gp`（保存全局数据起点的寄存器）加 500，即运行地址
  `0x62fc36b4`，交给同一个芯片串口配置函数；
- `0xa00295b8..0xa00295c8` 把路径 `/dev/ttyS1` 和通用设备地址 `gp+528`，即
  `0x62fc36d0`，交给通用串口注册函数；
- 没有任何调用把本设备注册为 `/dev/console`，静态控制台标志也为 0。

因此串口 1 与串口 0 共用驱动逻辑和操作表，但拥有独立的芯片配置、等待状态、缓冲描述、
搬运状态和事件等待槽。

## 6. 能力边界

本段证实串口 1 的接收搬运配置和缓冲描述，不等于目标接收缓冲已经包含有效数据；静态搬运
状态仍全零，运行时首次接收才会填充。`0x22fc0c08` 指向的内容、操作表函数正文和后续串口
对象仍按各自在镜像中的文件顺序另行通读。
