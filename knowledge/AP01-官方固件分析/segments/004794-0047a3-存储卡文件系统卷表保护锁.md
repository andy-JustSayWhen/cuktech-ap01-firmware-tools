# `0x004794..0x0047a3` 存储卡文件系统卷表保护锁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

互斥量字段定义原文：
[`0x0040a4..0x0040b3` 文件区间锁保护互斥量](0040a4-0040b3-文件区间锁保护互斥量.md)

## 1. 覆盖结论

本段连续覆盖 16 字节，是 `FatFs`（把存储块组织成兼容 `FAT`，即常见存储卡文件格式，
文件和目录的嵌入式文件系统库）适配层中十槽卷映射表的保护互斥量。原厂二进制没有保留
该静态对象的符号名；本文只按已证实职责定名，不补造源码符号。

| 项目 | 值 |
| --- | --- |
| 文件范围 | `0x004794..0x0047a3` |
| 复制后的运行内存范围 | `0x62fc3c80..0x62fc3c8f` |
| 原始值 | `01 00 05 00 00 00 00 00 00 00 00 00 ff ff ff ff` |
| 初始状态 | 可取得、等待队列为空、无持有者 |
| 已证实用途 | 保护十槽文件系统卷到块设备的映射表安装与移除 |
| 原厂符号名 | 未保留 |
| 未解释字节 | 0 |

## 2. 卷表安装与移除调用闭合

固件在 `0x62fc8be0` 保存十条各 8 字节的运行期卷记录；每条记录的第一字保存块设备文件
节点地址，第二字保存底层块大小换算值。本段互斥量只保护记录的占用和移除：

- `0xa004f10e..0xa004f172` 创建一个文件系统挂载对象后，取得 `gp+1984`，即本段
  互斥量；在十条记录中寻找第一条空槽，把块设备节点和初始换算值 1 写入该槽，把槽号
  保存到挂载对象 `+600` 字节处，然后释放互斥量；
- 十槽全部占用或取得互斥量失败时，函数释放刚申请的 624 字节挂载对象并返回错误，不会
  越过第十槽继续写；
- `0xa0049384..0xa00493c8` 在卸载或失败清理时用保存的槽号再次取得本互斥量，取回该槽
  的块设备节点地址，把第一字清零，再释放互斥量并返回取回的节点地址；
- `0xa00491ac..0xa0049202`、`0xa0049524..0xa0049540` 等底层读写与控制入口先检查槽号
  不大于 9，再从同一卷记录取得块设备节点和换算值，转发到节点操作表。

镜像只读区同时保留编译源码路径 `fatfs/fatfs_vfs.c`，以及挂载选项 `autoformat` 和
`forceformat`。结合十槽号、`数字:` 卷名前缀、块设备读写转发和挂载对象清理路径，可以
排除把本锁误认成普通文件节点树锁或单个挂载实例内部锁。

## 3. 能力边界

本锁保护十槽卷表的安装和移除，不是每个文件读写操作的全局锁。各挂载对象在 `+604`
字节处另有实例内互斥量，用于保护该卷内部文件操作；卷表本体位于运行期零初始化区，
不在本段 16 字节内。
