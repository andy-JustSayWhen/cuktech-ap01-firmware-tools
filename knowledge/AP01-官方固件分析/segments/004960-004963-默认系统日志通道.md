# `0x004960..0x004963` 默认系统日志通道

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

默认系统日志批量写入和其保护互斥量的唯一说明见
[`0x0045c8..0x00462b` 随机数、日志与网络全局保护对象](0045c8-00462b-随机数日志与网络全局保护对象.md#4-默认系统日志输出保护)。

## 1. 覆盖结论

本段连续覆盖 4 字节，是默认系统日志通道对象；对象只含一个六入口操作表地址。

| 项目 | 值 |
| --- | --- |
| 文件范围 | `0x004960..0x004963` |
| 复制后的运行内存范围 | `0x62fc3e4c..0x62fc3e4f` |
| 原始值 | `0xa01bd2b0` |
| 未解释字节 | 0 |

## 2. 六入口操作表

原厂采用版本
[`syslog_channel.c`](https://github.com/apache/nuttx/blob/271f76590f22/drivers/syslog/syslog_channel.c)
中的 `g_default_channel`（默认系统日志通道）只保存 `g_default_channel_ops`（默认通道操作
表）地址。固件 `0xa01bd2b0` 的六项与该源码逐项一致：

| 表内偏移 | 原始值 | 已证实职责 |
| ---: | --- | --- |
| `+0x00` | `0xa002c8f6` | 普通单字节输出 |
| `+0x04` | `0xa002c8f6` | 中断场景强制单字节输出，复用同一入口 |
| `+0x08` | 空 | 不提供刷新入口 |
| `+0x0c` | `0xa002f086` | 受互斥量保护的批量输出 |
| `+0x10` | 空 | 不提供中断场景批量强制输出 |
| `+0x14` | 空 | 不提供通道关闭入口 |

`0xa002c8f6..0xa002c920` 在换行前先输出回车，再输出原字节；
`0xa002f086..0xa002f0be` 的完整保护和批量输出路径只引用本文开头的唯一说明。操作表地址、
六项顺序和两个实际入口共同确认本段身份，不是仅按单个地址猜测。

## 3. 边界

本段在 `0x004963` 结束。`0x004964` 起的 16 字节具有完整互斥量初值，是下一独立对象，
不并入这个只有一个地址字段的日志通道。
