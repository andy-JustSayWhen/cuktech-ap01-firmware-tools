## 1. 覆盖结论

本段连续覆盖 156 字节，共 39 个小端序 32 位字。它们组成八份以空指针结尾的
WAPI（无线应用程序接口，给命令调用无线网卡设置的统一入口）枚举名称表。每个非空字都
指向原厂只读字符串；每份表最后一个字都为零，供调用方判断遍历结束。

| 项目 | 值 |
| --- | --- |
| 文件范围 | `0x004c84..0x004d1f` |
| 复制后的运行内存范围 | `0x62fc4170..0x62fc420b` |
| 32 位字数 | 39 |
| 连续覆盖字节 | 156 |
| 对象数 | 8 |

`0x004d20` 复制到运行地址 `0x62fc420c`，首字为代码地址 `0xa002fc1a`，不属于任何一份
字符串指针表。因此本段严格在 `0x004d1f` 结束。

## 3. 原厂镜像中的直接使用证据

`0xa005a620..0xa005a842` 是一组无线配置帮助信息输出循环。它依次把以下八个运行地址
装入同一个索引寄存器，逐项读取 32 位指针；非零时按 `[%d] %s` 输出编号和名称，读到
零指针后切换到下一份表：

| 指令地址 | 表起点 | 输出标题原文 |
| --- | --- | --- |
| `0xa005a63a` | `0x62fc41a0` | `Frequency Flags` |
| `0xa005a664` | `0x62fc4190` | `ESSID Flags` |
| `0xa005a68e` | `0x62fc4170` | `Passphrase algorithm Flags` |
| `0xa005a6b8` | `0x62fc41f8` | `Passphrase WPA version` |
| `0xa005a6e2` | `0x62fc41ac` | `Operating Modes` |
| `0xa005a70c` | `0x62fc4184` | `Bitrate Flags` |
| `0xa005a736` | `0x62fc41e8` | `TX power Flags` |
| `0xa005a760` | `0x62fc41d0` | `pta prio Flags` |

这条直接遍历关系同时证明了八个表的起点、四字节步长和零值结束规则。后方各项设置函数
对这些表还有单独引用；这里只用其地址反查确认对象身份，不把尚未顺序通读的后方代码计入
完成范围。

源码中的声明顺序与链接后镜像中的物理排列不同；本文以镜像文件偏移为唯一覆盖顺序，源码

## 5. 能力边界

本段证明这些值是供无线配置命令显示和解释枚举值的名称表，不是可调用函数表，也不直接
执行无线设置。表指向的只读字符串位于镜像后方，本文保存其目标地址和实际文本，但不会把
后方字符串存储区提前计为已覆盖。
