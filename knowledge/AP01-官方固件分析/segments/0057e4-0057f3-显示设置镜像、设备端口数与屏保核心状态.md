# `0x0057e4..0x0057f3` 显示设置镜像、设备端口数与屏保核心状态

## 1. 覆盖范围

- 原厂镜像：`ap01-1.0.2_0031.bin`
- 文件偏移：`0x0057e4..0x0057f3`
- 复制后运行地址：`0x62fc4cd0..0x62fc4cdf`
- 长度：16 字节
- 本段原始字节散列：`d205d8dfa3f94c70bb6e5df675aceaf2669504e15d0ff183c3ba5c5026975630`
- 运行地址换算：文件偏移加 `0x62fbf4ec`

本段是从 `0x62fc4cd0` 开始的显示与屏保全局状态块前 16 字节。后续字段
仍连续到至少 `0x62fc4d10`，本段只对已按顺序通读的前 16 字节下结论。

## 3. 屏保与息屏设置镜像

原厂保留了 `lv_screen_saver_close_init` 函数名和
`lv_screen_saver_close_init: ScreenSave = %d, ScreenOff = %d` 日志。该函数在
`0xa00b16e0..0xa00b1750` 完成两项镜像同步：

1. 读取系统设置中的 `ScreenSave` 和 `ScreenOff`；
2. 某项值为 3 时保留当前镜像；
3. 否则分别写入 `0x62fc4cd1` 和 `0x62fc4cd3`。

界面事件路径 `0xa00b862a..0xa00b8682` 也只在对应类型的新值不为 3 时更新
这两个字节。`0xa00f40c8..0xa00f4188` 从实际设置对象取值后，在值变化时写回镜像并
调用原厂的屏幕状态更新入口。

## 4. 设备端口数

`0xa00b16a4..0xa00b16de` 是原厂保留名称的 `lv_set_dev_port_num`，它先把入参
以 32 位值写入 `0x62fc4cd8`，再打印 `set dev port num = %d`。后续读取路径包括：

- `0xa00b27be..0xa00b27e0`：显示初始化时，非零选功率页，零选时钟页；
- `0xa00b94f4..0xa00b9512`：界面通知处理前要求该值非零；
- `0xa00b9566..0xa00b959e`：功率页数据更新时作为有效端口数使用；
- `0xa00be24e..0xa00be2a8`：切换界面前保存该值，并在需要时复用原厂页面切换入口；
- `0xa00f39e6..0xa00f3a0a`：界面事件只在该值非零时继续功率页分支。

所以这个值不是单纯的“在线布尔量”：零与非零确实被当作离线与可用边界，
但非零值同时直接参与端口数据遍历。

## 5. 屏保核心四字节

原厂 `j_update_screen_saver` 日志把相关字节按以下顺序输出：

```text
scr_flag, init_flag, scr_saver, scr_saver_flag, tim_cnt, encoder_flag, ota_flag, adc_asst_flag
```

日志参数按原厂日志调用的寄存器与栈顺序逐项对齐后，本段四字节分别是：

- `0x62fc4cdc` 是 `init_flag`；`lv_win_ui_theme_chg_home_page` 在返回主页时置 1，
  屏保与息屏计时路径都要求它非零；
- `0x62fc4cdd` 是 `scr_flag`；屏保删除回调 `j_win_ui_scr_saver_dtl_del_event_cb`
  在完成对象回收后将其置 1，关闭屏保的清理路径将其清零，屏保创建路径
  将其置 2；
- `0x62fc4cde` 是 `encoder_flag`；多类界面回调在收到交互事件时置 1，
  `j_update_screen_saver` 和 `j_update_screen_close` 读到非零后立即清零计时器，
  再把该字节清零；
- `0x62fc4cdf` 是 `ota_flag`；屏保与息屏计时分支都要求它非零，
  多个屏保进入、离开与界面切换路径会更新它。

`j_update_screen_saver` 的指令还证明：旋钮活动会先清零计时；没有新的旋钮
活动后，只有初始化标志、屏保运行状态、在线更新门禁和后续的辅助检测门禁
都满足时，才会累加计时并按设置进入屏保。

## 6. 能力边界

- 已闭合：全部 16 个源字节，两项显示设置镜像，设备端口数的写入、页面初选、
  数据遍历与界面门禁，以及屏保四个核心字节的读写路径。
- 保留未定：`0x62fc4cd0`、`0x62fc4cd2` 和 `0x62fc4cd4..0x62fc4cd7` 没有找到可以
  命名的直接读写证据；不把它们自动算作结构填充。
- 本段不授权改写设备端口数、屏保计时条件或设置镜像规则。
