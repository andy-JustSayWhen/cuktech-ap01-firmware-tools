# `0x005828..0x00582b` 辅助检测接口状态快照

## 1. 覆盖范围

- 原厂镜像：`ap01-1.0.2_0031.bin`
- 文件偏移：`0x005828..0x00582b`
- 复制后运行地址：`0x62fc4d14..0x62fc4d17`
- 长度：4 字节
- 本段原始字节散列：`185bc5277b1e7eef79d80d495613cc664b41c3863d273e8929ec83bd5dabe7c0`
- 运行地址换算：文件偏移加 `0x62fbf4ec`

本段是一份三字节的辅助检测接口状态快照，加一字节对齐填充。原厂日志
保留了正在进行、结束和开始三类操作文字；本文按其参数顺序和实际消息
拷贝记录，不自行展开原厂日志中缩写的硬件含义。

## 3. 接口索引与状态的发送路径

`0xa01aa8f4..0xa01aa9e6` 的原厂路径接收两个单字节参数。它根据当前辅助
检测是否运行，输出三类原厂日志：

- `ADC Ast Ongoing index = %d, status=%d`；
- `ADC Ast IS End index = %d, status=%d`；
- `ADC Ast Starting index = %d, status=%d`。

日志中第一个数值来自第一参数，第二个数值来自第二参数。紧接着的
`0xa01aa9aa..0xa01aa9ca` 把它们依次写入两字节消息载荷，投递内部消息
614，并立即把第一参数写到 `0x62fc4d14`。

该路径还会将接口索引与原厂当前接口数比较。索引超出范围时只输出日志
并返回，这与镜像中用 `0xff` 表示无有效索引的初值相互印证。

## 4. 三字节快照的接收与比较

原厂内部消息处理路径在 `0xa00b5bfa..0xa00b5c2c` 以长度 3 对消息数据和
`0x62fc4d14` 开始的快照执行比较：

1. 三字节完全一致时，不重复执行后续操作；
2. 任一字节改变时，把消息中的三字节整体复制到 `0x62fc4d14..0x62fc4d16`；
3. 复制后重新读取首字节，继续执行接口边界判定和原厂辅助检测控制入口。

这证明 `0x62fc4d16` 虽然在已读的发送路径中没有单独命名，但它属于三字节
快照的相等性和整体覆盖范围，不能当作填充删除。

- 保留未定：`0x62fc4d16` 的原厂字段名与数值 3 的枚举语义；原厂日志
