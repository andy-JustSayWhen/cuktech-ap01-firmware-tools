## 3. 构造和复用路径

七日天气界面构造循环在每轮建立日期、温度和天气内容后，
于 `0xa00c43f6` 和 `0xa00c4410` 两次把同一地址 `0x62fc4da8` 传给
`0xa00b1f78`，两次都明确传入点数 2。两次调用的：

- 属性 72 都取 2；
- 颜色都取 `0x333333`；
- 定位参数分别为 `5, 0, 0` 和 `2, 0, 0`。

循环计数在 `0xa00c441a..0xa00c4420` 与 7 比较后重复，所以这张两点表
被七轮日期列内容共用，每轮构造两个持有同一表地址的线对象。
