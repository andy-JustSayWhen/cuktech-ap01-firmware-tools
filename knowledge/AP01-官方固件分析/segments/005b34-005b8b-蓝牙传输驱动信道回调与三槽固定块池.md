## 2. `0x62fc5020..0x62fc5037` 蓝牙控制器传输驱动

| 表内偏移 | 原值 | 指令证据确认的含义 |
| --- | --- | --- |
| `+0` | `0xa0520aa4` | 驱动名称指针；目标仍在未通读区，不提前解码名称 |
| `+4` | `3` | 传输总线编号；原厂同源枚举中编号 3 为串口 |
| `+8` | `0` | 控制器特性位图初值 |
| `+12` | `0xa0101890` | 打开函数 |
| `+16` | `0xa0101872` | 关闭函数 |
| `+20` | `0xa0101714` | 发送函数 |

注册函数 `0xa0100f62` 直接取表首 `0x62fc5020`，并执行三道门禁：

1. 主状态对象 `+344` 已有驱动时返回 `-114`；
2. 打开或发送函数为空时返回 `-22`；
3. 两项都有效时，才把本表首写入主状态对象 `+344`并返回 0。

三个实际函数的直接行为：

- `0xa0101890` 打开底层传输对象、创建后台处理任务并登记其处理入口；
  任一后续步骤失败都关闭已打开的传输对象，返回原错误值。
- `0xa0101872` 关闭同一底层传输对象，然后返回 0。
- `0xa0101714` 读取待发缓冲的类型字节：类型 0、2、4 分别写入传输标识
  1、2、5，其他类型返回 `-22`；随后先写标识，再循环写完全部载荷，
  无论成功或失败都释放待发缓冲。

原厂同源头文件中的六字段顺序与本表一致；本文只借其核对字段顺序和
总线编号，函数边界与行为仍以本镜像指令为准。

## 3. `0x62fc5038..0x62fc505b` 逻辑链路信道回调表

这份 36 字节表含 9 个四字节槽。构造函数 `0xa0103de2` 从前一段第二固定块池
取得 228 字节块后，在 `0xa0103eb6..0xa0103eba` 把本表首写入该块 `+8`，
因此表身份与实际使用者均有直接指令证据。

| 槽 | 原值 | 直接角色与行为 |
| --- | --- | --- |
| 0 | `0xa0105592` | 连接建立：更新信道状态，在指定条件下把收发长度设为 23，初始化后续处理工作 |
| 1 | `0xa010609c` | 断开连接：解链信道与连接对象，清理排队项，并通过前段两个池的归还路径释放成对对象 |
| 2 | `0` | 加密状态变化回调未配置 |
| 3 | `0` | 接收缓冲自定义分配回调未配置 |
| 4 | `0xa0104ee0` | 接收：拒绝长度为 0 的载荷；取首字节在 26 项处理表中查找，验证最小长度后调用对应处理函数，本入口最终返回 0 |
| 5 | `0xa0104730` | 发送完成：调用已登记的完成函数，清除正在发送位，并继续处理排队发送项 |
| 6 | `0xa01048aa` | 信道状态变化：状态位 0 置位且当前没有活动发送时，尝试取下一排队项发送 |
| 7 | `0xa0103a6e` | 释放：把外部信道地址减 4，归还到 `0x62fc5004` 的 228 字节固定块池 |
| 8 | `0` | 编译时扩展槽未配置；无直接证据的原厂宏名保留未定 |

这两槽按实际地址与函数行为记录，不用现行头文件强行改名。

## 4. `0x62fc505c..0x62fc5077` 三槽固定块池

| 字段偏移 | 原值 | 直接含义 |
| --- | --- | --- |
| `+0` | `0x62fc505c` | 等待链表前向指针自指 |
| `+4` | `0x62fc505c` | 等待链表后向指针自指 |
| `+8` | `3` | 固定块数量 |
| `+12` | `16` | 每块字节数 |
| `+16` | `0x62fd0ac4` | 48 字节后备存储起始地址 |
| `+20` | `0` | 启动初始化前的空闲链头 |
| `+24` | `0` | 已取用数量初值 |

- 启动函数 `0xa0100f98` 先验证块长和后备地址的四字节对齐，再按 3 个块、
  每块 16 字节把 `0x62fd0ac4..0x62fd0af3` 穿成空闲链。
- `0xa0191942` 在关中断保护下从 `+20` 取块并使 `+24` 加一，成功后清零全部
  16 字节；无块且超时参数为 0 时返回空指针，否则把等待项接入池的等待链并等待归还。
- `0xa0104b92` 是直接释放路径：如块 `+8` 持有缓冲，先减少该缓冲引用并清空指针；
  然后调用通用归还函数 `0xa0103a2a`，把块放回本池并将 `+24` 减一。

本段只能确认该池保存三个可持有缓冲的 16 字节工作记录；记录的原厂业务类型名
在当前连续证据中没有可核对符号，保留未定。
