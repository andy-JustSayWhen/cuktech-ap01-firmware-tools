## 2. `0x62fc52e8..0x62fc5317` 芯片定时器十二入口操作表

本区是 12 个连续函数地址。后方两个芯片定时器设备对象都把本表作为首字段，上层
`/dev/timer0` 底层驱动再从芯片定时器对象首字段取表，并按固定槽位间接调用。
原厂各入口的断言源文件统一为 `chip/bl616_tim.c`。

| 表内偏移 | 原始入口 | 当前镜像直接行为 |
| ---: | --- | --- |
| `+0x00` | `0xa013215c` | 按设备配置设置计数模式、三路比较、预装载和各控制寄存器 |
| `+0x04` | `0xa01322d4` | 清除本通道的计数使能位 |
| `+0x08` | `0xa0132316` | 写入计数模式字节，供初始化入口决定对应模式位 |
| `+0x0c` | `0xa013233e` | 保存并写入本通道预装载值；非对应模式时不改写 |
| `+0x10` | `0xa013237a` | 保存并写入 0 号比较值 |
| `+0x14` | `0xa01323b0` | 读取 0 号比较值 |
| `+0x18` | `0xa01323e6` | 读取本通道当前计数值 |
| `+0x1c` | `0xa0132418` | 启用设备对象 `+13` 保存的中断号 |
| `+0x20` | `0xa013244c` | 停用同一中断号 |
| `+0x24` | `0xa0132480` | 读取本通道 0 号比较匹配状态 |
| `+0x28` | `0xa01324b4` | 清除本通道 0 号比较匹配状态 |
| `+0x2c` | `0xa0134412` | 登记或撤销中断处理函数，并成对启用或停用中断 |

上层定时器启动函数 `0xa012c040` 的实际调用顺序是：先清除通道使能、写计数模式 0、
清除 0 号匹配状态；存在上层回调时登记中断处理函数；随后启用中断，最后执行芯片定时器
初始化。停止函数 `0xa012c0ce` 先停用中断并撤销处理函数，再清除通道使能。

上层状态读取还分别调用 `+0x18` 和 `+0x14` 取得当前计数值与 0 号比较值；设置时长
调用 `+0x10` 写 0 号比较值。因此 12 个地址的顺序和职责不是按函数形状猜测，而是由
真实间接调用槽位闭合。

官方公开仓库固定版本的
[`bflb_timer.h`](https://github.com/bouffalolab/bouffalo_sdk/blob/f7b74e748db707a9ad2fbd1ee97d8a84d0fb7c77/drivers/lhal/include/bflb_timer.h)
列出相同的初始化、停止、预装载、比较、计数和比较中断能力。公开文件仅作芯片能力旁证；
当前镜像多出的中断处理函数登记槽和精确排列仍以二进制调用证据为准。

## 3. `0x62fc5318..0x62fc531b` 蓝牙接收分类参数选择标志

初始四字节为 `01 00 00 00`。只有首字节被访问，后三字节是零填充。

- 蓝牙底层初始化路径 `0xa01389f6..0xa0138dc4` 读取寄存器 `0x20056000`，取第 18 位、
  取反后再保留最低一位，写入 `0x62fc5318`；因此开机初值 1 会被硬件状态覆盖。
- 蓝牙接收分流 `0xa0186808..0xa0186966` 在特定报文分支读取该字节：值为 0 时选择
  分类参数 1，非零时选择参数 2，再交给 `0xa017aed6` 写入新建接收事件的首字节。

当前镜像没有给参数 1、2 或寄存器第 18 位留下可验证的上层枚举名。本文只保存取位、
取反和接收事件分类的直接关系，不补造控制器型号或协议版本含义。

## 4. `0x62fc531c..0x62fc5323` 蓝牙设备地址缓存和填充

原始八字节为：

```text
01 23 45 67 89 ab 00 00
```

前六字节是蓝牙设备地址缓存，后两字节没有读取或写入证据，是对齐填充：

1. 原厂文字 `bdaddr_init` 所属初始化函数取得六字节设备地址，完成字节调整后，
   由 `0xa0138ad4` 把恰好六字节写入本缓存；
2. 控制器初始化读取公开地址失败时，`0xa0176cfe` 把本缓存六字节复制到控制器地址区；
3. 后续公开地址事件生成、控制命令回应和地址比较均读取该控制器地址区的同一六字节值；
4. 因此 `01 23 45 67 89 ab` 是运行时覆盖前的原厂默认值，不能当作设备最终地址。

## 5. `0x62fc5324..0x62fc5327` 通用模数转换器增益系数

四个原始字节为 `00 00 80 3f`，按单精度浮点数解释为 `1.0`。射频参数初始化函数读取
原厂键名 `gpadc_gain`；取得有效校准值后，`0xa013294e` 把换算结果写入本地址。

`0xa0132bea..0xa01330f2` 在解析 13 条打包校准记录时多次读取本值作为除数，把原始整数
量化值换算为后续记录中的整数比例。初值 `1.0` 使没有有效增益校准时保持原量级，也避免
除数为零。该地址只按单精度加载和保存，不得改成整数 1。
