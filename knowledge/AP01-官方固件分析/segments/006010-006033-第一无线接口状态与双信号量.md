## 3. 第一无线接口调用关系

入口 `0xa01962a0` 先打开 `wlan0`（第一无线网络接口的系统名称），再把接口资料写到栈上并读取
结果类型。类型为 3 时进入使用本段对象的路径：

1. `0xa0196332` 形成本段首地址，`0xa0196336..0xa019633e` 等待第一项计数信号量；
2. `0xa0196342..0xa0196356` 读取状态字节，只在原值为 1 或 2 时继续；
3. `0xa019635a` 把状态写成 3，并通过同一条带地址推进的存储指令把工作寄存器移动到第二项
   计数信号量；
4. `0xa0196360` 从本段首地址加 28 字节读取文件描述符，以控制号 22 调用接口控制入口；
5. 控制成功后，`0xa01963a2..0xa01963a8` 等待第二项计数信号量；被唤醒后重新检查状态，
   状态仍为 3 就再次执行控制并等待；
6. 失败或状态离开 3 后，`0xa0196382..0xa019638a` 归还第一项计数信号量并结束本轮处理。

初始计数 1 和 0 分别与“先独占进入”和“等待外部通知”两种实际行为闭合，不是根据相邻
零值猜测。

## 4. 能力边界

- 已闭合：全部 36 个源字节、状态字节、两项计数信号量、文件描述符、尾部保留字和当前
  入口中的等待、控制、重试与清理顺序。
- 本段没有直接暴露把状态从 0 改为 1 或 2、以及归还第二项计数信号量的函数；这些变化可能
  来自接口驱动回调或通过已登记地址间接访问，当前证据不足以命名具体生产者。
- 文件描述符初值 `-1` 只表示镜像启动初态；入口运行期间会使用已打开接口对应的动态值。
- 后方 `0x006034` 已被界面对象直接作为坐标表首地址使用，不属于本状态对象。
