# `0x0060c4..0x0060c7` 架构日志处理门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

## 1. 覆盖范围

- 文件偏移：`0x0060c4..0x0060c7`
- 复制后运行地址：`0x62fc55b0..0x62fc55b3`
- 长度：4 字节
- 原始四字节值：`0x00000001`
- 本段原始字节散列：`67abdd721024f0ff4e0b3f4c2fc13bc5bad42d0b7851d456d88d203d15aaa450`

## 2. 直接读取与调用

`0xa01ab4ce` 对应原厂字符串中的 `arch_log_handler`。它在 `0xa01ab4e2..0xa01ab4ee`
直接读取本段最低字节：

- 值为 0 时立即返回；
- 值非 0 时按消息长度加一申请内存，清零后复制消息，补上结尾零字节并输出包含消息长度和
  内容的日志，随后继续处理并释放内存；
- 申请失败时只记录失败位置并返回。

直接调用者是 `0xa008ff6e` 和 `0xa009005a`。当前全镜像地址引用没有找到本字节的直接写入
指令，因此只能确认初值 1 会打开这条处理路径，不能确定运行时是否还会由间接路径修改。

## 3. 能力边界

- 已闭合：4 个源字节、最低字节读取、开关两条分支、两个直接调用者和成功、失败清理。
- 未闭合：原厂变量名、其余三个高字节是否仅为对齐，以及潜在间接写入生产者。
