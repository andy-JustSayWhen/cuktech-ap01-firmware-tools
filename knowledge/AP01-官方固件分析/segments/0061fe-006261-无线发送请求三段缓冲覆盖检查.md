## 1. 覆盖范围

- 文件偏移：`0x0061fe..0x006261`
- 执行地址：`0xa00051fe..0xa0005261`
- 长度：100 字节
- 本段原始字节散列：`ca98723384df1b9f2faea05fb7c1d8b0d0b884df9c99bad753896d46e32e84c4`

原厂接口唯一说明发送载荷最多可拆成三段，第一段必须包含完整以太网头和预留空间。本段二进制
正好实现一段、两段和三段三条路径，并拒绝缺链或三段仍未完整覆盖的输入。

## 3. 覆盖算法

| 实际输入 | 本段判定 |
| --- | --- |
| 首段后剩余长度为 0 | 段数 1，继续建描述 |
| 首段未覆盖完，第二段为空 | 记录分段不足并释放 |
| 第二段后剩余长度为 0 | 段数 2，继续建描述 |
| 第二段未覆盖完，第三段为空 | 记录分段不足并释放 |
| 第三段长度恰好等于全部剩余长度 | 段数 3，继续建描述 |
| 第三段短于或长于剩余长度 | 记录分段不足并释放 |

二、三段地址均由 `缓冲地址 + 12 + 数据偏移` 得到；只有首段为纳入以太网头额外向前移动
14 字节。这里没有第四段检查，三段是硬上限。

## 4. 能力边界

- 已闭合：100 个源字节、30 条指令、三种成功段数、二三段地址和长度公式、三条分段不足
  失败条件。
- “段数为 1”和“段数为 2”的赋值指令位于后方错误出口聚合区，本文只记录本段分支条件；
  待顺序读到对应地址时再把目标指令计入覆盖。
- 完整发送请求函数仍未闭合，下一地址开始写入发送描述公共字段。
