## 3. 描述字段与普通以太网路径

| 描述偏移 | 本段写入内容 |
| --- | --- |
| `+0x04` | 原发送缓冲 |
| `+0x08` | 确认回调 |
| `+0x0c` | 确认回调上下文 |
| `+0x10` | 可选接收缓冲 |
| `+0x18` | 描述自身地址 |
| `+0x1c` | 跳过以太网头后的首段数据地址 |
| `+0x20` | 原全包长度 |
| `+0x22` | 六字节目标硬件地址 |
| `+0x28` | 六字节源硬件地址 |
| `+0x2e` | 以太网类型原始 16 位值 |
| `+0x30` | 输入布尔标志形成的第 4 位 |
| `+0x34` | 从数据字节最高三位取得的分类值 |
| `+0x35` | 无线接口下一层对象提供的编号样字节 |

普通以太网路径只把 14 字节头用于提取目标地址、源地址和类型；送往后方硬件描述的首段地址
与长度会重新跳过这 14 字节。类型值等于 `0x0800` 时才提取数据字节最高三位；无接收缓冲从
首段数据 `+1` 读取的目标分支尚在后方，有接收缓冲则从第二段数据 `+1` 读取。

`0xa00052c4` 的四字节原码不在当前通用反汇编器的已命名指令表中。其输入是以太网头两个类型
字节、输出紧接无符号 16 位截取并与 `0x0800` 比较，因而“用于网络类型比较的字节顺序转换”
由数据流闭合；具体原厂助记名保留未定，不伪造名称。
