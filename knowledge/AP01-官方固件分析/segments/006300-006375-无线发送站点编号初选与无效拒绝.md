## 1. 覆盖范围

- 文件偏移：`0x006300..0x006375`
- 执行地址：`0xa0005300..0xa0005375`
- 长度：118 字节
- 本段原始字节散列：`39309e46c320186493c1b18f8f1211c816bcd6aa2652b2cc6bee19a10bcd73e0`

描述 `+0x36` 在后续所有发送队列计算中作为站点下标使用，原厂公开接口也把对应结果称为
`staid`；本文据此将它记为站点编号。

## 3. 站点编号门禁

- 当前可接受的普通站点编号是 0～3；255 是明确的无效哨兵值。
- 4～254 不会被当作普通失败继续执行，而是触发带 `fhost_tx_req` 和位置号 848 的断言。
- 站点编号 255 且描述第 3 标志位未置位时，函数调用统一释放入口、记录无效站点并返回 -2。
- 描述第 3 标志位已置位时允许 255 继续；该标志由后方非普通以太网路径设置，完整语义待顺序
  读到后闭合。

## 4. 能力边界

- 已闭合：118 个源字节、36 条指令、站点编号描述偏移、0～3 与 255 的合法集合、断言范围、
  普通无效站点的释放顺序和 -2 返回值。
- `+0x5e` 接口状态的正式枚举名，以及状态 0、2 各自选择站点编号的目标分支仍在后方；本文
  只记录已经到达的分流条件，不提前命名。
- 完整发送请求函数仍未闭合。
