## 3. 记录布局和串联结果

每条记录固定 20 字节，布局由本段三次完全一致的写入直接闭合：

| 记录内偏移 | 内容 |
| --- | --- |
| `+0x00` | 固定值 `0xcafefade` |
| `+0x04` | 下一条记录地址；末条为 0 |
| `+0x08` | 数据段起点 |
| `+0x0c` | 数据段包含式结束地址，即 `起点 + 长度 - 1` |
| `+0x10` | 0 |

第一、二、三条记录分别位于描述基址 `+0xd0`、`+0xe4`、`+0xf8`。描述 `+0x54` 始终指向
第一条；实际段数为 1 时第一条的下一地址为零，为 2 时第一条指向第二条且第二条结束，为 3
时再由第二条指向第三条且第三条结束。
