# `0x006622..0x006665` 按六字节地址查找站点编号

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

前一函数调用本函数的位置见
[`0x006376..0x006403` 无线发送分段回填、特殊类型与站点来源](006376-006403-无线发送分段回填特殊类型与站点来源.md)。

## 1. 覆盖范围

- 文件偏移：`0x006622..0x006665`
- 执行地址：`0xa0005622..0xa0005665`
- 长度：68 字节
- 本段原始字节散列：`979b7d6aa5c934e71a33c4a9f0fcbba1f0c01e03bf65d4e1af5f7473bd091b1d`

调用点把下一层接口对象作为第一参数、发送描述中的六字节目标地址作为第二参数；返回值随后
直接进入站点编号合法集合与无效值门禁。因此本文把返回字节记为站点编号。

## 3. 查找结构与返回值

接口对象 `+0xec` 保存单向站点链首节点；每个节点至少包含：

| 节点偏移 | 本函数已证实的用途 |
| --- | --- |
| `+0x00` | 下一节点地址 |
| `+0x21` | 一字节站点编号 |
| `+0x24..+0x29` | 六字节地址 |

本函数把六字节地址拆成三组 16 位值顺序比较。任一组不同就读取下一节点；三组全部相同就
返回节点 `+0x21`；链表为空或遍历到尾部仍未匹配则返回 255。调用者已经把 255 定义为无效
站点编号哨兵值。

## 4. 能力边界

- 已闭合：68 个源字节、22 条指令、链首偏移、下一节点偏移、六字节地址偏移、站点编号偏移、
  完整匹配路径和未命中返回值。
- 节点的原厂结构体名称、接口对象 `+0xec` 字段名和该链的增删入口不在本函数内，本文不反推。
- 本函数只做顺序查找，没有改变接口对象、节点或待查地址。
