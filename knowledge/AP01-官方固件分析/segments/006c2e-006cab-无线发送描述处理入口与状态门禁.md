## 3. 入口门禁

入口连续执行三层检查：

1. 描述 `+0x21` 只能是 0 或 1；
2. 描述 `+0x22` 若不是 255，则对应 560 字节站点状态项必须满足 `+0x23 != 0` 且
   `+0x30 == 0`；
3. 以 `+0x21` 索引的 1,128 字节无线状态项必须通过前文候选节点匹配判定。

第一层或第二层失败跳往同一后方终止准备路径；第三层失败跳往另一条终止准备路径。两条路径
尚未顺序读到，本文只保存跳转事实，不提前解释终止状态码。站点编号 255 明确跳过第二层，但
仍须通过第一层和第三层。
