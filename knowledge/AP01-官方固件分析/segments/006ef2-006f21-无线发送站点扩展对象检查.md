# `0x006ef2..0x006f21` 无线发送站点扩展对象检查

检查该站点项 `+0x144` 的扩展对象地址，并按检查结果转向后方处理。

## 3. 直接调用关系

本段以描述 `+0x22` 为索引，定位公式为 `0x62fd4a10 + 站点编号 * 560`。读取的站点项
字段是 `+0x144`，即十进制 324。该字段非空时，执行流携带描述 `+0x38` 指向的源对象，
跳至 `0xa0006fe0` 的后方扩展字段复制路径；该字段为空时，执行流携带原厂文字和行号 501，
跳至 `0xa0006642`。

`0xa0006642` 会继续调用更后方的 `0xa01644f0`，但两个目标尚未按文件顺序通读完成，因此
本文只把它登记为共用报告入口，不提前定义其最终日志级别或失败处置语义。

## 4. 能力边界

- 已闭合：48 个源字节、13 条指令、站点项定位公式、`+0x144` 检查和两条直接去向。
- 原厂文字和行号是直接常量证据；共用报告入口的最终语义仍待顺序读到对应实现后闭合。
- `0xa0006fe0` 的扩展字段复制位于当前大型函数后部，本文只登记其入口条件。
- 大型函数仍未闭合。
