# `0x007158..0x007183` 无线发送时间字段与模式计数

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段位于三参数函数调用之后。它按描述最低位决定是否用固定寄存器读数和全局 16 位值生成
描述 `+0x4c`，随后无条件增加当前 32 字节模式状态项 `+0x04` 的四字节计数。

## 3. 写回次序

描述最低位只控制 `+0x4c` 的生成：最低位为零时写入
`(读取四字节[0x24b00120] >> 10) + 读取两字节[0x62fd6c18]` 的低 16 位；最低位置位时
保留描述 `+0x4c` 原值。

无论最低位如何，随后都会定位 `0x62fd858c + 模式 * 32`，并把该模式状态项 `+0x04`
的四字节计数加一。原厂没有在本段执行饱和或溢出判断。
