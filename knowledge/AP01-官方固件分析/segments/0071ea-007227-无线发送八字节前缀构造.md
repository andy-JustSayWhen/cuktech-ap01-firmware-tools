# `0x0071ea..0x007227` 无线发送八字节前缀构造

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段只在描述标志最低位为零时继续：它沿描述 `+0x54` 所指对象取得 `+0x4c` 地址，按交换
字节后的描述 `+0x1a` 与 1,535 比较；超过阈值时把地址前移 8 字节并构造四个半字前缀。

## 1. 覆盖范围

- 文件偏移：`0x0071ea..0x007227`
- 执行地址：`0xa00061ea..0xa0006227`
- 长度：62 字节
- 本段原始字节散列：`7569a31773366c3d2f212c3aa806cc47d162ffcbbf11c4a1fe37e975e3800198`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa00061ea` | `001b7b13` | 提取此前保存的描述标志最低位 `0x0001`。 |
| `0xa00061ee` | `380b1de3` | 最低位置位时跳往后方 `0xa0006d88` 路径。 |
| `0xa00061f2` | `054d2783` | 最低位为零时读取发送描述 `+0x54` 的对象地址。 |
| `0xa00061f6` | `5ff00713` | 把比较上限设为 1,535。 |
| `0xa00061fa` | `47ec` | 读取该对象 `+0x4c` 的地址，作为后续调用的第二参数。 |
| `0xa00061fc` | `01ad5783` | 读取发送描述 `+0x1a` 的 16 位值。 |
| `0xa0006200` | `ad8787f7` | 执行 `swap8`，交换这两个字节的位置。 |
| `0xa0006204` | `3c07b78b` | 只保留交换结果的低 16 位。 |
| `0xa0006208` | `02f77063` | 交换结果不大于 1,535 时不构造前缀，保持第二参数地址不变。 |
| `0xa000620c` | `77ed` | 装入前缀首个半字常量的高位。 |
| `0xa000620e` | `aaa78793` | 得到四字节值 `0xffffaaaa`，其待写低半字为 `0xaaaa`。 |
| `0xa0006212` | `2985d78b` | 先把第二参数地址减 8，再在新地址写入半字 `0xaaaa`。 |
| `0xa0006216` | `478d` | 把第二个半字设为 3。 |
| `0xa0006218` | `00f59123` | 在新地址 `+0x02` 写入半字 3。 |
| `0xa000621c` | `00059223` | 在新地址 `+0x04` 写入半字 0。 |
| `0xa0006220` | `01ad5783` | 重新读取发送描述 `+0x1a` 的原始 16 位值。 |
| `0xa0006224` | `00f59323` | 在新地址 `+0x06` 写入该原始值。 |

## 3. 地址更新与前缀布局

`th.shib` 在这里不是普通定址写入。按[玄铁处理器扩展规范](https://github.com/T-head-Semi/thead-extension-spec/releases/download/2.2.2/xthead-2023-01-30-2.2.2.pdf)，
它先把基址寄存器加上有符号立即数，再向更新后的地址写 16 位值；本条立即数为 -8、移位为
0，所以第二参数地址永久前移 8 字节。

当交换字节后的描述 `+0x1a > 1535` 时，最终八字节布局为：

| 相对新地址 | 半字值 |
| --- | --- |
| `+0x00` | `0xaaaa` |
| `+0x02` | `0x0003` |
| `+0x04` | `0x0000` |
| `+0x06` | 描述 `+0x1a` 的原始值 |

未超过阈值时不写这八字节，第二参数仍指向对象原 `+0x4c` 地址。两种路径在下一条指令会合。

## 4. 能力边界

- 已闭合：62 个源字节、17 条指令、前移写入语义、阈值和八字节精确布局。
- 描述最低位置位的 `0xa0006d88` 路径待顺序读到后闭合。
- 八字节前缀的原厂结构名称尚无字符串或类型定义证据。
- 大型函数仍未闭合。
