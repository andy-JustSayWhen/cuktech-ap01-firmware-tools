## 3. 当前构造区布局

通过 `+0x20 != 255` 门禁后，本段形成的直接布局为：

| 构造区偏移 | 值 |
| --- | --- |
| `+0x00` | `0x80` |
| `+0x01` | `0x00` |
| `+0x16..+0x17` | `低16位(描述[+0x2c] << 4)`，小端序 |

描述 `+0x1c` 的 `0x0200` 位还决定描述 `+0x20` 的值是否附加 `0x10`；结果将在下一段
写入构造区。只有 `0x0100` 位置位才顺序进入下一段，否则转到 `0xa0006be2`。
