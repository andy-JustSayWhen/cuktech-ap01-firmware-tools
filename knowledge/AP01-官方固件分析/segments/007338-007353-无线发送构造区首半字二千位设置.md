# `0x007338..0x007353` 无线发送构造区首半字二千位设置

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段只在前文已确认描述 `+0x1c` 的 `0x0004` 位置位时执行。它重组构造区首半字，设置
`0x2000` 位，并按小端序写回两字节。

## 1. 覆盖范围

- 文件偏移：`0x007338..0x007353`
- 执行地址：`0xa0006338..0xa0006353`
- 长度：28 字节
- 本段原始字节散列：`d731b3ddf80d0d5cac83935c23e3e8f81c82b1eb8cd810f3d44ee3af9b26399c`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa0006338` | `0019c783` | 读取构造区 `+0x01`。 |
| `0xa000633c` | `0009c683` | 读取构造区 `+0x00`。 |
| `0xa0006340` | `07a2` | 把高字节左移 8 位。 |
| `0xa0006342` | `8fd5` | 按小端序重组构造区首半字。 |
| `0xa0006344` | `6689` | 装入待设置位 `0x2000`。 |
| `0xa0006346` | `8edd` | 把 `0x2000` 合入首半字。 |
| `0xa0006348` | `00f98023` | 写回原首半字的低字节；设置位不影响该字节。 |
| `0xa000634c` | `0086d793` | 取设置后的高字节。 |
| `0xa0006350` | `00f980a3` | 把高字节写回构造区 `+0x01`。 |

## 3. 位映射

直接效果是：

`构造区首半字 = 构造区首半字 | 0x2000`

原厂低字节写回使用的是设置前的首半字，但 `0x2000` 只位于高字节，因此与直接公式完全
等价。描述 `+0x1c` 的 `0x0004` 位为零时，前段已直接跳过本段。

## 4. 能力边界

- 已闭合：28 个源字节、9 条指令、描述 `0x0004` 到构造区 `0x2000` 的精确映射。
- 本段不修改构造区首半字其他位。
- 构造区的正式协议结构名称仍无直接证据。
- 大型函数仍未闭合。
