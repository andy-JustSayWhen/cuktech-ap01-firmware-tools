# `0x007354..0x007393` 无线发送三半字复制与首字段组合门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段以描述 `+0x21` 的无线状态项编号定位 1,128 字节状态项，将其中连续三个半字复制到
构造区，再要求构造区首半字的 `0x0300` 组合恰好等于 `0x0100` 才顺序继续。

## 1. 覆盖范围

- 文件偏移：`0x007354..0x007393`
- 执行地址：`0xa0006354..0xa0006393`
- 长度：64 字节
- 本段原始字节散列：`0e14ea90a4fbcfd70d058c025c74fcf2897a0af59929c810c7ff31ea80161fd6`

## 3. 复制与组合条件

三项复制关系连续且固定：

| 无线状态项源偏移 | 构造区目标偏移 |
| --- | --- |
| `+0x58..+0x59` | `+0x0a..+0x0b` |
| `+0x5a..+0x5b` | `+0x0c..+0x0d` |
| `+0x5c..+0x5d` | `+0x0e..+0x0f` |

复制完成后检查首半字 `& 0x0300`。只有结果等于 `0x0100` 才进入下一段；`0x0000`、
`0x0200` 和 `0x0300` 都转到 `0xa0006c36`。

## 4. 能力边界

- 已闭合：64 个源字节、17 条指令、三项半字复制和四选一首字段组合门禁。
- `0xa0006c36` 的替代构造路径尚待顺序读取。
- 三个无线状态字段的正式名称尚无原厂结构定义证据。
- 大型函数仍未闭合。
