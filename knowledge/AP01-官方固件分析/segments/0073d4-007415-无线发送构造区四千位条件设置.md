# `0x0073d4..0x007415` 无线发送构造区四千位条件设置

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段根据早先保存的站点对象首字、无线状态项 `+0x450` 的 `0x02` 位，以及交换字节后的
描述 `+0x1a` 与站点项 `+0x38` 的比较，决定是否设置构造区首半字 `0x4000` 位。

- 文件偏移：`0x0073d4..0x007415`

## 3. 设置条件

先决条件是站点项 `+0xac` 所指对象的首个四字节值非零。在此前提下，满足以下任一条件
就设置构造区首半字 `0x4000`：

1. 当前无线状态项 `+0x450` 的 `0x02` 位为零；
2. 该位为一，但交换字节后的描述 `+0x1a` 不等于当前站点项 `+0x38`。

对象首字为零，或无线状态位为一且两字段相等时，原厂保持首半字 `0x4000` 原状态，不主动
清除它。

## 4. 能力边界

- 已闭合：66 个源字节、20 条指令、三个输入条件和构造区 `0x4000` 的只置不清行为。
- 站点对象首字与无线状态项 `+0x450` 的正式字段名仍无直接证据。
- 本段执行后进入下一组字段处理，不代表构造区已完成。
- 大型函数仍未闭合。
