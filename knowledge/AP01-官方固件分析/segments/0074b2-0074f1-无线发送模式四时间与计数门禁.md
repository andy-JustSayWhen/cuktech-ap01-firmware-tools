# `0x0074b2..0x0074f1` 无线发送模式四时间与计数门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是前文模式字节等于 4 时进入的专用路径。它把固定地址 `0x24b00120` 的当前读数与
十二字节索引区两个旧值执行带常数差值门禁，再检查八位计数和站点项字节。

## 1. 覆盖范围

- 文件偏移：`0x0074b2..0x0074f1`
- 执行地址：`0xa00064b2..0xa00064f1`
- 长度：64 字节
- 本段原始字节散列：`93bdf0b7b97f9ca6d7175857a691ce517e730a3174c65913a2374ff3a8ee6242`

## 3. 四项连续门禁

本段只有以下四项全部通过才顺序进入下一段：

1. `有符号32位(当前读数 - 1,000,000 - 索引区[+0x198]) >= 0`；
2. `有符号32位(当前读数 - 500,000 - 索引区[+0x19c]) >= 0`；
3. 前文刚加一并截成八位的计数大于 1；
4. 当前站点项 `+0x22` 不等于 1。

任一失败都在本段直接跳至共用路径 `0xa0006184`。前两项按原厂实际 32 位有符号结果记录，
不把计数器回绕情形改写成普通数学时间差。

## 4. 能力边界

- 已闭合：64 个源字节、18 条指令、两个精确差值公式、八位计数门禁和站点字节门禁。
- `+0x198`、`+0x19c` 两个旧值的正式时间字段名尚无原厂结构定义证据。
- 当前固定读数来自前文 `0x24b00120`，本段不重新读取。
- 大型函数仍未闭合。
