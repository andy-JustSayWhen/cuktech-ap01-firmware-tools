# `0x007606..0x00762f` 无线发送固定区替代调用路径

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是固定对象首层检查失败或返回新编号等于 4 时汇入的替代路径。它检查固定区另一字段，
按条件调用一到两个后方函数，最后统一跳回 `0xa0006184`。

- 文件偏移：`0x007606..0x00762f`
- 执行地址：`0xa0006606..0xa000662f`

## 3. 替代调用条件

路径关系为：

1. `读取四字节[0x62fd860c] != 0`：不调用，直接返回共用路径；
2. `读取四字节[0x62fd860c] == 0`：调用
   `a01a2988(读取四字节[0x62fd8614])`；
3. 第一个返回低字节等于 4：不执行第二调用；
4. 第一个返回低字节不等于 4：调用 `a0165c60(返回低字节)`。

所有分支最终都去 `0xa0006184`，两个调用的返回值都不再用于当前函数后续判断。

## 4. 能力边界

- 已闭合：42 个源字节、12 条指令、两固定地址、两级调用门禁、参数和统一去向。
- 两个后方函数的内部动作待顺序读到函数本体后闭合。
- 固定区两个字段的正式变量名尚无直接证据。
- 大型函数仍未闭合。
