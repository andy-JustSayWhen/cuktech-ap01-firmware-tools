# `0x007684..0x0076d1` 无线发送扩展对象超时刷新

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段比较站点扩展对象保存的旧读数和固定地址当前读数，并结合对象 `+0x106` 的 `0x10` 位
决定是否调用刷新函数。刷新后清两个状态字节、滚动一个二位编号并更新旧读数。

## 3. 刷新条件与结果

刷新条件是以下两项的任意一项成立：

1. `有符号32位(旧读数 + 150000 - 当前读数) < 0`；
2. 上式不小于零，但扩展对象 `+0x106` 的 `0x10` 位已置。

不刷新时，本段把后续使用的结果寄存器明确设为 0。刷新时，该寄存器保留
`0xa00072c8` 的返回值；随后无条件执行 `+0xfa = 0`、`+0x108 = 0`、
`+0x107 = (+0x107 + 1) & 3`，并用重新读取的当前值覆盖 `+0x00`。
