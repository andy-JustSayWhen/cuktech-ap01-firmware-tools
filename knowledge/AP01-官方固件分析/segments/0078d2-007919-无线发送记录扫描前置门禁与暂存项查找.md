# `0x0078d2..0x007919` 无线发送记录扫描前置门禁与暂存项查找

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段检查扫描编号是否到达对象 `+0x118` 上界，然后定位对应二十字节记录，按记录半字、
记录字节以及它是否对应对象 `+0xe8`、`+0xea` 两项编号执行门禁。通过后再按辅助编号读取
十二字节暂存区半字，跳过值为 `0xffff` 的项。

## 1. 覆盖范围

- 文件偏移：`0x0078d2..0x007919`
- 执行地址：`0xa00068d2..0xa0006919`
- 长度：72 字节
- 本段原始字节散列：`ccdc1c0296c442367a72acc7ebd3e0c13478a129f9ab6e7cc6ca7864a8a7d7f9`

## 3. 前置门禁

当前扫描记录在进入后方暂存值比较路径前，必须没有被以下条件提前转走：

1. 扫描编号达到对象 `+0x118` 上界；
2. 记录 `+0x14` 大于 `0xa665` 且记录 `+0x1c` 不大于 `10`；
3. 扫描编号等于对象 `+0xe8`，且记录 `+0x0c` 不大于 `20`；
4. 扫描编号等于对象 `+0xea`，且记录 `+0x0c` 不大于 `20`；
5. 辅助编号大于 `5`。

随后按辅助编号读取六个半字暂存项。值为 `0xffff` 的项被跳过，首个非 `0xffff` 值转到
`0xa00069f2` 继续比较。

## 4. 专用指令证据

`0xa000690c` 的 `th.lrhu` 按[玄铁处理器扩展规范](https://github.com/T-head-Semi/thead-extension-spec/releases/download/2.2.2/xthead-2023-01-30-2.2.2.pdf)
执行带寄存器缩放索引的无符号半字读取；末尾缩放值 `1` 使辅助编号乘以 `2`，与十二字节
暂存区的六个半字布局一致。

## 5. 能力边界

- 已闭合：72 个源字节、21 条指令、扫描上界、记录地址、五项前置门禁和六半字查找方式。
- `0xa00069f2` 与 `0xa0006a1e` 的目标路径尚未顺序覆盖，本段不提前解释其最终效果。
- 二十字节记录各字段的正式名称尚无原厂结构定义证据。
- 大型函数仍未闭合。
