# `0x0079b6..0x0079e3` 无线发送其余高编号与第六暂存项写入

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段承接六项暂存分派中大于 `3` 且不等于 `4` 的项目编号。在从当前编号递增至结束值
`6` 的正常循环中，该路径对应编号 `5`。它以前文保存的第二项记录半字调用
`0xa0163246`，经变化和有效性两级门禁后写入暂存区第六项。

## 1. 覆盖范围

- 文件偏移：`0x0079b6..0x0079e3`
- 执行地址：`0xa00069b6..0xa00069e3`
- 长度：46 字节
- 本段原始字节散列：`e7b2c756916decacaf9819c18f420b874c03025431b13af2cfb4b8479f7902ee`

## 3. 第六项写入条件

在正常递增至 `6` 的循环中，编号 `5` 的第六项只在以下条件全部满足时更新：

1. `新值 = 0xa0163246(扩展对象, 第二项记录半字)`；
2. 新值不等于原第二项记录半字；
3. `0xa0163f1a(扩展对象, 新值)` 返回非零；
4. `暂存区第六项 = 新值低16位`。

否则该项保持初始化值 `0xffff`，控制流直接递增项目编号。

## 4. 能力边界

- 已闭合：46 个源字节、14 条指令、剩余高编号路径的两次调用参数、两级门禁、第六项写入和会合点。
- 路径条件的机器事实是“项目编号大于 `3` 且不等于 `4`”；编号 `5` 的对应关系还依赖前文正常递增至结束值 `6` 的循环约束。
- 两个被调用函数的本体尚未顺序覆盖，本段不替它们命名业务功能。
- 大型函数仍未闭合。
