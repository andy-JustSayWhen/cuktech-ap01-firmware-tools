# `0x007a1e..0x007a31` 无线发送扫描递增与低读数替代换算

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段包含两个前方分支的回接路径。第一条把记录扫描编号按低 16 位加一后继续扫描；第二条
处理前文函数返回值不大于 `2,000,000` 的情况，用对象 `+0xf6` 半字乘以 `10`，再回到
前方低半字提取与对象 `+0xf8` 写入处。

## 1. 覆盖范围

- 文件偏移：`0x007a1e..0x007a31`
- 执行地址：`0xa0006a1e..0xa0006a31`
- 长度：20 字节
- 本段原始字节散列：`c216b8a626389f9b2d55f1aee58e3709fb91d991397affde19efd404b51bcc70`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa0006a1e` | `0605` | 把当前记录扫描编号加一。 |
| `0xa0006a20` | `3c06360b` | 把递增结果限制为低 16 位。 |
| `0xa0006a24` | `b57d` | 回到 `0xa00068d2`，按上界继续记录扫描。 |
| `0xa0006a26` | `0f6cd703` | 另一回接路径读取扩展对象 `+0xf6` 的 16 位值。 |
| `0xa0006a2a` | `46a9` | 准备乘数常数 `10`。 |
| `0xa0006a2c` | `02d70733` | 计算对象 `+0xf6` 半字乘以 `10`。 |
| `0xa0006a30` | `b3b5` | 回到 `0xa000679c`，提取乘积低 16 位并写入对象 `+0xf8`。 |

## 3. 两条回接关系

- 记录扫描跳过当前项时：`扫描编号 = 低16位(扫描编号 + 1)`，然后重走前置门禁；
- 前文调用返回值不大于 `2,000,000` 时：
  `对象[+0xf8] = 低16位(对象[+0xf6] × 10)`。

后一关系与前文高读数路径组成两种写入来源：高读数采用 `30,000,000 / 返回值`，低读数
采用对象 `+0xf6 × 10`。

## 4. 能力边界

- 已闭合：20 个源字节、7 条指令、扫描递增回接和低读数替代换算回接。
- 对象 `+0xf6`、`+0xf8` 的正式字段名称尚无原厂结构定义证据。
- 两条路径均回到已经顺序覆盖的地址，直接调用关系已闭合。
- 大型函数仍未闭合。
