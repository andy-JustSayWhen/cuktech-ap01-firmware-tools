# `0x007aa4..0x007b07` 无线发送候选高位组合与分级低值门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续筛选候选记录 `+0x16` 半字。对象 `+0x106` 的 `0x02` 位置位时，候选半字第
12、13 位不得全零。随后按对象 `+0x11c`、`+0x120` 决定是否进入更细筛选；细筛先检查
候选半字的一组中间位，再按对象 `+0x11c` 是否大于 `0x2000`，要求前文变宽低位值至少
达到 `2` 或 `4`。

## 3. 分级门禁

候选半字的变宽低位值 `V(H)` 唯一定义见
[`记录半字变宽低位值比较`](007a32-007aa3-无线发送记录半字变宽低位值比较.md#3-比较值选择规则)。

本段控制关系为：

1. 对象 `+0x106` 的 `0x02` 位置位时，候选半字第 12、13 位不得全零；
2. 对象 `+0x11c` 与 `+0x120` 均为零时，直接去 `0xa0006b08`；
3. 否则候选半字第 12、13 位仍不得全零；
4. 候选中间值为：第 13 位置位时取第 4 至 6 位，否则取第 3 至 4 位；
5. 中间值大于 `1` 时直接去 `0xa0006b08`；
6. 中间值不大于 `1` 时：对象 `+0x11c <= 0x2000` 要求 `V(H) >= 2`，大于
   `0x2000` 要求 `V(H) >= 4`。
