# `0x007b60..0x007ba1` 无线发送候选淘汰与临时标记复核

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合候选淘汰回跳，并处理通过前方门禁的复核路径。复核前把候选记录 `+0x14` 临时
写成 `0xffff`，以扩展对象和候选编号调用 `0xa000722e`，随后恢复原半字。函数返回值
不小于原记录 `+0x18` 的 32 位值时回到前方候选后续检查，否则淘汰当前候选。

## 1. 覆盖范围

- 文件偏移：`0x007b60..0x007ba1`
- 执行地址：`0xa0006b60..0xa0006ba1`
- 长度：66 字节
- 本段原始字节散列：`5bde34e29c86f700f0c81ae1fbf385f5bc421e5de91707a36b07ebe28c84a4da`

## 3. 临时标记不变量

调用 `0xa000722e` 前后，候选记录 `+0x14` 的处理顺序为：

1. 旧半字已在前方保存；
2. 写入临时值 `0xffff`；
3. 调用 `0xa000722e(扩展对象, 候选编号低8位)`；
4. 无条件恢复旧半字；
5. 用返回值与原记录 `+0x18` 比较。

因此本段不会把临时 `0xffff` 留在候选记录中。返回值达到原记录值时重入前方
`0xa0006804`，否则递增遍历编号继续寻找候选。

## 4. 能力边界

- 已闭合：66 个源字节、20 条指令、候选淘汰回跳、临时标记、调用参数、原值恢复和返回门禁。
- `0xa000722e` 的函数本体尚未顺序覆盖，本段不替它命名业务功能。
- 回到 `0xa0006804` 后仍会经过前文记录半字门禁，唯一事实原文见相应前序分段。
- 大型函数仍未闭合。
