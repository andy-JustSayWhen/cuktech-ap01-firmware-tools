# `0x007e2a..0x007e69` 无线发送返回对象长度与附属半字初始化

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续初始化前段取得的返回对象：绑定既有对象指针，清四个 32 位字段，按来源值四字节
对齐后再加 `4` 计算低 16 位长度并写入返回对象 `+0x28`。随后设置工作对象状态字节，以
既有对象 `+0x18` 的值和工作对象 `+0x3c` 半字调用 `0xa01a2946`，把返回低半字写入
工作对象 `+0x3e`。

## 3. 长度公式与字段结果

返回对象 `+0x28` 的计算为：

`低16位(((既有对象[+0x18] + 3) & 0xfffffffc) + 4)`

返回对象同时得到：

- `+0x18 = 既有对象指针`；
- `+0x1c/+0x38/+0x3c/+0x40/+0x4c = 0`。

工作对象得到：

- `+0x41 = 1`；
- `+0x3e = 低16位(0xa01a2946(既有对象[+0x18], 工作对象[+0x3c]))`。
