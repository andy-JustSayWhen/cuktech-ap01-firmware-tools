# `0x007e6a..0x007eab` 无线发送计算半字并入长度与描述标志提交

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段把前段计算半字左移 `9` 位合入描述对象 `+0x30`，并把“计算半字乘以 `4`”加到返回
对象 `+0x28` 的长度。随后在工作对象与描述对象间写入双向指针，清描述标志
`0x00180000` 区后合入 `0x00680000`，再把同一标志同步到关联对象 `+0x38`。

## 3. 直接公式与指针关系

- `描述[+0x30]` 先合入 `工作[+0x3e] << 9`；
- `返回对象[+0x28] += 工作[+0x3e] × 4`；
- `工作[+0x24] = 工作[+0x28] = 描述对象指针`；
- `描述[+0x50] = 返回对象指针`；
- `最终标志 = (描述标志 & 0xffe7ffff) | 0x00680000`；
- `描述[+0x30] = 关联对象[+0x38] = 最终标志`。
