# `0x007eac..0x007ed1` 无线发送既有候选状态掩码与双编号门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是另一条既有候选对象复用路径的入口门禁。既有状态为零、掩码结果等于
`0x00280000`，或者候选对象 `+0x0c/+0x0d` 两个编号字节与描述对象 `+0x22/+0x20`
任一不相等时，都转到统一后方路径；四项检查全部通过才顺序继续。

## 1. 覆盖范围

- 文件偏移：`0x007eac..0x007ed1`
- 执行地址：`0xa0006eac..0xa0006ed1`
- 长度：38 字节
- 本段原始字节散列：`defb1c9c34a40513c03c24df42e573985d8c12210b45eca815de4fe11f341ff1`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa0006eac` | `ca7d` | 既有状态值为零时跳到 `0xa0006fa2`。 |
| `0xa0006eae` | `0197f7b3` | 把既有标志值与前方保存的掩码相与。 |
| `0xa0006eb2` | `00280737` | 准备比较值 `0x00280000`。 |
| `0xa0006eb6` | `0ee78663` | 掩码结果等于 `0x00280000` 时跳到 `0xa0006fa2`。 |
| `0xa0006eba` | `00c6c603` | 读取候选对象 `+0x0c` 的第一编号字节。 |
| `0xa0006ebe` | `022d4783` | 读取描述对象 `+0x22` 的第一期望编号。 |
| `0xa0006ec2` | `0ef61063` | 第一编号不相等时跳到 `0xa0006fa2`。 |
| `0xa0006ec6` | `00d6c603` | 读取候选对象 `+0x0d` 的第二编号字节。 |
| `0xa0006eca` | `020d4783` | 读取描述对象 `+0x20` 的第二期望编号。 |
| `0xa0006ece` | `0cf61a63` | 第二编号不相等时跳到 `0xa0006fa2`；相等时顺序继续。 |

## 3. 继续条件

顺序进入 `0xa0006ed2` 必须同时满足：

1. 既有状态值非零；
2. `既有标志值 & 前方掩码 != 0x00280000`；
3. `候选对象[+0x0c] == 描述对象[+0x22]`；
4. `候选对象[+0x0d] == 描述对象[+0x20]`。

任一不满足都统一跳到 `0xa0006fa2`。

## 4. 能力边界

- 已闭合：38 个源字节、10 条指令、空状态、掩码值和双编号四项门禁。
- 前方掩码寄存器的完整构造来源以及 `0xa0006fa2` 的实际处理要在相应顺序地址闭合。
- 候选对象与编号字段的正式业务名称尚无原厂定义证据。
- 大型函数仍未闭合。
