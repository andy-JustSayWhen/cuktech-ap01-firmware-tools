# `0x007ed2..0x007f39` 无线发送既有候选增量长度与容量门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段取得工作对象中的描述指针、索引和计算参数，再次调用 `0xa01a2946` 并把返回低半字
写入工作对象 `+0x3e`。代码用来源值的四字节对齐长度加“返回半字乘以 `4`”得到增量，
从按索引定位的表项读取容量，与候选对象当前长度加增量的需求值比较。

## 3. 长度与容量公式

`基础增量 = 低16位(((来源值 + 3) & 0xfffffffc) + 4)`

`总增量 = 基础增量 + 4 × 低16位(0xa01a2946 返回值)`

`需求值 = 候选对象[+0x28] + 总增量`

`容量值 = 表基址[4 × (既有表索引基值 + 工作对象[+0x43]) + 0x2c]`

- 容量值小于需求值：转到 `0xa0006fac`；
- 容量值不小于需求值：从 `0xa0006f3a` 顺序继续。
