# `0x007f3a..0x007f9f` 无线发送既有候选容量提交与源计数推进

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段处理前段容量足够的既有候选。它以 `72 × 当前索引` 定位源对象，把源对象 `+0x3e`
半字左移 `9` 位合入描述标志，随后用掩码和 `0x00700000` 规范标志并同步到关联对象。
本段还把增量加到候选对象长度，递增源对象 `+0x41` 字节计数，并在计数达到 `+0x40`
上限时调用 `0xa0007eba`。

## 3. 提交结果

- `源对象地址 = 源对象区基址 + 72 × 当前索引`；
- `最终标志 = ((描述标志 | (源对象[+0x3e] << 9)) & 0xffe7ffff) | 0x00700000`；
- `描述[+0x30] = 关联对象[+0x38] = 最终标志`；
- `描述[+0x50] = 候选对象指针`；
- `候选对象[+0x28] += 前段总增量`；
- `源对象[+0x28] = 描述对象指针`；
- `源对象[+0x41] = 低8位(源对象[+0x41] + 1)`。

只有新计数不小于源对象 `+0x40` 上限时才调用 `0xa0007eba(当前索引)`。
