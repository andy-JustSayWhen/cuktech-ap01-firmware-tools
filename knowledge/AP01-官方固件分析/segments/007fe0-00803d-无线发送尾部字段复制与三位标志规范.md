# `0x007fe0..0x00803d` 无线发送尾部字段复制与三位标志规范

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段复制四个 32 位字段到目标对象，并在源标志第 11、13 位均置位时重写目标 `+0x28`
字的第 16 至 18 位：源标志第 9、10 位决定第 16、17 位写 `0x00010000` 或

`+0x3c` 的 `0x04` 位决定是否清目标 `+0x08` 的 `0x0180`。

## 3. 字段复制与三位公式

直接复制：

| 目标 | 来源 |
| --- | --- |
| 目标 `+0x1c` | 第一源对象 `+0x14` |
| 目标 `+0x2c` | 第一源对象 `+0x24` |
| 目标 `+0x18` | 第二源对象 `+0xfc` |
| 目标 `+0x28` | 第二源对象 `+0x100` |

只有第二源对象 `+0xfc` 字的原第 11、13 位均为一时，才规范目标 `+0x28`：

- 先清第 16、17 位；源第 9、10 位等于 `0x0400` 时写 `0x00020000`，否则写
  `0x00010000`；
- 第二源对象 `+0x105` 非零时设置第 18 位，为零时转到后方清除路径。
