# `0x00803e..0x00808f` 无线发送中断保护提交与大型函数返回

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段在两次独立的中断保护区内完成尾部提交：第一次以描述对象、描述对象和当前索引为三个
参数调用 `0xa01a2b34`；第二次设置描述对象 `+0x5c` 半字最低位。随后恢复全部保存寄存器
和栈并返回。返回指令后保留的分支尾闭合前段源状态字节为零路径，清目标字第 18 位并回到
公共写回点。

## 3. 中断保护与返回

两次保护区互相独立：

1. 保存状态并清中断允许位；调用 `0xa01a2b34`；恢复原状态；
2. 再次保存状态并清中断允许位；执行 `描述[+0x5c] |= 1`；恢复原状态。

之后恢复进入函数时保存的返回地址、帧指针和 `s1..s11`，释放 `112` 字节栈帧并返回。

## 4. 大型函数闭合

- 本段闭合前段源状态字节为零时的目标第 18 位清除路径；源状态非零路径设置同一位。
- 下一条顺序指令位于 `0xa0007090`，形成另一函数入口。
- 因此执行地址 `0xa0005c2e..0xa000708f`、文件偏移 `0x006c2e..0x00808f` 的大型函数
  已经全部逐指令覆盖；所有前跳落点、回接、返回指令和返回后的分支尾均已纳入连续分段。
- `0xa01a2b34` 的函数本体尚未顺序到达，其具体业务名称保持未定。
