# `0x008126..0x008193` 无线发送组合编号表内半字查询

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0007126` 开始的独立查询函数。它把输入低 8 位作为十六字节记录编号，
把输入右移 `8` 位作为记录内半字编号；记录编号 `0..13` 且半字编号小于记录 `+0x0e`
上限时，从记录 `+0x08` 指针按两字节跨度读取并返回无符号半字。三类越界分别使用固定
字符串地址和行号调用 `0xa01644f0`。

## 3. 正常查询公式

`记录编号 = 输入 & 0xff`

`半字编号 = 输入 >> 8`

正常查询必须满足：

1. 记录编号小于 `14`；
2. 输入第 4 至 7 位为零；
3. 半字编号小于 `半字(记录表[记录编号] + 0x0e)`。

`记录地址 = 0xa053d3fc + 16 × 记录编号`

`返回值 = 无符号半字(*(记录地址 + 8) + 2 × 半字编号)`
