## 3. 当前路径公式

`比值 Q = (半字(对象 + 6) << 16) / 半字(对象 + 4)`

在对象 `+0x11 != 0` 时：

- `Q > 57,670`：`新值 = ((原值 × 32) + (Q × 96)) >> 7`；
- `Q <= 13,106` 且基准 `> 9`：采用同一第一算式；
- `Q <= 13,106` 且基准 `<= 9`：`新值 = 第1至25位(Q + 原值)`；
- `13,106 < Q <= 57,670`：转到下一顺序分段的第二算式。

所有写回只保留目标半字可容纳的低 16 位。
