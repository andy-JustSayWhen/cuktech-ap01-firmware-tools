## 3. 快照与加权关系

四项快照的直接关系为：

`快照[k] = 无符号半字(对象 + 20 × 无符号半字(对象 + 232 + 2k) + 22)`，
其中 `k = 0..3`。

令 `U = 无符号半字(对象 + 240)`、`V = 无符号半字(对象 + 242)`、
`P = 对象 + 244 的原 32 位字`。当 `V != 0` 时：

1. `Q = 有符号32位(低32位(U << 16)) / V`；
2. `对象[+244] = 低32位(80 × P + 48 × Q) 无符号右移 7 位`；
3. 对象 `+240..+243` 被清零。

当 `V == 0` 时，本段不改变对象 `+240..+247`。两条路径随后都调用
[`0x008194..0x00822d` 半字比值更新函数](008194-0081f3-无线发送半字比值分段更新主路径.md)，
其分支尾原文见
[`0x0081f4..0x00822d`](0081f4-00822d-无线发送半字比值更新分支尾与饱和计数.md)。
