# `0x00833a..0x0083af` 记录循环初始化与暂存半字恢复

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段读取对象 `+280` 的半字项数，清对象 `+216..+219`，并准备一个按二十字节记录跨度
运行的初始化循环。循环体位于尚待顺序到达的 `0xa000741e`。循环结束后，本段检查对象
`+286` 与 `+296` 的两个半字哨兵；在前者为 `65535`、后者不是 `65535` 时，把后者
恢复到对象 `+294` 字节指定记录的偏移 `+22`，清该记录的偏移 `+20` 半字和 `+29`
字节，并重置四个索引半字及保存槽。

## 3. 已证实的状态变化

当 `对象半字[+286] == 65535` 且 `对象半字[+296] != 65535` 时，令
`j = 对象字节[+294]`、`N = 对象半字[+280]`：

- `对象半字[20j + 22] = 对象半字[+296]`；
- `对象半字[20j + 20] = 0`；
- `对象字节[20j + 29] = 0`；
- `对象半字[+232,+234,+236,+238] = 低16位(N-1), 低16位(N-2), 低16位(N-3), 0`；
- `对象半字[+296] = 65535`，`对象字节[+294] = 0`。
