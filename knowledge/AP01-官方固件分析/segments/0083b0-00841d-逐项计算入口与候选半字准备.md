## 3. 当前直行路径的精确关系

当两次后方调用已经返回、`对象半字[+232] == 0` 且
`2 <= 对象字节[+265] <= 4` 时：

`候选半字 = 低16位(对象字节[+265] << 11) | 1`。

若随后候选搜索走到当前直行出口，令 `R = 0xa012f664` 的返回值、
`N = 对象半字[+280]`，则：

`候选编号 = 低8位((R 无符号取余 (N - 3)) + 1)`。

本段调用 `0xa012f664` 前没有紧邻的参数准备指令；目前只能确认其返回值用途，不能据此
给该函数命名。
