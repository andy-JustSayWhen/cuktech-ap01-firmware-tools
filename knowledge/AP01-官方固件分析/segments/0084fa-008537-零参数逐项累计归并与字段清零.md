# `0x0084fa..0x008537` 零参数逐项累计归并与字段清零

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是函数入口第二参数为零的路径。它把对象 `+262` 字节第六位置一，再以对象 `+280`
半字为项数，从 `对象 + 12` 开始按二十字节跨度遍历：若当前项偏移 `+6` 半字为零，
就把偏移 `+4` 半字加到偏移 `+0` 的 32 位字；否则把偏移 `+0` 的字清零。两条路径
随后都清偏移 `+4`、`+6` 两个半字。遍历完成后复用前段返回路径返回零。

## 3. 逐项关系

令 `N = 对象半字[+280]`，当前项起点 `P(i) = 对象 + 12 + 20i`，其中
`i = 0..N-1`：

- 若 `无符号半字(P(i)+6) == 0`：
  `字(P(i)+0) = 低32位(原字(P(i)+0) + 无符号半字(P(i)+4))`；
- 若 `无符号半字(P(i)+6) != 0`：`字(P(i)+0) = 0`；
- 两种情况都执行：`半字(P(i)+4) = 半字(P(i)+6) = 0`。

此外，对象字节 `+262` 的新值为 `原值 | 0x40`。遍历结束跳回
`0xa00074be`，该前段已证明会把返回值设为零并完整恢复现场。

## 4. 能力边界

- 已闭合：62 个源字节、20 条指令、对象标志位置一、两路逐项转换、两个半字清零、
  低 32 位加法截断和最终返回零。
- 本段只证明第二参数为零会执行这套归并；第二参数的正式业务含义仍无结构定义证据。
- 项数与对象内实际记录容量之间的约束在本段没有显式检查。
- 本大型函数继续于执行地址 `0xa0007538`、文件偏移 `0x008538`。
