本段是对象 `+262` 字节第四位已置一路径。它以对象 `+286` 半字为候选值，按对象

末项，把末项编号保存到对象 `+294`，把末项原半字保存到对象 `+296`，再用候选半字

索引，准备清全部项字段；项数为零的直行路径会直接改写对象标志并进入前方快照复核。

## 3. 常规未命中路径关系

令 `C = 对象半字[+286]`、`N = 对象半字[+280]`。搜索逐项比较
`对象半字[20i + 22] == C`，其中搜索编号每次递增后都截成低 8 位。

在未发生低 8 位回绕、搜索正常以 `i == N` 结束时，令 `j = 低8位(N - 1)`：

- `对象字节[+294] = j`；
- `对象半字[+296] = 对象半字[20j + 22]` 的原值；
- `对象半字[20j + 22] = C`；
- `对象半字[20j + 20] = 0`；
- `对象半字[+232] = 对象半字[+234] = 对象半字[+236] = j`。

清零循环结束后的标志变换由当前直行尾直接证明为：

`对象字节[+262] = (原值 & 0xcf) | 0x20`，同时 `对象字节[+250] = 0`。

随后待返回值设为 `1`，进入已经通读的四项快照复核循环；全相等出口保持该返回值为一。

## 4. 能力边界

- 已闭合：112 个源字节、32 条指令、候选搜索、常规末项选择、原值保存、候选替换、
  三索引同步、标志变换和全相等时返回一。
- 命中或搜索编号与项数宽度不一致时进入 `0xa00075ea`，尚待下一顺序段闭合。
- 非零项数进入 `0xa0007600` 的清零循环体，也尚未到达当前端点。
- 搜索编号被限制为 8 位，而项数是 16 位；本段没有显式上限门禁。正常终止所需的项数
  不变量必须由对象构造证据确认。
- 本大型函数继续于执行地址 `0xa00075ea`、文件偏移 `0x0085ea`。
