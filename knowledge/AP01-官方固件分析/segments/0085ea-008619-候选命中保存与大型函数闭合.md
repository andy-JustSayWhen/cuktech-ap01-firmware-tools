## 3. 三条尾部关系

### 3.1 候选命中

令 `j = 低8位命中编号`：

- `对象字节[+294] = j`；
- `对象半字[+296] = 对象半字[20j + 22]`；
- 随后从 `0xa00075bc` 开始，把 `j` 同步到对象 `+232`、`+234`、`+236`。

这条命中路径不在本段改写命中记录偏移 `+22`，也不在进入共用点前清该记录偏移 `+20`。

### 3.2 全项清零

令 `N = 对象半字[+280]`，`P(i) = 对象 + 12 + 20i`。对 `i = 0..N-1`：

`字(P(i)+0) = 0`，`半字(P(i)+4) = 0`，`半字(P(i)+6) = 0`。

循环完成后执行前段已经证明的对象 `+262` 标志变换和对象 `+250` 清零。

### 3.3 返回值闭合

- 入口第二参数非零的四项快照复核：四项全等返回 `0`，任一不等经本段返回 `1`。

  先把返回值设为 `1`；四项全等保持一，任一不等由本段再次置一，因此返回 `1`。
