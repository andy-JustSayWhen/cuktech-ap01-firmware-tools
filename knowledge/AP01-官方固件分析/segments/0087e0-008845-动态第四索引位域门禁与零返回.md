# `0x0087e0..0x008845` 动态第四索引位域门禁与零返回

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段以对象 `+264` 字节为编号，从对象 `+232` 起的半字数组动态选择第四个索引，再读取
该索引记录偏移 `+22` 半字。它按三位模式选择低 7 位、低 3 位或低 4 位门禁；模式
`5..7` 且低 4 位恰为一时，还要求第 14 位未置一。任何被判为失败的路径都把返回值设为
零并在本段恢复现场；其余路径进入下一段继续检查对象标志和记录偏移 `+20` 半字。

## 3. 动态记录门禁

令：

- `j = 对象字节[+264]`；
- `I = 对象半字[+232 + 2j]`；
- `H = 对象半字[20I + 22]`；
- `M = H[13:11]`。

本段返回零的条件为以下任一项：

- `M` 为 `0/1` 且 `H[6:0] == 0`；
- `M` 为 `2/3` 且 `H[2:0] == 0`；
- `M` 为 `4` 且 `H[3:0] == 0`；
- `M` 为 `5..7` 且 `H[3:0] == 0`；
- `M` 为 `5..7`、`H[3:0] == 1` 且 `H[14] == 1`。

其余情况进入 `0xa0007846`。模式 `4` 与模式 `5..7` 的零字段条件相同，但后者多一条
“低四位为一且第十四位置一”的失败条件，因此保留分开表述。

## 4. 能力边界

- 已闭合：102 个源字节、31 条指令、动态索引地址、记录半字读取、八种模式的字段选择、

- 动态选择字节是否受半字数组长度约束，本段没有显式检查。
- 本函数继续于执行地址 `0xa0007846`、文件偏移 `0x008846`。
