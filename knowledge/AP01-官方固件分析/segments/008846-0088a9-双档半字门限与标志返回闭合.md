## 3. 门限选择与最终结果

沿用前段动态记录半字 `H`、模式 `M = H[13:11]`，令
`V = 动态索引记录偏移 +20 的无符号半字`。

在前段所有门禁通过、入口对象字节 `+262` 第五位未置一时，以下情况选择高门限
`T = 6552`：

- `M` 为 `0/1` 且 `H[6:0] <= 2`；
- `M` 为 `2/3`、`H[2:0] <= 2` 且 `H[4:3] == 0`；
- `M` 为 `4..7`、`H[3:0] <= 2` 且 `H[6:4] == 0`。

其余通过前段门禁的情况选择低门限 `T = 654`。

- 若入口对象字节 `+262` 第五位已置一：直接成功；
- 否则仅当 `V > T` 时成功；
- 成功：`对象字节[+262] = 入口原值 | 0x04`，返回 `1`；
- 失败：`对象字节[+262] = 入口原值 & 0xfb`，返回 `0`。
