## 3. 当前项关系

令当前循环编号为 `i`：

- `J = 第二关联对象半字[+232 + 2i]`；
- `H = 第二关联对象半字[20J + 22]`；
- `W = (H & 0x3fff) | 0x40000000`；
- `M = H[13:11]`。

后续比较值 `C` 在本段被准备为：

- `M = 2/3`：`C = H[4:3]`；
- `M = 4`：`C = H[6:4]`；
- `M = 5..7`：`C = H[6:4]`；
- `M = 0/1`：直接跳过本段的比较值路径。

模式 `5..7` 还先清第二快照当前字第 16、17 位，然后：

- 若 `H[10:9] == 2`，置第 17 位；否则置第 16 位；
- 若 `H[14] == 1`，当前直行路径置第 18 位；若为零，跳到后方清位路径，尚待顺序闭合。
