# `0x008c86..0x008d09` 零组功率表读取与动态上限选择

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段从规范化后的共同入口读取一个全局状态字节和一个全局指针。规范组号为零时，它从
`0x62fc300c` 的第零行按组内编号读取有符号字节并乘四，再根据全局状态定位八字节记录，
从记录的两个候选字段中择一；记录标志非零时返回基础值与候选值的较小者，否则返回基础值。
`0x62fc300c` 对象的唯一身份原文见
[`0x003b20..0x003b53` 分模式发射功率与晶振标志](003b20-003b53-分模式发射功率与晶振标志.md)，

## 3. 零组返回关系

令规范组内编号为 `N`，全局状态字节为 `Q`，全局地址 `0x62fc57a8` 保存的指针为 `P`：

- `基础表索引 = N <= 3 ? N : 3`；
- `B = 有符号字节(0x62fc300c + 基础表索引) × 4`；
- `R = P + (Q + 21) × 8`；
- `N <= 1` 时，`C = 有符号字节(R + 20) × 4`；否则
  `C = 有符号字节(R + 21) × 4`；
- 若 `无符号字节(R + 19)` 非零，返回 `B` 与 `C` 的较小值截成无符号字节；否则返回
  `B` 截成无符号字节。
