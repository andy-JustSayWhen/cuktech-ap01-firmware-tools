# `0x008de8..0x008e37` 双字状态循环右移混合器

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个独立的双字状态混合函数。它读取输入对象开头两个 32 位状态字，把第二参数
异或进第一状态字，依次执行循环右移、异或、加法和相邻字节交换，最后把两个新状态字
写回原对象。

`th.srri` 的精确动作已由 QEMU（按指令模拟处理器的软件）上游实现固定：它是 32 位
循环右移指令的另一种编码，证据为提交 `3e3ccab106f879b1512f8e0d51a827dd4de30e22` 的
[`trans_xthead.c.inc` 第 140 至 145 行](https://github.com/qemu/qemu/blob/3e3ccab106f879b1512f8e0d51a827dd4de30e22/target/riscv/tcg/insn_trans/trans_xthead.c.inc#L140-L145)。

## 3. 完整算式

所有加法均按 32 位自然回绕。令入口状态为 `A`、`B`，输入值为 `X`，`右循(V,n)`
表示把 32 位值 `V` 循环右移 `n` 位：

- `X1 = X 异或 A`；
- `B1 = B 异或 右循(X1, 15)`；
- `X2 = X1 + B1`；
- `S = ((X2 >> 8) & 0x00ff00ff) | ((X2 << 8) & 0xff00ff00)`；
- `T1 = S 异或 B1`，`X3 = X2 + T1`；
- `T2 = 右循(X3, 29) 异或 T1`，`X4 = X3 + T2`；
- `T3 = 右循(X4, 2) 异或 T2`，`X5 = X4 + T3`；
- 写回 `对象+0 = X5`、`对象+4 = T3`。

## 4. 能力边界

- 已闭合：80 个源字节、31 条指令、专用循环右移语义、三轮混合、相邻字节交换和双字写回。
- 本段没有读取或写入对象 `+8` 以后字段，也没有返回计算值。
- 尚未凭算式为该混合器附加散列、校验或随机数等业务名称；其用途需由调用者继续闭合。
