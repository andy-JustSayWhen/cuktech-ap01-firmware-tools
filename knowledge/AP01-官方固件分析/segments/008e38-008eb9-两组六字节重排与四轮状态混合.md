# `0x008e38..0x008eb9` 两组六字节重排与四轮状态混合

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是前一双字状态混合器的直接调用者。它从两组六字节输入各读三个无符号半字，按
跨输入边界的顺序拼成三个 32 位值；随后把初始对象的两个状态字复制到输出对象，清零
输出 `+8` 的字和 `+12` 的字节，再依次混入三个拼接值与一个三位选择值。

## 3. 拼接与调用顺序

令第一组六字节的三个半字为 `A0、A1、A2`，第二组为 `B0、B1、B2`：

- `V1 = A0 | (A1 << 16)`；
- `V2 = A2 | (B0 << 16)`；
- `V3 = B1 | (B2 << 16)`；
- `V4 = 选择值为255 ? 0 : (选择值 & 7)`。

输出对象先取得初始对象的 `+0`、`+4` 两个状态字，随后按 `V1、V2、V3、V4` 的顺序
四次调用前段混合器；每一次都在上一次写回的双字状态上继续混合。
