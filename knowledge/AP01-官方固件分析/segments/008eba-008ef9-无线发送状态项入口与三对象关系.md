# `0x008eba..0x008ef9` 无线发送状态项入口与三对象关系

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是新大型函数入口。它按输入编号定位 `0x62fd8248` 起始、每项 72 字节的无线发送
状态项，读取状态项 `+32`、`+40` 的两个对象地址，再从第二个对象 `+88` 取得第三个
对象地址。状态项 `+65` 字节等于 `1` 时进入当前直行路径，否则跳往后方另一主路径。

72 字节状态项的唯一入口门禁原文见
[`0x00676a..0x00679b` 无线发送待处理位消费与函数闭合](00676a-00679b-无线发送待处理位消费与函数闭合.md)；
本文沿用该地址关系，不重复定义结构名称。

## 1. 覆盖范围

## 3. 对象关系

令入口编号为 `I`：

- `状态项 E = 0x62fd8248 + 72 × I`；
- `第一关联对象 A = 读取32位字(E + 40)`；
- `第二关联对象 B = 读取32位字(E + 32)`；
- `第三关联对象 C = 读取32位字(A + 88)`；
- `无符号字节(E + 65) == 1` 时进入 `0xa0007efa`，否则进入 `0xa0007fd0`。

## 4. 能力边界

- 已闭合：64 个源字节、22 条指令、状态项地址、三个关联对象来源和双主路径分流。
- 当前段只证明地址关系；三个关联对象的完整结构边界和正式名称仍需沿后续读写继续闭合。
- 本大型函数继续于执行地址 `0xa0007efa`、文件偏移 `0x008efa`。
