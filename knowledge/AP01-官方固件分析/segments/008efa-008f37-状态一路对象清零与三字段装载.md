# `0x008efa..0x008f37` 状态一路对象清零与三字段装载

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是状态项 `+65` 等于 `1` 的主路径前半。它清零第一关联对象和第三关联对象的三个
字段，并把第三关联对象 `+56` 设为 `256`。第二关联对象 `+8` 半字的 `0x0002` 位非零
时，再从第一关联对象 `+84` 所指对象向第三关联对象装载三个字段；最后读取第一关联对象
`+28` 半字的 `0x2000` 位，为后续两种门禁位选择分流。

## 3. 直行字段关系

沿用入口文档的第一关联对象 `A`、第二关联对象 `B`、第三关联对象 `C`，并令
`D = 读取32位字(A + 84)`：

- 无条件执行 `A[+48] = 0`、`A[+80] = 0`、`C[+8] = 0`、`C[+56] = 256`；
- 若 `读取无符号半字(B + 8) & 0x0002` 为零，则跳过本段后半的三字段装载；
- 否则 `C[+32] = D[+60]`、`C[+36] = D自身地址 + 4`、`C[+52] = D[+56]`；
- 随后以 `A[+28]` 半字的 `0x2000` 位，决定后续从第五关联对象选择哪一个门禁位。
