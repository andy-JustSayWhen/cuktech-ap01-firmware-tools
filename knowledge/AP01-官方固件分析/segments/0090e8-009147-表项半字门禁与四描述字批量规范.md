# `0x0090e8..0x009147` 表项半字门禁与四描述字批量规范

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是前一描述字规范函数的批量调用者。它按输入对象 `+33` 字节索引
`0x62fd61a0` 起始、每项 1128 字节的表，读取表项 `+1118` 半字。该半字等于 `1023`
时直接返回；否则以输入对象 `+88` 所指对象 `+24` 字为第二参数、表半字为第三参数，
依次规范输入对象 `+84` 所指区域 `+24` 至 `+36` 的四个连续描述字。

## 3. 批量调用关系

令入口对象为 `O`，`J = 无符号字节(O + 33)`，
`E = 0x62fd61a0 + 1128 × J`：

- 若 `无符号半字(E + 1118) == 1023`，不修改任何描述字并返回；
- 否则令 `A = 读取32位字(O + 84)`、`B = 读取32位字(O + 88)`；
- 对 `A + 24、A + 28、A + 32、A + 36` 四个地址，按顺序调用
  `0xa0008058(当前地址, 读取32位字(B + 24), 无符号半字(E + 1118))`。
