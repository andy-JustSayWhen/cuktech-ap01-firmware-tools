# `0x0091e0..0x00923d` 选择值偏移表与三寄存器共同更新

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是四路寄存器配置函数的共同后半。它读取 `0x24b00120`，加上运行时地址
`0x62fd73d0` 按选择值索引的 32 位偏移，再写入 `0x24b00128 + 4 × 选择值`。同时生成
`1 << 选择值`，把它写入 `0x24b08088` 并合入 `0x24b0808c`。选择值按有符号数大于
`9` 时，会先以固定地址和固定数值调用后方函数，但仍继续全部寄存器写入。

## 3. 共同更新公式

令保存的选择值为 `K`：

- `B = 读取32位字(0x24b00120)`；
- `D = 读取32位字(0x62fd73d0 + 4 × K)`；
- `M = 1 << K`；
- 写 `读取目标地址 = 0x24b00128 + 4 × K`，`该地址内容 = B + D`；
- 写 `0x24b08088 = M`；
- 写 `0x24b0808c = 原值 | M`。

其中移位和地址计算遵循 32 位指令行为。前段常规选择值为 `0..3`；越界路径可能把其他
值带到这里，不能把全部输入行为简化为四路表格。

## 4. 能力边界

- 已闭合：94 个源字节、27 条指令、偏移表读取、目标地址公式、选择值越界调用和三项
  寄存器写入。
- 运行时偏移表 `0x62fd73d0` 的初始化与业务名称尚未由当前顺序范围闭合。
- 选择值零、一和越界分支尾仍位于后方，整个函数尚未闭合。
- 本函数继续于执行地址 `0xa000823e`、文件偏移 `0x00923e`。
