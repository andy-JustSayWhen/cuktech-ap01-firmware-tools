# `0x0093f0..0x00945b` 组合硬件事件与当前状态对象入口

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续处理入口读取的硬件状态字。仅当 `0x20000000` 或 `0x00000800` 至少一位置一
时进入当前处理；随后读取全局控制区 `+180` 次低位。该位为零时，使用全局 `+162`
字节编号定位 72 字节状态项；状态项 `+14` 字节为零时读取状态项 `+4` 保存的对象地址。
该地址为零会以固定地址和固定数值调用后方函数，但机器码随后仍顺序进入对象解引用路径，
因此本段不假设该调用是否返回。

## 3. 当前入口关系

令大型函数入口硬件状态字为 `H`，全局控制区为 `G = 0x62fd8454`：

- `H & 0x20000800` 为零时，当前组合事件路径完全跳过；
- 命中时若 `G[+180] & 2` 非零，进入尚待顺序覆盖的专用路径；
- 否则令 `I = 无符号字节(G + 162)`，`E = 0x62fd8248 + 72 × I`；
- `E[+14]` 非零时进入另一后方专用路径；
- `E[+14]` 为零时令 `O = 读取32位字(E + 4)`；若 `O == 0`，先执行固定参数调用，
  然后仍顺序进入后续 `O` 的使用位置。

## 4. 能力边界

- 已闭合：108 个源字节、29 条指令、组合事件掩码、全局控制位、状态项地址、状态字节
  分流、对象地址读取和固定参数调用。
- 后方调用是否返回尚无当前函数内证据；不能用其后的空地址解引用反推调用必不返回。
- 三个后方专用路径及当前对象处理均尚未顺序闭合。
- 本函数继续于执行地址 `0xa000845c`、文件偏移 `0x00945c`。
