# `0x0096aa..0x0096ef` 空状态项事件清位与共同返回

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是五位事件处理的当前直行返回路径。它检查当前状态项 `+14` 字节和 `+4` 对象地址；
两者都为零时清状态项首字，从 `0x24b0808c` 清除当前编号位值 `1 << 编号`，并向
`0x24b08088` 写该位值。随后恢复入口保存的全部寄存器并返回。前方五位事件组全零也
直接复用同一现场恢复。

## 3. 当前返回条件与结果

令当前编号为 `I`，当前状态项为 `E`，编号位值为 `M = 1 << I`：

- 若 `E[+14] != 0` 或 `E[+4] != 0`，分别跳往后方专用路径，不执行当前清位；
- 若两者都为零，执行 `E[+0] = 0`；
- `0x24b0808c = 原值 & ~M`；
- `0x24b08088 = M`；
- 恢复现场并返回。
