# `0x0098ea..0x009917` 空节点状态清位与条件发送处理

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段承接首节点地址为空的分支。它清除当前状态项首字，在硬件位图中清当前事件位并写入
同一事件位作为确认；随后仅在状态字节等于 `1` 且状态项 `+32` 非空时，以事件编号调用
已经在前文完整闭合的发送处理函数。

## 1. 覆盖范围

- 文件偏移：`0x0098ea..0x009917`
- 执行地址：`0xa00088ea..0xa0008917`
- 长度：46 字节
- 本段原始字节散列：`a7dedaae49855f8137105b4c686291eb76afed4b1d3d77c482cacf43cd11eb9f`

## 3. 精确状态关系

令当前状态项为 `E`、事件编号为 `I`、事件位为 `M = 1 << I`：

- 无条件执行 `E[+0] = 0`；
- 执行 `读取32位字(0x24b0808c) &= ~M`，并写回同一地址；
- 执行 `写入32位字(0x24b08088, M)`；
- 仅当 `E[+68] == 1` 且 `E[+32] != 0` 时调用 `0xa0007eba(I)`；该目标函数已在
  [`008eba-009057 无线发送处理函数`](008eba-008ef9-无线发送状态项入口与三对象关系.md)
  至其后连续分段中完整闭合。
