# `0x009918..0x009941` 负值位门禁与定长记录基础值保存

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段检查前方保存的下游负值是否包含 `0x00800000` 位。该位为一且状态对象 `+34`
字节不大于 `3` 时，按每项 560 字节定位运行时记录，把硬件寄存器 `0x24b00120`
的当前值保存到该记录 `+552`。

## 1. 覆盖范围

- 文件偏移：`0x009918..0x009941`
- 执行地址：`0xa0008918..0xa0008941`
- 长度：42 字节
- 本段原始字节散列：`b285ed9875b9e62afd2a1852b57554fbd0896f87abcb1b5424d0e6939b6a0860`

| `0xa0008918` | `00800737` | 准备位值 `0x00800000`。 |
| `0xa000891c` | `00ec7733` | 从前方保存的下游负值中提取该位。 |
| `0xa0008920` | `c30d` | 该位为零时跳到后方共同状态处理。 |
| `0xa0008922` | `022ac703` | 读取状态对象 `+34` 的无符号字节。 |

## 3. 精确寻址关系

令前方保存的下游负值为 `V`、状态对象为 `O`、`K = O[+34]`：

- `V & 0x00800000 == 0` 时不写记录；
- `K > 3` 时不写记录；比较按无符号字节进行；
- 其余情况执行
  `写入32位字(0x62fd4a10 + 560 × K + 552, 读取32位字(0x24b00120))`。
