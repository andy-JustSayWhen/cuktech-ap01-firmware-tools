# `0x009ac4..0x009b13` 双寄存器轮询与编号函数表调用

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

这是一个完整独立函数。它反复读取固定地址 `0x24910000` 和 `0x24910004`；两者都为零时
调用固定后方函数并恢复现场返回。任一非零时，它读取 `0x24910040` 的编号，只有编号落在
`10..63` 时才从固定表读取函数地址；表项非零则调用该地址，然后继续轮询。

## 3. 完整控制关系

令 `A = 读取32位字(0x24910000)`、`B = 读取32位字(0x24910004)`、
`I = 读取32位字(0x24910040)`：

- 若 `A == 0 && B == 0`，调用 `0xa018ab50()` 一次，然后恢复现场返回；
- 否则仅当无符号关系 `I - 10 <= 53` 成立，也就是 `10 <= I <= 63` 时，读取
  `F = 读取32位字(0xa053db38 + 4 × I)`；
- `F != 0` 时调用 `F()`；范围无效、表项为空或表项调用返回后，都重新读取 `A` 和 `B`；
- 当前函数自身不改变三个固定寄存器，也没有固定循环次数上限。
