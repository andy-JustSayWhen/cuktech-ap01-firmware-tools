## 3. 完整状态关系

令第一输入对象为 `X`、第二输入参数为 `I`、`V = X[+60]`：

- `V >= 0` 时直接返回；
- `V < 0 && (V & 0x00010000) == 0` 时调用 `0xa0164394(0xa053edd0, 3178)` 后返回；
- `V < 0 && (V & 0x00010000) != 0` 时，令 `Y = X[+36]`，执行
  `X[+60] = 0`、`Y[+20] = (Y[+20] & 0xfffe3fff) | 0x00004000`，再调用
