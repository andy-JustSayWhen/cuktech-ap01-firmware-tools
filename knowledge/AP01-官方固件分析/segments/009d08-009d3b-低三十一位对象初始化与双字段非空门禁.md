# `0x009d08..0x009d3b` 低三十一位对象初始化与双字段非空门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段把运行时字 `0x62fd8634` 的低 31 位直接作为对象地址，先以该地址调用后方函数，
再把对象 `+152` 字节置一。随后读取对象 `+48` 半字和 `+28` 的 32 位地址；半字为零或
地址为空时分别跳到两个靠后的专用分支，二者都非零时才顺序进入对象内容解析。

## 3. 精确对象关系

令 `W = 读取32位字(0x62fd8634)`、`X = W & 0x7fffffff`：

- 无条件调用 `0xa015c75e(X)`，随后执行 `X[+152] = 1`；
- 读取 `X[+48]` 的半字和 `X[+28]` 的 32 位地址；
- `X[+48] == 0` 时跳到 `0xa0009156`；
- `X[+48] != 0 && X[+28] == 0` 时带已装入的固定数值 `399` 跳到 `0xa0009162`；
- 两项均非零时从 `0xa0008d3c` 继续。
