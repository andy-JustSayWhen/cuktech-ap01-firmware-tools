# `0x009d3c..0x009d67` 关联半字双类型分流与对象双位门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段沿当前对象 `+28`、再沿该对象 `+8` 取得一个地址，读取其起始半字并只保留
`0x00fc` 位。结果等于 `36` 时进入第一后方分支；等于 `148` 时还必须满足当前对象
`+84` 字的 `0x00002002` 两位都为一，才能顺序进入第二分支；其他情况进入公共收尾。

## 3. 精确分流关系

令当前对象为 `X`、`Y = X[+28]`、`Z = Y[+8]`、
`C = 读取16位无符号数(Z) & 0x00fc`、`V = X[+84]`：

- `C == 36` 时跳到 `0xa0008f28`；
- `C == 148 && (V & 0x00002002) == 0x00002002` 时从 `0xa0008d68` 继续；
- 其余情况均跳到公共收尾 `0xa0008e7c`。
