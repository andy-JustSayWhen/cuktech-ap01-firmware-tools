# `0x009e3c..0x009e7b` 缓冲项三类长度判定与动态表索引

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是缓冲扫描循环的分类入口。剩余长度大于一时，它把当前位置前两个字节组成小端半字：
低 11 位等于 `2045` 时选择长度 `12`，`0x0800` 位非零时选择长度 `2`；否则要求剩余
长度大于三，再读取后两个字节，从其第 1 至 3 位索引固定字节表 `0xa053cfa0`，表值加四
形成动态长度。动态长度不超过剩余长度时才进入统一项目处理。

## 3. 三类长度公式

令扫描地址为 `P`、剩余长度为 `N`、`W = P[0] | (P[1] << 8)`：

- `N <= 1` 时结束扫描；
- 若 `W & 0x07ff == 2045`，项目长度 `L = 12`；
- 否则若 `W & 0x0800 != 0`，项目长度 `L = 2`；
- 否则要求 `N > 3`，令 `H = P[2] | (P[3] << 8)`；`P[2] & 0x08 != 0` 时结束扫描；
- 其余情况 `L = 读取8位无符号数(0xa053cfa0 + ((H >> 1) & 0x7)) + 4`；
- 动态分支仅在 `N >= L` 时进入统一项目处理 `0xa0008ec0`，否则结束扫描。
