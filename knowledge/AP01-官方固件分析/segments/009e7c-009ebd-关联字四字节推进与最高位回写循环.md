# `0x009e7c..0x009ebd` 关联字四字节推进与最高位回写循环

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是多条解析路径汇入的共同更新。它把关联对象 `+12` 字清最低两位后加四，生成候选值；
候选等于运行时地址 `0x62fd8630` 的字时改用 `0x62fd862c`。随后把候选写入当前对象 `+148`，
按候选与 `0x62fd8634` 当前低 31 位的无符号大小关系决定是否翻转原最高位，拼接写回，
调用当前对象后回到函数入口的硬件值比较。

## 3. 精确更新公式

令当前对象为 `X`、关联对象为 `Y = X[+28]`：

- 先计算 `C = (Y[+12] & 0xfffffffc) + 4`；
- 若 `C == 读取32位字(0x62fd8630)`，则改令 `C = 读取32位字(0x62fd862c)`；
- 写 `X[+148] = C`；
- 令 `W = 读取32位字(0x62fd8634)`、`T = W & 0x80000000`；若无符号关系
  `C < (W & 0x7fffffff)`，则 `T = T ^ 0x80000000`；
- 写 `读取32位字(0x62fd8634) = C | T`，调用 `0xa015c4c2(X)`，然后重新进入入口比较。
