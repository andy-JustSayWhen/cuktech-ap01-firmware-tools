# `0x009f08..0x009f27` 另一缓冲分类三项门禁与十字节复制

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段处理前方缓冲分类不等于 `22` 的另一分支。它要求当前对象 `+84` 字的 `0x200` 位
为零、当前对象 `+48` 半字等于 `28`、前方缓冲半字高四位等于返回对象 `+13` 字节；
三项同时命中后，固定从缓冲区 `+18` 复制 10 字节到返回对象 `+228`，再回接前段已闭合的
对象指针写入与半字置位。

## 3. 精确门禁与回接

令当前对象为 `X`、返回对象为 `R`、缓冲区为 `B`、前方组合的缓冲半字为 `W`：

- 只有 `(X[+84] & 0x200) == 0`、`X[+48] == 28`、`(W >> 12) == R[+13]` 三项
  同时成立，才进入复制；
- 复制参数为目标 `R + 228`、源 `B + 18`、长度 `10`；
- 回接前段后执行 `R[+224] = R + 228` 和 `R[+8] = R[+8] | 0x40`，再进入共同更新；
- 任一门禁失败都直接进入共同运行时更新 `0xa0008e7c`。
