# `0x009fbc..0x009feb` 记录半字写入与第二记录地址硬件门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段承接选中 560 字节记录的非回退路径。它把记录 `+40` 半字写入全局对象 `+156`，
再用前段读取的记录 `+32` 字节索引每项 1128 字节的表 `0x62fd61a0`，要求所得记录地址
等于全局对象 `+16` 保存的地址。地址匹配后，还要求硬件寄存器 `0x24b08354` 低六位按
无符号数大于 `9`，才能进入后续硬件字段处理。

## 1. 覆盖范围

- 文件偏移：`0x009fbc..0x009feb`
- 执行地址：`0xa0008fbc..0xa0008feb`
- 长度：48 字节
- 本段原始字节散列：`108cbd0f3d2619738d6f2069e086a549b39f5753e2aafb1256b9cfb5d34512ec`

## 3. 精确门禁关系

令前段选中的 560 字节记录为 `D`、全局对象为 `G = 0x62fd8454`：

- 执行 `G[+156] = D[+40]`，读取与写入均为半字；
- 令 `E = 0x62fd61a0 + 1128 × D[+32]`，要求 `G[+16] == E`；
- 地址不等时进入共同运行时更新；
- 地址相等后令 `H = 读取32位字(0x24b08354) & 0x3f`，仅当 `H > 9` 时从
  `0xa0008fec` 继续，`H <= 9` 时进入共同更新。

## 4. 能力边界

- 已闭合：48 个源字节、13 条指令、记录半字写入、第二记录地址公式、地址相等门禁、
  硬件低六位提取与无符号门限。
- 后续硬件字段处理尚未闭合；两张记录表之间的业务关系不由当前地址相等判断命名。
- 本函数继续于执行地址 `0xa0008fec`、文件偏移 `0x009fec`。
