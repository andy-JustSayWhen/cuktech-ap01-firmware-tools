# `0x00a05e..0x00a07d` 硬件负值轮询与低三位双路径分流

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段反复读取硬件寄存器 `0x24b08360`，直到读取值按有符号数为负；循环没有固定次数上限。
条件出现后重新读取该寄存器，只保留 `0x000ffffc` 位。随后以前段从第二硬件字提取的低三位
数值是否按无符号数大于 `2`，在两个后续计算路径之间分流。

## 1. 覆盖范围

- 文件偏移：`0x00a05e..0x00a07d`
- 执行地址：`0xa000905e..0xa000907d`
- 长度：32 字节
- 本段原始字节散列：`881e26a7e840345fcf1b13149f9dc7ed9ecac47a15504b6b57f70db4d7f44f90`

## 3. 精确轮询与分流

令 `H = 读取32位字(0x24b08360)`、前段第二硬件字低三位为 `I`：

- 循环读取 `H`，只要 `H >= 0` 就继续；本段没有超时计数或其他退出条件；
- 首次观察到 `H < 0` 后，再读取一次同一寄存器并计算 `V = H & 0x000ffffc`；
- `I <= 2` 时从 `0xa000907e` 继续，`I > 2` 时跳到 `0xa000911e`；
- 两条路径都会使用掩码结果 `V`，其具体计算尚待后续闭合。

## 4. 能力边界

- 已闭合：32 个源字节、10 条指令、硬件地址、有符号轮询、二次读取、精确掩码和无符号分流。
- 当前证据不说明硬件负值出现的外部条件，也没有证明轮询时限。
- 本函数继续于执行地址 `0xa000907e`、文件偏移 `0x00a07e`。
