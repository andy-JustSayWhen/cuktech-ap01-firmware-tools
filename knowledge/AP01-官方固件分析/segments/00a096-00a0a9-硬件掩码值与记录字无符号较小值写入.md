# `0x00a096..0x00a0a9` 硬件掩码值与记录字无符号较小值写入

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是前方低三位两条路径的共同入口。它读取全局对象 `+140` 所指记录的 `+12` 字，
与硬件寄存器 `0x24b08360` 二次读取后的 `0x000ffffc` 掩码结果做无符号比较，选择两者
较小值写入全局对象 `+148`。同时把第一硬件字第 19 位加一结果左移九位，把第一硬件字
第 16 至 17 位左移七位，为后续位组合准备。

## 1. 覆盖范围

- 文件偏移：`0x00a096..0x00a0a9`
- 执行地址：`0xa0009096..0xa00090a9`
- 长度：20 字节
- 本段原始字节散列：`56d9e2bddf0e6835252c3552df71206dcbb61a2a3976494709f9879dcaaf1cf9`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa0009096` | `00c82703` | 读取全局对象 `+140` 所指记录的 `+12` 字。 |
| `0xa000909a` | `0926` | 把第一硬件字第 19 位加一结果左移九位。 |
| `0xa000909c` | `061e` | 把第一硬件字第 16 至 17 位左移七位。 |
| `0xa000909e` | `00e6b5b3` | 比较硬件掩码结果是否按无符号数小于记录字。 |
| `0xa00090a2` | `42b6970b` | 比较成立时用硬件掩码结果替换记录字，得到无符号较小值。 |
| `0xa00090a6` | `08e4aa23` | 把无符号较小值写入全局对象 `+148`。 |

## 3. 精确关系

令全局对象为 `G = 0x62fd8454`、`E = G[+140]`、
`A = 读取32位字(0x24b08360) & 0x000ffffc`、`B = E[+12]`：

- 写 `G[+148] = 无符号较小值(A, B)`；
- 同时准备 `P = (第一硬件字第 19 位 + 1) << 9`；
- 准备 `Q = 第一硬件字第 16 至 17 位 << 7`；
- 两个移位结果只为后续组合保留，当前段尚未写入内存。

## 4. 能力边界

- 已闭合：20 个源字节、6 条指令、记录字段来源、无符号比较、条件替换、写入地址和两项移位。
- 较小值及移位字段的业务身份尚未由当前范围确定。
- 本函数继续于执行地址 `0xa00090aa`、文件偏移 `0x00a0aa`。
