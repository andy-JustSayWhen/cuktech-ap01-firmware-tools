# `0x00a0ee..0x00a11d` 硬件高字节全局写入与记录关联半字提交

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合第二硬件字低三位不大于二的当前路径。它把硬件寄存器 `0x24b08364` 最高字节
左移六位并把低位固定为 `19`，写入全局对象 `+144`。随后重新按前段索引选择 560 字节
记录，把该记录地址写入全局对象 `+140` 并清全局对象 `+176`；最后沿记录 `+324` 地址，
把前段两个拼接半字写入其 `+222`、`+228`，并把全局对象 `+170` 字节写入记录 `+29`。

## 1. 覆盖范围

- 文件偏移：`0x00a0ee..0x00a11d`
- 执行地址：`0xa00090ee..0xa000911d`
- 长度：48 字节
- 本段原始字节散列：`318fa8f79c0cc3dc5af8c1c29b8296b9ff8158eef6b84b03accf027ff2932d89`

## 3. 精确写入关系

令全局对象为 `G = 0x62fd8454`、前段八位索引为 `I`、
选中记录 `D = 0x62fd4a10 + 560 × I`、关联对象 `Z = D[+324]`，两个前段拼接值为 `P`、`Q`：

- 写 `G[+144] = ((读取32位字(0x24b08364) >> 24) << 6) | 19`；
- 写 `G[+176] = 0`、`G[+140] = D`；
- 写半字 `Z[+222] = P`、`Z[+228] = Q`；
- 写字节 `D[+29] = G[+170]`；
- 全部写入完成后进入共同运行时更新，随后重新比较硬件状态。

## 4. 能力边界

- 已闭合：48 个源字节、14 条指令、硬件高字节组合、记录重选、全局字段、关联地址、
  两个半字与一个字节写入及回接。
- 三类对象字段的业务身份尚未由当前范围确定；当前段不推断关联对象生命周期。
- 本函数继续于执行地址 `0xa000911e`、文件偏移 `0x00a11e`。
