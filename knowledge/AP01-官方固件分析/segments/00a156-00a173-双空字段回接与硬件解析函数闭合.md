# `0x00a156..0x00a173` 双空字段回接与硬件解析函数闭合

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合大型函数入口处对象 `+48` 半字或 `+28` 地址为空的后方分支。半字为零且地址也
为空时，以“当前对象地址加 156”为候选值回接共同更新；半字为零但地址非空时，执行固定
参数 `441` 的调用；仅地址为空时复用前方准备的固定参数 `399`，进入同一固定调用。
固定调用后重新回到硬件值比较入口。其后出现新函数栈帧，因此本大型函数完整闭合。

## 3. 两个空字段分支

令当前对象为 `X`、`Y = X[+28]`：

- 前方 `X[+48] == 0` 时来到 `0xa0009156`；若同时 `Y == 0`，以 `X + 156` 为候选值
  回接共同更新，然后继续硬件比较循环；
- `X[+48] == 0 && Y != 0` 时调用 `0xa0164394(0xa053c8b8, 441)`；
- 前方 `X[+48] != 0 && Y == 0` 时直接跳到 `0xa0009162`，此时第二参数已经是 `399`，
  因此调用 `0xa0164394(0xa053c8b8, 399)`；
- 两类固定调用都重新进入硬件比较循环。
