# `0x00a246..0x00a265` 原标志位索引定长记录双字节清零门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段承接输入对象原 `+40` 字的 `0x00800000` 位非零路径。它用对象 `+33` 字节按每项
1128 字节索引运行时表 `0x62fd61a0`；只有选中记录 `+94` 字节为零且 `+96` 字节非零时，
才把记录 `+112` 字节清零。其余情况不写记录，全部在下一地址会合。

## 3. 精确记录关系

令输入对象为 `X`、索引 `I = X[+33]`、选中记录
`D = 0x62fd61a0 + 1128 × I`：

- 当前入口已保证对象原 `+40` 字的 `0x00800000` 位非零；
- 仅当 `D[+94] == 0 && D[+96] != 0` 时执行 `D[+112] = 0`；
- 三个记录字段均按字节宽度访问；
- 无论是否清零，均在执行地址 `0xa0009266` 继续。
