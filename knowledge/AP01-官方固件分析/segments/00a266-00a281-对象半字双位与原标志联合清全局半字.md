# `0x00a266..0x00a281` 对象半字双位与原标志联合清全局半字

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段读取输入对象 `+28` 半字。其 `0x08` 位为零时跳到后方另一尾路；该位非零时继续
检查 `0x20` 位。只有 `0x20` 位也非零，且函数入口保存的对象原 `+40` 字
`0x00800000` 位为零时，才把全局地址 `0x62fd6f22` 的半字清零。

## 1. 覆盖范围

- 文件偏移：`0x00a266..0x00a281`
- 执行地址：`0xa0009266..0xa0009281`
- 长度：28 字节
- 本段原始字节散列：`ac70ae6b3d5e3adf7cf5b391db72eb5626db68ef48181bc51b20294192c078d0`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa0009266` | `01c4d783` | 读取输入对象 `+28` 的无符号半字。 |
| `0xa000926a` | `0087f713` | 提取该半字的 `0x08` 位。 |
| `0xa000926e` | `c33d` | `0x08` 位为零时跳到执行地址 `0xa00092d4`。 |
| `0xa0009270` | `0207f793` | `0x08` 位非零时提取同一半字的 `0x20` 位。 |
| `0xa0009274` | `c799` | `0x20` 位为零时跳过全局半字清零。 |
| `0xa0009276` | `000a1663` | 对象原 `+40` 字的 `0x00800000` 位非零时也跳过清零。 |
| `0xa000927a` | `62fd77b7` | 两项位门禁通过时准备全局半字地址的高位。 |
| `0xa000927e` | `f2079123` | 把全局地址 `0x62fd6f22` 的半字清零。 |

## 3. 精确联合门禁

令输入对象为 `X`、半字 `H = X[+28]`、入口保存位
`A = 原X[+40] & 0x00800000`：

- `H & 0x08 == 0` 时跳到 `0xa00092d4`；
- `H & 0x08 != 0` 时，仅当 `(H & 0x20) != 0 && A == 0` 才写
  `读取16位无符号数(0x62fd6f22) = 0`；
- `0x20` 位为零或原标志位非零时不写该全局半字，从 `0xa0009282` 继续。

## 4. 能力边界

- 已闭合：28 个源字节、8 条指令、对象半字读取、两位门禁、原标志联合条件、全局地址
  与半字写入宽度。
- 两条后方路径和尚未命名的全局半字用途需由后续顺序范围闭合。
- 本函数继续于执行地址 `0xa0009282`、文件偏移 `0x00a282`。
