# `0x00a2d4..0x00a2e1` 半字清零尾回接与原双标志三路分流

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合对象 `+28` 半字 `0x08` 位为零的尾路：同一半字 `0x200` 位非零时直接回接
前段编号记录清零，位为零时进入共同分流。共同分流再按函数入口保存的对象原 `+40` 字
`0x40000000` 与 `0x00800000` 两位选择两个后方分支或当前直行路径。

## 1. 覆盖范围

- 文件偏移：`0x00a2d4..0x00a2e1`
- 执行地址：`0xa00092d4..0xa00092e1`
- 长度：14 字节
- 本段原始字节散列：`2ff747306dd10eacd62463a0b4299957efde0cfd92cc684241d78c55ef9d8a1f`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa00092d4` | `2007f793` | 在对象半字 `0x08` 位为零的路径提取同一半字 `0x200` 位。 |
| `0xa00092d8` | `f3ed` | `0x200` 位非零时回接 `0xa00092ba`，执行编号记录字节清零尾。 |
| `0xa00092da` | `0c090363` | 对象原 `+40` 字的 `0x40000000` 位为零时跳到 `0xa00093a0`。 |
| `0xa00092de` | `0c0a1363` | 原 `0x40000000` 位非零且原 `0x00800000` 位非零时跳到 `0xa00093a4`。 |

## 3. 精确分流关系

令对象 `+28` 半字为 `H`，入口保存位 `A = 原X[+40] & 0x40000000`、
`B = 原X[+40] & 0x00800000`：

- 当前尾路来自 `H & 0x08 == 0`；若 `H & 0x200 != 0`，只回接前段记录清零；
- 若不回接，则 `A == 0` 跳到 `0xa00093a0`；
- `A != 0 && B != 0` 跳到 `0xa00093a4`；
- `A != 0 && B == 0` 从 `0xa00092e2` 顺序继续。

- 三条原标志路径的动作尚待后续顺序闭合。
- 本函数继续于执行地址 `0xa00092e2`、文件偏移 `0x00a2e2`。
