# `0x00a2e2..0x00a303` 对象新字双位置一与编号哨兵分流

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段处理入口原 `0x40000000` 位非零、原 `0x00800000` 位为零的直行路径。它把前面已经
由对象 `+44` 半字左移生成的新 `+40` 字依次置 `0x02`、`0x01` 两位，把对象 `+36`
字节置一，并读取对象 `+34` 编号。编号等于 `255` 时跳到共同返回值路径，正常编号则进入
运行时记录计数处理。

## 1. 覆盖范围

- 文件偏移：`0x00a2e2..0x00a303`
- 执行地址：`0xa00092e2..0xa0009303`
- 长度：34 字节
- 本段原始字节散列：`2fbcc984c5943966c9b0832aa8926b44b82d73f29f6587862d55db130b7c6522`

## 2. 全部指令

| 地址 | 原始指令 | 作用 |
| --- | --- | --- |
| `0xa00092e2` | `549c` | 读取输入对象新 `+40` 的 32 位字。 |
| `0xa00092e4` | `4905` | 准备字节值 `1` 并保存供后续使用。 |
| `0xa00092e6` | `0027e793` | 把对象新字的 `0x02` 位置一。 |
| `0xa00092ea` | `d49c` | 把置位结果写回对象 `+40`。 |
| `0xa00092ec` | `549c` | 重新读取对象 `+40`。 |
| `0xa00092ee` | `0224c703` | 读取对象 `+34` 的无符号编号字节。 |
| `0xa00092f2` | `03248223` | 把对象 `+36` 字节置为 `1`。 |
| `0xa00092f6` | `0017e793` | 把对象新字的 `0x01` 位置一。 |
| `0xa00092fa` | `d49c` | 把第二次置位结果写回对象 `+40`。 |
| `0xa00092fc` | `0ff00793` | 准备编号哨兵值 `255`。 |
| `0xa0009300` | `06f70563` | 编号等于 `255` 时跳到共同返回值路径 `0xa000936a`。 |

## 3. 精确状态变换

令输入对象为 `X`、前段覆盖后的新字为 `W = X[+40]`、编号 `I = X[+34]`：

- 写 `X[+40] = W | 0x03`；
- 写 `X[+36] = 1`；
- `I == 255` 时跳到 `0xa000936a`；
- `I != 255` 时从 `0xa0009304` 继续，按编号处理运行时记录。

## 4. 能力边界

- 已闭合：34 个源字节、11 条指令、新对象字双位置一、对象字节置一、编号读取与哨兵分流。
- 正常编号的记录处理及哨兵返回值路径尚待后续顺序闭合。
- 本函数继续于执行地址 `0xa0009304`、文件偏移 `0x00a304`。
