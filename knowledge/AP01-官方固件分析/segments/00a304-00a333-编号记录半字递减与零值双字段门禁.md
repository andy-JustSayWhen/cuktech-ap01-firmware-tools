# `0x00a304..0x00a333` 编号记录半字递减与零值双字段门禁

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段按对象 `+34` 编号选择 560 字节运行时记录，把记录 `+50` 半字减一并写回。随后它
重新读取对象编号并重新定位记录；只有记录 `+48` 字节非零且记录 `+50` 半字为零时，
才顺序进入后方创建与提交路径。任一门禁不满足都跳到共同返回值路径。

## 3. 精确记录关系

令输入对象为 `X`、编号 `I = X[+34]`、记录 `D = 0x62fd4a10 + 560 × I`：

- 先执行 `D[+50] = 低十六位(D[+50] - 1)`；原值为零时会回绕到 `65535`；
- 随后重新读取 `I` 并重新计算 `D`，不假定对象编号在两次读取之间不变；
- 只有 `D[+48] != 0 && D[+50] == 0` 时从 `0xa0009334` 继续；
- 其余情况均跳到共同返回值路径 `0xa000936a`。
