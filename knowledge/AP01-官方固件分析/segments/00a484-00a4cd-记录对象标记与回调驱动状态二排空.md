## 3. 调用与循环公式

令前段 32 字节记录 `+28` 指针为 `P`，输入对象为 `X`。

首先调用：

`0xa00070d2(P, X[+44], 2)`

按已闭合的 [`0080d2-008125 无线发送十二位差值门限与回调定位写入`](0080d2-008125-无线发送十二位差值门限与回调定位写入.md)，该调用使用 `P[0]` 函数指针返回的偏移，把
值二写到 `P + 返回偏移 + 6`。

随后令已清理数量 `C = 0`，反复执行：

1. `L = P[+70]`；
2. 若 `P[L + 6] != 2`，以 `C` 的低 8 位作为后续状态值跳到 `0xa00093da`；
3. 否则写 `P[L + 6] = 0`；
4. 写 `P[+4] = (P[+4] + 1) & 0x0fff`；
5. 写 `C = 有符号8位(低8位(C + 1))`；
6. 调用 `P[0](P, 1)`，把返回值低 8 位写入 `P[+70]`，再回到第一步。

循环没有独立次数上限；退出条件完全取决于某次 `P[+70]` 所指位置 `+6` 字节不等于二。
