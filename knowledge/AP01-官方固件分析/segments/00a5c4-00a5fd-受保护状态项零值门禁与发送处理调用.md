返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa00095c4` 开始的完整独立函数。它保存处理器状态字并暂时清除
`0x08` 位，按输入编号选择 `0x62fd8248` 起始、每项 72 字节的状态项。只有状态项
`+68` 字节等于零且 `+32` 对象指针非零时，才调用已经完整闭合的无线发送处理函数；
随后无条件恢复原处理器状态字并返回。

## 3. 精确门禁与调用关系

令输入编号为 `I`，状态项 `E = 0x62fd8248 + 72 × I`：

- `E[+68] != 0`：不调用，直接恢复状态；
- `E[+68] == 0` 且 `字(E + 32) == 0`：不调用，直接恢复状态；
- `E[+68] == 0` 且 `字(E + 32) != 0`：调用 `0xa0007eba(I)`，再恢复状态；
- 调用目标的完整原文见 [`008eba-009057 无线发送处理函数`](008eba-008ef9-无线发送状态项入口与三对象关系.md) 及其连续分段。
