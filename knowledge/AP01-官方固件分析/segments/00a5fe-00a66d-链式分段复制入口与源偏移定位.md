# `0x00a5fe..0x00a66d` 链式分段复制入口与源偏移定位

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa00095fe` 开始的大型链式分段复制函数入口。六个参数依次保存为源链
首节点、复制长度、源偏移、目标链首节点、目标偏移和新节点取得参数。原厂先把“目标偏移
加复制长度”写入目标首节点 `+8`，再沿源链按每节点 `+4` 半字逐段扣除源偏移，定位包含
起始源位置的节点。随后计算目标当前节点从 `+6` 半字到 640 字节边界的容量：目标偏移在
当前容量内时可进入复制准备，否则转到后方的目标链推进路径。

## 1. 覆盖范围

- 文件偏移：`0x00a5fe..0x00a66d`
- 执行地址：`0xa00095fe..0xa000966d`

## 3. 参数与源链定位公式

令六个入口参数依次为：

- `S`：源链首节点；
- `L`：复制长度；
- `O`：源偏移；
- `D`：目标链首节点；
- `T`：目标偏移；
- `C`：后续取得新目标节点时使用的参数。

入口先写 `字(D + 8) = T + L`。

源定位反复执行：

1. 若当前 `S == 0`，停止源定位；
2. 计算 `r = O - 无符号半字(S + 4)`；
3. 若 `r < 0`，当前 `S` 包含源起点；
4. 若 `r >= 0`，写 `S = 字(S + 0)`、`O = r` 后继续。

目标当前节点容量判定为：

`A = 640 - 无符号半字(D + 6)`

- `T < A`：目标起点位于当前节点内，随后只有 `S != 0` 且 `L != 0` 才进入实际复制；
- `T >= A`：进入执行地址 `0xa000966e`，以 `T - A` 继续推进目标链。

## 4. 能力边界

- 已闭合：112 个源字节、41 条指令、六参数保存、目标 `+8` 写入、源链定位、目标当前容量公式和零长度返回分流。
- 当前段只定位源起点，没有读取或复制源数据；源数据地址和单轮复制量由后方路径继续闭合。
- 即使源节点已经为空，若目标偏移仍越过当前节点容量，代码也会先进入目标链推进路径；本段不把空源简化为立即返回。
