# `0x00a6b4..0x00a741` 三余量最小复制与源目标双链推进

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa00095fe` 开始的大型链式分段复制函数最后一段。每轮复制长度取
“当前源节点剩余长度、请求剩余长度、当前目标节点剩余容量”三者最小值；源地址和目标
地址都由节点基址、固定 12 字节头、节点 `+6` 半字及当前节点内偏移相加得到。调用已完整
闭合的底层字节复制函数后，原厂分别推进源偏移、剩余长度和目标偏移；源节点用尽时跳过
后续零长度节点，目标节点到达 640 字节边界时复用或取得下一节点。源耗尽或长度归零返回
零，取得目标节点失败返回 `-12`。

## 1. 覆盖范围

## 3. 单轮复制公式

令当前源节点为 `S`、源节点内偏移为 `O`、当前目标节点为 `D`、目标节点内偏移为 `T`、
请求剩余长度为 `L`：

`源余量 = 无符号半字(S + 4) - O`

`目标余量 = 640 - 无符号半字(D + 6) - T`

`N = 无符号最小值(源余量, L, 目标余量)`

`源地址 = S + 12 + 无符号半字(S + 6) + O`

`目标地址 = D + 12 + 无符号半字(D + 6) + T`

调用已闭合的底层字节复制函数：

`0xa000579c(目标地址, 源地址, N)`

其函数事实唯一原文从 [`00679c-00682b 底层字节复制入口与零至七字节路径`](00679c-00682b-底层字节复制入口与零至七字节路径.md) 开始，并由连续分段闭合到文件偏移 `0x006bd3`。

## 4. 循环推进与返回

- 复制后写 `T = T + N`、`O = O + N`、`L = L - N`，并把 `T` 低 16 位写到 `D[+4]`；
- `O` 达到当前源节点分段长度时推进源链，并跳过所有 `+4` 长度为零的节点，再把 `O` 清零；
- `无符号半字(D + 6) + T <= 639` 时回到源非空且长度非零门禁；
- 目标节点达到 640 字节边界时，即使 `L` 已经归零，只要源节点仍非空，当前顺序代码也会先推进或取得下一目标节点，再回到长度门禁；
- 目标已有下一节点时清零其 `+4..+11` 八字节后复用；没有时调用 `0xa0009dd4(C)`；
- 源节点为空或剩余长度为零时返回零；新目标节点取得失败时返回 `-12`；源链提前耗尽不会改成错误返回。
