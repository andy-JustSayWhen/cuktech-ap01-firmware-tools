本段是执行地址 `0xa0009742` 开始的大型函数入口。六个参数依次为目标分段链、连续源
地址、写入长度、目标逻辑偏移、新节点取得参数和取得方式选择值。原厂要求目标链与连续源
地址非零；随后以目标首节点 `+8` 的 32 位逻辑末端和 `+6` 半字检查目标偏移范围，越界
返回 `-29`。门禁通过后，沿目标链按各节点 `+4` 半字逐段扣除目标偏移，定位起始目标
节点。写入长度为零时直接返回原长度零，否则进入后方复制路径。

## 3. 参数、门禁与目标定位

令六个入口参数依次为：

- `D`：目标分段链首节点；
- `P`：连续源地址；
- `L`：写入长度；
- `T`：目标逻辑偏移；
- `C`：后续取得新目标节点时使用的参数；
- `M`：后续选择取得函数的值。

正常路径要求 `D != 0` 且 `P != 0`；否则调用固定报告函数，该目标本体尚未顺序覆盖，
是否返回保持未定。

范围门禁为：

- `T - 字(D + 8) <= 0`；
- `无符号半字(D + 6) + T >= 0`。

任一条件不满足都返回 `-29`。

目标定位反复执行：

1. `r = T - 无符号半字(当前节点 + 4)`；
2. 若 `r <= 0`，当前节点包含写入起点；
3. 若 `r > 0`，令 `当前节点 = 字(当前节点 + 0)`、`T = r` 后继续。

定位循环本身不检查下一节点是否为空；它依赖前述目标逻辑末端与链结构保持一致。
