# `0x00a7d0..0x00a84d` 连续源分段写入扩容与双取得路径

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合执行地址 `0xa0009742` 开始的连续源写目标分段链函数。原厂先用当前节点 `+4`
半字减节点内目标偏移得到已有写入余量；余量足够时一次写完，余量不足且没有下一节点时，
把当前节点长度最多扩到“640 减 `+6` 半字”，并同步调整目标首节点 `+8` 的逻辑末端。
每轮调用既有底层字节复制函数，推进连续源地址和剩余长度；需要新节点时，第六参数为零
调用 `0xa0009dd4`，非零则调用 `0xa0009b24(第五参数, -1)`。成功返回原请求长度，节点
取得失败返回 `-12`。

## 3. 单轮地址、长度与扩展公式

令当前目标节点为 `D`、节点内目标偏移为 `T`、连续源地址为 `P`、剩余写入长度为 `L`：

`目标地址 = D + 12 + 无符号半字(D + 6) + T`

`已有余量 = 无符号半字(D + 4) - T`

- 若 `已有余量 >= L`，本轮长度 `N = L`；
- 若 `已有余量 < L` 且 `字(D + 0) != 0`，本轮长度 `N = 已有余量`；
- 若 `已有余量 < L` 且没有下一节点，令
  `E = 无符号最小值(L + T, 640 - 无符号半字(D + 6))`，写
  `字(目标首节点 + 8) = 原逻辑末端 - 原无符号半字(D + 4) + E`、
  `半字(D + 4) = E`，并取 `N = E - T`。

随后调用：

`0xa000579c(目标地址, P, N)`

并更新 `P = P + N`、`L = L - N`。底层字节复制函数原文从
[`00679c-00682b 底层字节复制入口与零至七字节路径`](00679c-00682b-底层字节复制入口与零至七字节路径.md) 开始。

## 4. 节点取得与返回

- `L == 0` 时经前段共用返回尾返回原请求长度；
- `L != 0` 且已有下一节点时直接推进，节点内偏移清零后继续；
- 没有下一节点且第六参数 `M == 0` 时调用 `0xa0009dd4(C)`；
- 没有下一节点且 `M != 0` 时调用 `0xa0009b24(C, -1)`；
- 取得非零节点后接到当前节点 `+0` 并继续；取得零时返回 `-12`；
- 两个取得函数本体都在后续尚未顺序覆盖区域，当前只确认参数、选择条件和返回节点用途。
