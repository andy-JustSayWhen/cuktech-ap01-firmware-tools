## 3. 定位与单轮复制公式

令四个入口参数依次为连续目标地址 `P`、源链首节点 `S`、请求长度 `L`、源逻辑偏移 `O`。

前置门禁：

`有符号32位(无符号半字(S + 6) + O) >= 0`

失败返回 `-29`。本函数在门禁读取前不检查 `S` 是否为空，调用者必须提供可读源首节点。

源定位反复执行：

- `r = O - 无符号半字(S + 4)`；
- `r >= 0` 时令 `S = 字(S + 0)`、`O = r` 并继续；
- `r < 0` 时当前节点包含源起点；
- 定位期间源链耗尽则返回零。

定位完成后的单轮公式：

`源余量 = 无符号半字(S + 4) - O`

`N = 无符号最小值(剩余请求长度, 源余量)`

`源地址 = S + 12 + 无符号半字(S + 6) + O`

`0xa000579c(P, 源地址, N)`

随后目标地址增加 `N`、剩余请求长度减少 `N`，下一源节点从偏移零继续。底层复制原文从
[`00679c-00682b 底层字节复制入口与零至七字节路径`](00679c-00682b-底层字节复制入口与零至七字节路径.md) 开始。
