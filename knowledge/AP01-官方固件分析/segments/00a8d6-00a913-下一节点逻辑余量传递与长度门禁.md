令输入节点为 `N`，下一节点 `next = 字(N + 0)`：

- `next == 0`：不处理逻辑余量，直接进入执行地址 `0xa0009914`；
- 若 `无符号半字(N + 4) >= 字(N + 8)`，写 `字(next + 8) = 0`；
- 否则令 `R = 字(N + 8) - 无符号半字(N + 4)`，先写 `字(next + 8) = R`；
- 若 `R >= 无符号半字(next + 4)`，保持该差值并进入后方路径；
- 若 `R < 无符号半字(next + 4)`，调用固定报告函数；若调用返回，再写 `字(next + 8) = 0`。
