# `0x00a9bc..0x00a9d3` 原链逐节点受保护转挂循环

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa00099bc` 开始的完整独立函数。入口节点为空时直接返回；非空时反复
调用已经闭合的 `0xa00098d6` 节点转挂函数。该函数每次把当前节点挂入受保护全局链，并
返回挂接前保存的原下一节点，因此当前循环能沿原链依次处理，直到返回空指针后结束。

## 3. 精确循环

令入口节点为 `N`：

```text

    N = 0xa00098d6(N)
return
```
