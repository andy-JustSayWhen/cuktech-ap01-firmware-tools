## 3. 精确挂头规则

令输入节点为 `N`，`C = 有符号16位(半字(0x62fc3f94))`：

- 若 `C < 0`：`old = 字(0x62fda080)`，写 `字(0x62fda080) = N`、`N[+0] = old`；
- 若 `C >= 0`：`old = 字(0x62fc62e8)`，写 `N[+0] = old`、`字(0x62fc62e8) = N`；
- 两条路径随后都调用 `0xa00272cc(0x62fc3f94)`；
- 调用结束后无条件恢复原完整处理器状态字并返回。

## 4. 能力边界

- 已闭合：88 个源字节、30 条指令、处理器状态保护、全局半字地址、正负分流、两个链头、固定调用、状态恢复和完整返回。
- 两条路径的写入先后顺序略有不同，但最终链表关系相同：输入节点成为新链头，原链头成为其 `+0` 下一节点。
- `0xa00272cc` 本体尚未顺序覆盖；本函数不像前一个挂头函数那样重读半字或检查上限。
