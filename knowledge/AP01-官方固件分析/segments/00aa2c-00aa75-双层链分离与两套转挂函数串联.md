返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009a2c` 开始的完整独立函数。入口参数指向外部链头；原厂先取出
链头并把外部头清零。若原链非空，则沿每个主节点 `+0` 保存的原下一节点推进；每个主节点
的 `+4` 完整 32 位字必须是非零附属链指针。当前主节点交给 `0xa00099d4` 挂入另一组
受保护全局链，其附属链交给 `0xa00099bc` 逐节点转挂。附属链指针为零时调用固定报告函数，
当前函数没有为报告返回提供正常续接路径。

## 3. 精确双层循环

令入口外部链头地址为 `H`：

1. `N = *H`，随后写 `*H = 0`；
2. 若 `N == 0`，直接返回；
3. 读取 `A = 字(N + 4)`；`A == 0` 时调用固定报告函数；
4. 保存 `next = 字(N + 0)`；
5. 调用 `0xa00099d4(N)`，其原文见
   [`00a9d4-00aa2b 另一有符号全局半字分流双链挂头`](00a9d4-00aa2b-另一有符号全局半字分流双链挂头.md)；
6. 调用 `0xa00099bc(A)`，其原文见
   [`00a9bc-00a9d3 原链逐节点受保护转挂循环`](00a9bc-00a9d3-原链逐节点受保护转挂循环.md)；
7. 令 `N = next`，非空时回到第三步，否则返回。

## 4. 能力边界

- 已闭合：74 个源字节、30 条指令、外部头清零、主链推进、附属链门禁、两套已知转挂调用和完整返回。
- 主节点 `+4` 在本函数中按完整 32 位指针读取，不得与前面分段缓冲节点 `+4` 的半字长度混为同一结构。
