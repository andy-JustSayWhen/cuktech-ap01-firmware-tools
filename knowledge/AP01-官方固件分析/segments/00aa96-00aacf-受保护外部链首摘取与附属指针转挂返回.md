# `0x00aa96..0x00aacf` 受保护外部链首摘取与附属指针转挂返回

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009a96` 开始的完整独立函数。入口参数指向含 `+0` 主链头和
`+4` 伴随指针的外部结构。原厂在处理器状态保护下摘取 `+0` 首节点：链空时返回零；
非空时把外部 `+0` 推进到首节点 `+0`，推进结果为空时同时清零外部 `+4`。随后读取被摘
节点 `+4` 的附属指针，把它交给已闭合的 `0xa00099d4` 全局挂头函数，并在恢复处理器
状态后返回该附属指针。

## 3. 精确摘取与返回

令入口外部结构为 `H`：

- 保存处理器状态并清除掩码值 `0x08` 对应位；
- `N = 字(H + 0)`；若 `N == 0`，恢复状态并返回零；
- `next = 字(N + 0)`，写 `字(H + 0) = next`；
- 若 `next == 0`，再写 `字(H + 4) = 0`；
- `A = 字(N + 4)`；调用 `0xa00099d4(A)`；
- 恢复原处理器状态并返回 `A`。

调用目标原文见
[`00a9d4-00aa2b 另一有符号全局半字分流双链挂头`](00a9d4-00aa2b-另一有符号全局半字分流双链挂头.md)。
