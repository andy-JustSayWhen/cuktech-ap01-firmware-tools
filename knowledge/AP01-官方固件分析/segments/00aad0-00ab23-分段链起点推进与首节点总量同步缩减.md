# `0x00aad0..0x00ab23` 分段链起点推进与首节点总量同步缩减

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009ad0` 开始的完整独立函数。第一参数既是分段链首节点，也是保存
`+8` 总量的节点；第二参数是待推进量。原厂沿链逐节点处理，每轮把待推进量无符号限制为
最多 640，计算该轮目标起点减当前节点原 `+6` 半字的差值，并在差值超过当前 `+4` 长度
时把实际缩减量限制为当前长度。随后从首节点 `+8` 总量和当前节点 `+4` 长度中扣除实际
缩减量，把当前节点 `+6` 写成该轮目标起点，再推进到 `+0` 下一节点。链耗尽或待推进量
归零时返回。

## 3. 精确单轮公式

令链首节点为 `H`、当前节点为 `N`、剩余待推进量为 `R`：

`Q = 无符号最小值(R, 640)`

`O = 无符号半字(N + 6)`

`L = 无符号半字(N + 4)`

`X = Q - O`

`C = (有符号32位(L - X) < 0) ? L : X`

本轮写入：

- `R = R - Q`；
- `字(H + 8) = 字(H + 8) - C`；
- `半字(N + 6) = 低16位(Q)`；
- `半字(N + 4) = 低16位(L - C)`；
- `N = 字(N + 0)`。

在正常结构不变量 `Q >= O` 下，`C` 等价于 `min(L, Q - O)`。当前函数没有显式门禁保证
`Q >= O`；若调用者破坏该不变量，代码会保留负的 `X`，不能把精确行为无条件简化为普通
无符号最小值。
