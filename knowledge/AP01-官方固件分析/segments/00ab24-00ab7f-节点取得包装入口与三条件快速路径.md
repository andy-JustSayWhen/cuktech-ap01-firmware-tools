返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009b24` 开始的大型节点取得包装函数入口。第一参数是后续节点来源
选择值，第二参数是等待参数。原厂读取全局字 `0x62fc6014`，并在它为零时调用
`0xa0027730()`。只要全局字非零、固定函数返回非零、或等待参数等于零，都会走快速路径：
调用一次 `0xa0009dd4(选择值)` 并原样返回节点或空指针。只有三项依次都为零、零、非零，
才进入后方等待取得路径。

## 3. 精确快速路径

令选择值为 `S`、等待参数为 `W`、`G = 字(0x62fc6014)`、
`R = 0xa0027730()`（仅在 `G == 0` 时调用）：

- `G != 0`：返回 `0xa0009dd4(S)`；
- `G == 0` 且 `R != 0`：返回 `0xa0009dd4(S)`；
- `G == 0`、`R == 0` 且 `W == 0`：返回 `0xa0009dd4(S)`；
- `G == 0`、`R == 0` 且 `W != 0`：进入执行地址 `0xa0009b80` 的等待路径。

## 4. 能力边界
