# `0x00ab80..0x00abff` 等待取得负一路径与全局链摘头重试

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段承接大型节点取得包装函数的等待路径。选择值为零时使用全局半字
`0x62fc3c68`，非零选择值在后方改用 `0x62fc3c74`。原厂保存处理器状态并清除
`0x08` 位，保存全局字 `0x62fc6c44` 快照，再次直接调用 `0xa0009dd4(选择值)`；成功
立即进入恢复返回。仍为空且等待参数等于 `-1` 时，调用固定等待函数；非负返回后在另一层
状态保护下尝试从全局链头 `0x62fc8f30` 摘取节点，摘到的节点会清零 `+0..+11` 中的三个
指针/状态字。链空时先把所选全局半字加一，再直接取得一次；固定等待返回零时允许循环重试。

## 3. 负一等待路径精确流程

令选择值为 `S`，等待参数为 `W`，所选全局半字地址为 `C`：

- `S == 0` 时 `C = 0x62fc3c68`；`S != 0` 的地址选择由下一段闭合；
- 在外层状态保护下先执行 `N = 0xa0009dd4(S)`；`N != 0` 时恢复状态并返回；
- 若 `N == 0` 且 `W == -1`，执行 `R = 0xa00287b8(C)`；
- `R < 0` 时恢复状态并返回零；
- `R >= 0` 时在内层状态保护下从 `0x62fc8f30` 摘头；成功时清零被摘节点 `+0`、`+4`、`+8` 三个完整字；
- 摘头失败时把 `有符号16位(半字(C))` 加一写回，再调用一次 `0xa0009dd4(S)`；
- `R == 0` 时回到取得结果门禁，空结果会再次等待；`R != 0` 时不循环，进入状态恢复返回。
