## 3. 有限等待公式

令选择值为 `S`、原等待参数为 `W`、入口全局字快照为 `G0`、当前全局字为 `G1`：

`等待半字地址 C = (S == 0) ? 0x62fc3c68 : 0x62fc3c74`

`delta = G1 - G0`

`W2 = (delta < 0 或 无符号(delta) >= 无符号(W)) ? 0 : W - delta`

随后调用 `R = 0xa0052074(C, W2)`，并从执行地址 `0xa0009bb2` 开始复用前段逻辑：
负返回结束，非负返回尝试从 `0x62fc8f30` 摘头；返回零允许在仍为空时循环，非零只完成
这一轮后返回。

成功摘头后的递减地址为：

`D = (S == 0) ? 0x62fc3c74 : 0x62fc3c68`

即 `D` 与等待地址 `C` 相反。原厂直接执行 `半字(D) = 低16位(半字(D) - 1)`，没有
零值或下溢门禁。
