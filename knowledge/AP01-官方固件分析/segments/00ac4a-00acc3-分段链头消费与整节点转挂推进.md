# `0x00ac4a..0x00acc3` 分段链头消费与整节点转挂推进

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009c4a` 开始的完整独立函数。第一参数是分段链首节点，第二参数是
待消费量；任一为零都直接返回。待消费量小于当前节点 `+4` 半字长度时，原厂从首节点
`+8` 总量和当前 `+4` 长度中扣除消费量，并把当前 `+6` 起点增加消费量。待消费量覆盖
完整当前节点时，原厂扣除整段长度；存在下一节点则调用已闭合的 `0xa00098d6` 转挂当前
节点，再以保存的原下一节点继续。链已耗尽时要求剩余总量为零，否则调用固定报告函数。

## 3. 精确消费规则

令当前节点为 `N`、剩余总量为 `T`、剩余待消费量为 `R`、当前长度
`L = 无符号半字(N + 4)`：

- `R < L`：写 `T = T - R`，`半字(N + 4) = 低16位(L - 低16位(R))`，
  `半字(N + 6) = 低16位(无符号半字(N + 6) + 低16位(R))`，再写 `字(N + 8) = T` 并返回；
- `R >= L`：写 `T = T - L`、`R = R - L`；
- 若原下一节点非零，保存它，调用 `0xa00098d6(N)` 转挂当前节点，再令 `N = 原下一节点`；
- `R != 0` 时继续处理新当前节点；`R == 0` 时把 `T` 写入新当前节点 `+8` 后返回；
- 原下一节点为空时要求 `T == 0`，随后把当前节点 `+4` 的完整 32 位字清零并写 `N[+8] = 0`；
- 链耗尽但 `T != 0` 时进入固定报告调用，该调用后没有安全的本地正常续接保证。

## 4. 能力边界

- 已闭合：122 个源字节、44 条指令、空值门禁、部分消费、整节点消费、总量同步、已知转挂调用、链推进、尾节点清零和完整返回。
- 部分消费只把请求量低 16 位用于节点 `+4/+6` 半字更新，但从 32 位总量中扣除的是原完整请求量；正常路径由 `R < L` 且 `L` 为无符号半字约束请求量小于 65536。
- 固定报告若返回，参数寄存器已经指向报告字符串，顺序清零将不再针对原节点；因此该路径依赖报告目标不返回，需待目标本体证据确认。
