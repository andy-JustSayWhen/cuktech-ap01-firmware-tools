# `0x00acc4..0x00ad39` 分段链尾消费与末节点逐轮转挂

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009cc4` 开始的完整独立函数。第一参数是分段链首节点，第二参数是
待从链尾消费的量；链空返回零，消费量为零或负值返回原链首。原厂每轮从链首遍历到末节点
并保存前驱：待消费量小于末节点 `+4` 半字长度时，只从链首 `+8` 总量和末节点 `+4`
长度中扣除；待消费量覆盖整个末节点时，先把末节点长度清零并调用已闭合的
`0xa00098d6` 转挂该节点，再把前驱 `+0` 清零。若被移除的是唯一节点则返回空链；仍有
消费量时重新从链首寻找新的末节点。

## 3. 精确尾部消费

令链首为 `H`、剩余待消费量为 `R`，每轮遍历得到末节点 `N`、前驱 `P`，
`L = 无符号半字(N + 4)`：

- `R <= 0`：返回当前链首 `H`；
- `0 < R < L`：写 `字(H + 8) = 字(H + 8) - R`，
  `半字(N + 4) = 低16位(L - R)`，返回 `H`；
- `R >= L`：写 `字(H + 8) = 字(H + 8) - L`、`半字(N + 4) = 0`、`R = R - L`，
  调用 `0xa00098d6(N)`；
- 若 `P == 0`，被移除的是唯一节点，返回零；
- 若 `P != 0`，写 `字(P + 0) = 0`，再按 `R` 是否仍为正决定重新寻找新末节点或返回 `H`。
