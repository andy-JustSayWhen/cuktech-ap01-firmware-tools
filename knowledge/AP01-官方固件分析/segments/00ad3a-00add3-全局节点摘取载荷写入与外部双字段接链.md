# `0x00ad3a..0x00add3` 全局节点摘取载荷写入与外部双字段接链

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009d3a` 开始的完整独立函数。第一参数是待保存载荷指针，第二参数
指向含 `+0` 主链头与 `+4` 伴随节点指针的外部结构。原厂先在处理器状态保护下从全局链头
`0x62fc62e8` 摘取节点，同时把全局半字 `0x62fc3f94` 减一并要求结果非负；链空返回
`-12`。成功时把载荷指针写入节点 `+4`、清零节点 `+0`，再进入第二层状态保护：外部主链
为空时把新节点同时写入外部 `+0` 与 `+4`；非空时要求外部 `+4` 指针也非零，并把新节点
写入该伴随节点 `+0`。成功返回零。

## 3. 精确摘取与接链

令载荷指针为 `P`、外部结构为 `H`：

1. 在第一层状态保护下，`N = 字(0x62fc62e8)`；
2. `N == 0` 时恢复状态并返回 `-12`；
3. `N != 0` 时写 `字(0x62fc62e8) = 字(N + 0)`，并执行
   `半字(0x62fc3f94) = 低16位(半字(0x62fc3f94) - 1)`；更新后有符号值必须非负；
4. 清 `N[+4]`，恢复第一层状态，再写 `N[+4] = P`、`N[+0] = 0`；
5. 在第二层状态保护下，若 `字(H + 0) == 0`，写 `字(H + 0) = N`、`字(H + 4) = N`；
6. 若外部主链非空，要求 `A = 字(H + 4)` 非零，并写 `字(A + 0) = N`；
7. 恢复第二层状态并返回零。

## 4. 能力边界

- 已闭合：154 个源字节、53 条指令、双层状态保护、全局摘头、计数递减、负值报告、载荷写入、两类外部接链、失败和成功返回。
