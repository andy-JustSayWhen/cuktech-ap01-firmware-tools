# `0x00add4..0x00ae77` 双计数门禁与全局链节点直接取得

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009dd4` 开始的完整独立函数，也是前面节点取得包装函数直接
调用的取得本体。入口参数为零时先检查全局有符号半字 `0x62fc3c68`，入口参数
非零时先检查 `0x62fc3c74`；后者不大于零时，只有前者大于 24 才继续。原厂随后
从全局链头 `0x62fc62e4` 摘取节点，依次递减上述两个半字，恢复处理器状态后
清零节点 `+0`、`+4`、`+8` 三个字并返回节点地址；任一前置门禁或链空命中时
恢复状态并返回空地址。

## 3. 精确取得规则

令入口参数为 `S`，第一全局有符号半字为 `C0 = 半字(0x62fc3c68)`，第二个为
`C1 = 半字(0x62fc3c74)`：

1. `S == 0` 时要求 `C0 > 0`，否则恢复处理器状态并返回空地址；
2. `S != 0` 时先要求 `C1 > 0`；不满足时只有 `C0 > 24` 才继续；
3. 读取 `N = 字(0x62fc62e4)`，`N == 0` 时恢复状态并返回空地址；
4. 写 `字(0x62fc62e4) = 字(N + 0)`，再依次写回 `C0 - 1` 与 `C1 - 1`；
5. `C0 - 1` 按有符号 16 位读取为负时，调用固定报告地址；本段没有对 `C1 - 1`
   做同类负值检查；
6. 正常路径恢复处理器状态，写 `字(N + 0) = 0`、`字(N + 4) = 0`、`字(N + 8) = 0`，
   返回 `N`。

## 4. 能力边界

- 已闭合：164 个源字节、49 条指令、入口参数双门禁、24 的备用余量门禁、全局摘头、
  双计数递减、三字清零、空地址失败与节点成功返回。
- 两个全局半字的业务含义尚未由本段自证，只能将它们记为取得门禁与递减计数，不得
  无证据命名为某类资源总量或剩余量。
- `0xa0019572` 的函数本体尚未顺序通读；若它在负值报告后返回，控制流会从
  `0xa0009e46` 重新选择第二全局半字并回到共同检查；在该目标被通读前，不宣称报告
  路径一定返回或一定不返回。
