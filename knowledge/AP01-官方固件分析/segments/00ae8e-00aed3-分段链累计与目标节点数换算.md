# `0x00ae8e..0x00aed3` 分段链累计与目标节点数换算

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009e8e` 开始的大型分段链调整函数入口。第一参数为
分段链头，第二参数为后续要写入链头 `+8` 字段并分配到各节点 `+4` 半字的
请求量。链头为空时直接返回。非空时，原厂遍历每个节点，统计节点个数，
并把每个节点 `+6` 半字累加后每轮截为 16 位。遍历结束后，以请求量、累计值和
固定段界 640 换算目标节点数，并将结果下限设为一，再按目标数是否小于
现有节点数分流。

## 3. 精确遍历与换算

令链中节点数为 `K`，第二入口参数为 `R`，每个节点 `+6` 无符号半字为
`O[i]`。原厂按以下规则得到目标节点数 `T`：

1. 沿 `+0` 下一节点遍历整链，得到 `K`；
2. `U = 低16位(O[0] + O[1] + ... + O[K-1])`，每轮加法后都明确截为 16 位；
3. `Q = 低32位(低32位(R + 639) + U)`；
4. `T = Q 按无符号数除以 640`；
5. `T == 0` 时把 `T` 改为一；
6. `T < K` 进入后续裁减链路径，`T >= K` 进入后续保留或增加节点路径。
