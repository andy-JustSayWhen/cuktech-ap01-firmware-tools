# `0x00af38..0x00af5d` 裁减定位回跳与目标节点逐个扩链

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合执行地址 `0xa0009e8e` 开始的大型分段链调整函数。裁减路径沿 `+0`
指针前进目标节点数次，将第 `T` 个节点和第 `T+1` 个节点分别留给前段的断链与
转挂路径。增链路径在目标节点数大于现有数时，以参数零反复调用已通读的
`0xa0009dd4` 直接取得函数，将新节点逐个接到原链尾，直到节点数达标或取得
失败；随后都回到前段的请求量与分段长度重写。入口链头为空时则直接返回。

## 3. 精确裁减定位与增链

令目标节点数为 `T`、现有节点数为 `K`：

1. `T < K` 时，从链头开始每轮读取下一节点并执行 `T = T - 1`，直到 `T == 0`；
2. 此时保留的当前节点是裁减后的链尾，其原下一节点是待转挂剩余链头；
3. `T == K` 时不改变节点数，直接重写各节点承担量；
4. `T > K` 时，从原链尾开始重复执行 `N = 0xa0009dd4(0)`、`字(当前链尾+0) = N`、
   `K = K + 1`；
5. `N == 0` 或 `K == T` 时结束增链，回到前段重写请求量和节点承担量；
6. 因此取得失败不会使本函数报错返回，而是通过前段把链头 `+8` 回写为实际
   能分配到现有链的总量。
