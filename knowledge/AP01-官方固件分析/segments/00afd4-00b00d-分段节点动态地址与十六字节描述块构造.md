# `0x00afd4..0x00b00d` 分段节点动态地址与十六字节描述块构造

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa0009f5e` 开始的大型函数共同构造入口。原厂读取第一
对象 `+48` 的分段节点，保存节点地址，并用节点 `+6` 半字和固定值 12 计算
动态数据起点。随后在栈上构造 16 字节描述块：起始半字固定为 2，第二半字
来自动态数据起点 `+20`，紧随的 32 位字由动态数据起点 `+12` 和 `+14` 两个
半字按低、高半部拼接，末尾 8 字节通过已知填充入口置零。

填充入口的行为原文见：
[`0x0043a0..0x0045c7` 清零入口、串口搬运通道与路径缓冲池`](0043a0-0045c7-清零入口串口搬运通道与路径缓冲池.md)。

## 1. 覆盖范围

- 文件偏移：`0x00afd4..0x00b00d`
- 执行地址：`0xa0009fd4..0xa000a00d`
- 长度：58 字节
- 本段原始字节散列：`e50b36ed01517629adb16e34e26454163682a2f95784296af5888fa9b4f7cd53`

## 3. 精确描述块布局

令第一对象为 `A`，分段节点 `N = 字(A+48)`，动态数据起点
`D = N + 半字(N+6) + 12`，栈上 16 字节描述块为 `P`：

| 描述块偏移 | 长度 | 写入值 |
| --- | ---: | --- |
| `P+0` | 2 字节 | `2` |
| `P+2` | 2 字节 | `半字(D+20)` |
| `P+4` | 4 字节 | `半字(D+12) | (半字(D+14) << 16)` |
| `P+8` | 8 字节 | 全部填零 |

## 4. 能力边界

- 已闭合：58 个源字节、18 条指令、节点地址保存、动态数据起点公式、描述块四部分布局、
  半字拼接顺序和末尾填零调用。
- 本段直接解引用 `字(A+48)` 并读取动态地址；本地没有空值检查。该指针非空的
  保证若存在，来自调用者或尚未通读的前置函数，不由本段自证。
- 下一字节 `0x00b00e` 开始根据分段节点和第一对象字段计算多个逻辑偏移，
  并反复调用前面已闭合的包装写入函数。
