# `0x00b00e..0x00b039` 节点逻辑末端换算与十六字节描述块写入

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续执行地址 `0xa0009f5e` 开始的大型函数。原厂从第一对象 `+64`
的 32 位地址中，依次减去分段节点基址、固定值 12 和节点 `+6` 半字，得到
节点内逻辑末端偏移。它还在栈上准备一字节固定值 16，随后调用已闭合的
`0xa0009e78` 包装写入函数，把前段构造的 16 字节描述块写到逻辑末端之前
16 字节处。写入返回负值时跳到后方失败清理路径。

## 1. 覆盖范围

- 文件偏移：`0x00b00e..0x00b039`
- 执行地址：`0xa000a00e..0xa000a039`
- 长度：44 字节
- 本段原始字节散列：`0c01e47d4bb1a772f71b63df289910d2033e2c4e58f4c86d6e5b250369e2a303`

## 3. 精确偏移与写入参数

令第一对象为 `A`、分段节点 `N = 字(A+48)`、前段描述块为 `P`：

1. `E = 低32位(字(A+64) - (N + 12) - 半字(N+6))`；
2. 栈上单字节局部值设为 16，供下一次写入使用；
3. 执行 `R0 = 0xa0009e78(N, P, 16, E-16, 1)`；
4. `R0 < 0` 按有符号比较成立时，跳到 `0xa000a0f2` 失败清理；
5. `R0 >= 0` 时，从下一字节开始继续写入逻辑末端前的单字节字段。

## 4. 能力边界

- 已闭合：44 个源字节、14 条指令、逻辑末端偏移公式、描述块写入五个参数、
  包装固定的第六参数、返回值有符号检查和失败分流。
- 逻辑末端偏移使用 32 位减法，本段没有在调用前单独检查下溢；越界结果由已闭合的
  `0xa0009e78` 及其被调函数门禁处理。
- 下一字节 `0x00b03a` 开始执行两次单字节写入和一次两字节写入。
