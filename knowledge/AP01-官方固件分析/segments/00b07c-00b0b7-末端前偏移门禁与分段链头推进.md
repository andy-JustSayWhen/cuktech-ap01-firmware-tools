# `0x00b07c..0x00b0b7` 末端前偏移门禁与分段链头推进

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续执行地址 `0xa0009f5e` 开始的大型函数。原厂把已减 20 的逻辑
末端偏移与分段节点 `+6` 半字相加，按有符号 32 位要求结果非负；负值时
调用固定报告地址。正常路径以分段节点和上述和值调用已通读的
`0xa0009ad0` 分段链头推进函数。随后以第二对象 `+68` 地址和指向局部节点字的
地址调用 `0xa01b0e10`，再调用 `0xa0052262(6, 第二对象)`。

## 1. 覆盖范围

- 文件偏移：`0x00b07c..0x00b0b7`
- 执行地址：`0xa000a07c..0xa000a0b7`
- 长度：60 字节
- 本段原始字节散列：`305123f140cd1ba961214ca9cb69fdf1dc172fb6267f7736c0f65f658ed859eb`

## 3. 精确调用链

令第二对象为 `B`、分段节点为 `N`、前段逻辑末端偏移为 `E`，局部
节点地址字为 `LN`：

1. `M = 低32位(半字(N+6) + (E-20))`；
2. `M < 0` 按有符号比较成立时，调用固定报告地址；
3. 正常路径执行 `0xa0009ad0(N, M)`；
4. 执行 `0xa01b0e10(B+68, &LN)`；
5. 执行 `0xa0052262(6, B)`。

## 4. 能力边界

- 已闭合：60 个源字节、17 条指令、偏移和公式、有符号门禁、报告参数、已知链头推进调用，
  以及后续两个调用的精确实参。
- `0xa01b0e10` 和 `0xa0052262` 本体尚未按顺序覆盖，因此本段不命名它们的业务效果。
- 报告目标 `0xa0019572` 本体尚未顺序通读；若其返回，本地没有重建原节点和偏移实参，
  因此不声称负值报告后可继续正常推进。
- 下一字节 `0x00b0b8` 开始比较局部原半字与第一对象 `+68` 入口原值，并进入共同清理尾。
