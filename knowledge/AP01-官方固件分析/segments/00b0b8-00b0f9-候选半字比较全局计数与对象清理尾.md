# `0x00b0b8..0x00b0f9` 候选半字比较、全局计数与对象清理尾

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合执行地址 `0xa0009f5e` 开始的大型三参数函数。完成前面的写入与
链头推进后，原厂读取局部候选半字，清零第一对象 `+48` 和 `+60` 两个字段；
早退与写入失败路径会跳过这两次清零，并把比较候选固定为零。共同尾按
无符号数比较候选半字与入口时保存的第一对象 `+68` 原半字；候选较小时把
全局半字 `0x62fc8924` 加一。所有进入处理路径的分支最后都把第一对象
`+68` 半字清零，并返回入口调用结果清第 2 位后的低 16 位。各次包装写入
失败时，则先以第一对象调用 `0xa000c498`，再把零候选送入共同尾。

## 3. 完整返回与清理规则

令入口首次调用结果为 `R`，第一对象为 `A`，入口时保存的
`原半字 = 半字(A+68)`：

1. `(R & 2) == 0` 时直接恢复现场并返回完整 `R`，不执行本段对象清理；
2. `(R & 2) != 0` 时，最终返回 `低16位(R & ~2)`；
3. 正常完成写入时，候选为局部保存半字，并清零 `字(A+48)` 与 `字(A+60)`；
4. 前段关联字比较早退或任一包装写入失败时，候选为零，并跳过 `A+48`、`A+60`
   两个字的清零；
5. 包装写入失败时额外调用 `0xa000c498(A)`；
6. `候选 < 原半字` 按无符号比较成立时，执行
   `半字(0x62fc8924) = 低16位(半字(0x62fc8924) + 1)`；
7. 最后无条件写 `半字(A+68) = 0`。

## 4. 能力边界

- 已闭合：66 个源字节、23 条指令、正常两字段清零、候选比较、全局半字计数、
  无条件对象半字清零、两种返回公式、写入失败调用、回跳与整个
  `0xa0009f5e..0xa000a0f9` 函数。
- 前段关联字早退路径已在跳入本共同尾前递增过一次 `0x62fc8924`；如果入口原半字
  大于零，本段的零候选比较还会再递增一次。两次递增是可达的不同指令，不合并解释。
- `0xa000c498` 本体尚未按顺序覆盖，因此本段只记录调用实参与后继清理，不命名该调用效果。
- 下一独立函数从文件偏移 `0x00b0fa`、执行地址 `0xa000a0fa` 开始。
