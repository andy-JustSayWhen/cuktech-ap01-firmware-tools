# `0x00b0fa..0x00b14f` 对象交换半字懒初始化与可选配置写入

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa000a0fa` 开始的完整两参数函数。第一对象 `+40`
半字已非零时保留原值；为零时，原厂以第一对象 `+32` 地址调用 `0xa000a52c`，
对返回寄存器执行既有双字节交换指令，再把结果低 16 位写入对象 `+40`。
第二参数非空时，把其 `+2` 半字写入第一对象 `+42`，把其 `+4` 字写入
第一对象 `+36`；但第二参数 `+4` 字为零时，改写固定值 `0x0100007f`。
第二参数为空时，对象 `+42` 半字与 `+36` 字都清零。函数固定返回零。

双字节交换指令的唯一行为原文见：
[`0x0071ea..0x007227` 无线发送八字节前缀构造`](0071ea-007227-无线发送八字节前缀构造.md)。

## 3. 精确字段规则

令第一对象为 `A`、第二参数为 `B`：

1. 若 `半字(A+40) == 0`，则以 `A+32` 调用 `0xa000a52c`，对返回值执行双字节交换，
   并写 `半字(A+40) = 交换结果低16位`；
2. 若 `B != 0`，写 `半字(A+42) = 半字(B+2)`；
3. `B != 0` 且 `字(B+4) != 0` 时，写 `字(A+36) = 字(B+4)`；
4. `B != 0` 且 `字(B+4) == 0` 时，写 `字(A+36) = 0x0100007f`；
5. `B == 0` 时，写 `半字(A+42) = 0` 与 `字(A+36) = 0`；
6. 固定返回零。
