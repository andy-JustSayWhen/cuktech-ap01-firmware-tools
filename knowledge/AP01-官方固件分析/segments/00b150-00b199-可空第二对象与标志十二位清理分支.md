# `0x00b150..0x00b199` 可空第二对象与标志十二位清理分支

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa000a150` 开始的大型三参数函数入口。第三参数是本函数
最终透传返回的标志值。第二对象为空时不做任何改写，直接返回原标志值。
第二对象非空且标志值的 `0x1000` 位置一时，原厂读它 `+4` 所指对象，清零
该对象 `+20` 半字、`+16` 字和 `+12` 字，把第二对象 `+28` 字写为 `-101`，
再调用 `0xa00272cc(第二对象+12)`，最后仍返回原标志值。`0x1000` 位为零时
进入下一字节开始的第二位检查路径。

## 3. 精确清理规则

令第二对象为 `B`、第三参数标志值为 `F`、关联对象 `Q = 字(B+4)`：

1. `B == 0` 时直接返回 `F`；
2. `B != 0` 且 `(F & 0x1000) == 0` 时进入下一字节开始的第 2 位检查；
3. `B != 0` 且 `(F & 0x1000) != 0` 时，写 `半字(Q+20)=0`、`字(Q+16)=0`、`字(Q+12)=0`；
4. 写 `字(B+28) = -101`；
5. 调用 `0xa00272cc(B+12)`；
6. 返回原标志值 `F`。
