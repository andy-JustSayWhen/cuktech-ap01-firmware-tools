# `0x00b19a..0x00b1d5` 标志第二位门禁与既有十六字节描述块构造

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续执行地址 `0xa000a150` 开始的大型三参数函数。标志值第 2 位为零
时直接回到共同末尾，返回原标志值。该位为一时，原厂从第一对象 `+48` 取分段
节点，按“节点基址加 `+6` 半字再加 12”得到动态数据起点，并在栈上构造与前面
已闭合函数完全相同的 16 字节描述块。

该描述块字段布局的唯一原文见：
[`0x00afd4..0x00b00d` 分段节点动态地址与十六字节描述块构造`](00afd4-00b00d-分段节点动态地址与十六字节描述块构造.md)。

## 3. 本次实例化关系

令第一对象为 `A`、分段节点 `N = 字(A+48)`、动态数据起点
`D = N + 半字(N+6) + 12`：

- 标志第 2 位为零时，本次不构造描述块；
- 标志第 2 位为一时，按已有唯一布局原文构造 16 字节描述块，本次的三个动态
  半字来源为 `半字(D+20)`、`半字(D+12)` 和 `半字(D+14)`；
- 描述块末尾 8 字节通过 `0xa0024806` 填零。
