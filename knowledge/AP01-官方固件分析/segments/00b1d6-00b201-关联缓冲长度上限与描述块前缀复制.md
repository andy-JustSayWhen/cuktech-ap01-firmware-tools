# `0x00b1d6..0x00b201` 关联缓冲长度上限与描述块前缀复制

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续执行地址 `0xa000a150` 开始的大型函数。原厂把第二对象 `+8`
所指对象解释为 `+0` 目标地址与 `+4` 复制长度两个字段。目标地址非空时，将长度
无符号限制到最多 16，把限制结果写回 `+4`，并从前段构造的 16 字节描述块
起点复制相同长度到目标地址。目标地址为空时不读改长度、也不执行复制。
两路随后都调用 `0xa000a4c0(第二对象, 描述块, 第一对象+26字节)`。

底层字节复制函数的唯一定义原文起点见：
[`0x00679c..0x00682b` 底层字节复制入口与零至七字节路径`](00679c-00682b-底层字节复制入口与零至七字节路径.md)。

## 3. 精确复制与调用

令第一对象为 `A`、第二对象为 `B`、描述块为 `P`、关联缓冲对象
`Q = 字(B+8)`：

1. 若 `字(Q+0) != 0`，则令 `L = 字(Q+4)`，再将 `L` 按无符号数限制到最大 16；
2. 写 `字(Q+4) = L`，执行 `0xa000579c(字(Q+0), P, L)`；
3. 若 `字(Q+0) == 0`，则不改写 `Q+4` 也不执行复制；
4. 两路都执行 `0xa000a4c0(B, P, 字节(A+26))`。

## 4. 能力边界

- 已闭合：44 个源字节、17 条指令、目标地址空值门禁、长度无符号上限、长度写回、
  底层复制三实参和后续调用三实参。
- 本段直接解引用 `字(B+8)`，本地没有空值检查；该指针非空的保证若存在，来自调用者
  或尚未通读的对象初始化。
- `0xa000a4c0` 本体尚未按顺序覆盖，因此只记录它的三个实参，不命名业务效果。
- 下一字节 `0x00b202` 开始从第一对象和第二对象的多层关联对象换算连续复制长度与逻辑偏移。
