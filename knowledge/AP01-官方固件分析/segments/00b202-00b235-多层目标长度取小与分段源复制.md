# `0x00b202..0x00b235` 多层目标长度取小与分段源复制

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续执行地址 `0xa000a150` 开始的大型函数。原厂沿“第二对象 `+8`
所指对象的 `+8`”取到第二层目标对象，把它 `+4` 字与第一对象 `+68` 半字
按无符号数取较小值作为复制长度。源分段节点来自第一对象 `+48`，逻辑源偏移
由第一对象 `+64` 地址依次减节点基址、12 和节点 `+6` 半字得到。原厂调用
已闭合的分段源读连续目标函数，把实际复制长度写入第二对象 `+24`，再清零
第一对象 `+68` 半字。

条件移动指令的唯一语义原文见：
[`0x002c48..0x002d7b` 串行外设轮询发送`](002c48-002d7b-串行外设轮询发送.md)。
分段源读连续目标函数原文见：
[`0x00a84e..0x00a8d5` 分段源读连续目标与实际复制长度返回`](00a84e-00a8d5-分段源读连续目标与实际复制长度返回.md)。

## 3. 精确复制公式

令第一对象为 `A`、第二对象为 `B`、源分段节点 `N = 字(A+48)`、
第一层关联对象 `Q = 字(B+8)`、第二层目标对象 `T = 字(Q+8)`：

1. `L = min(半字(A+68), 字(T+4))`，使用无符号比较；
2. `O = 低32位(字(A+64) - (N+12) - 半字(N+6))`；
3. `C = 0xa000984e(N, 字(T+0), L, O)`；
4. 写 `字(B+24) = C`；
5. 写 `半字(A+68) = 0`。
