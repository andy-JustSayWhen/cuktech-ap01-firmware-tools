# `0x00b26a..0x00b2b7` 全局链首四条件首匹配节点查找

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的三参数链表查找函数。原厂从全局地址
`0x62fc8788` 读取单向链表首节点，沿每个节点 `+0` 的下一节点地址
顺序遍历。候选节点必须通过入口第三参数 `0x0800` 位所控制的
附加门禁，且节点 `+45` 字节等于 2、`+40` 半字等于入口第二
参数。节点 `+32` 字若等于第一参数所指的字，或它自身为零，
就返回该节点；否则继续遍历。整链无匹配时返回空值。

## 3. 精确匹配规则

令第一参数所指的字为 `K`、第二参数为 `H`、第三参数为 `F`、
当前候选节点为 `N`。节点必须依次满足：

1. 若 `(F & 0x0800) != 0`，则必须有 `(字(N+20) & 0x0800) == 0`；
2. `字节(N+45) == 2`；
3. `半字(N+40) == H`；
4. `字(N+32) == K` 或 `字(N+32) == 0`。

第一个满足全部条件的节点立即返回；不满足时以 `字(N+0)`
继续，直到节点为空并返回空值。
