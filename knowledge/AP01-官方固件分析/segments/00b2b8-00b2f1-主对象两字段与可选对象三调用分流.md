# `0x00b2b8..0x00b2f1` 主对象两字段与可选对象三调用分流

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的两参数分流函数。原厂先选一个保留在
第二调用参数寄存器中的字：入口第二对象非空时读它 `+4`，
为空时读第一对象 `+36`。随后检查第一对象 `+32` 字：非零时
调用 `0xa000c556(该字, 栈上一字节地址)`；为零时再读第一对象
`+28` 字节，非零时调用 `0xa000c2ca(该字节, 前述选定字)`，为零时
调用 `0xa000c298(0, 前述选定字)`。函数透传被选调用的返回值。

## 1. 覆盖范围

- 文件偏移：`0x00b2b8..0x00b2f1`
- 执行地址：`0xa000a2b8..0xa000a2f1`
- 长度：58 字节
- 本段原始字节散列：`a12a751f74af334d729147e7fdbde8c66914fc95289a2ab2b72affe4aa7cee8d`

## 3. 精确分流

令第一对象为 `A`、第二对象为 `B`，先得到：

- `S = B != 0 ? 字(B+4) : 字(A+36)`；
- `P = 字(A+32)`。

随后的调用与返回为：

1. `P != 0` 时，返回 `0xa000c556(P, &栈上一字节)` 的返回值；
2. `P == 0` 且 `字节(A+28) != 0` 时，返回
   `0xa000c2ca(字节(A+28), S)` 的返回值；
3. `P == 0` 且 `字节(A+28) == 0` 时，返回 `0xa000c298(0, S)` 的返回值。

## 4. 能力边界

- 已闭合：58 个源字节、24 条指令、可选第二对象来源、第一对象两字段门禁、
  三个直接调用的已准备实参、返回值透传和整个函数。
- 选定字 `S` 在 `P == 0` 的两条路径中保留在第二调用参数寄存器内；
  原厂指令没有在调用前覆盖它。
- `0xa000c556`、`0xa000c2ca` 和 `0xa000c298` 本体尚未按顺序覆盖，因此
  本段不命名它们的效果，也不把栈上一字节擅自解释为输入或输出。
- 下一字节 `0x00b2f2` 开始新的大型函数。
