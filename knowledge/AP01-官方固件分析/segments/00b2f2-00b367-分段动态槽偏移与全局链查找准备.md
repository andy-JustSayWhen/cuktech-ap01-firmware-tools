# `0x00b2f2..0x00b367` 分段动态槽偏移与全局链查找准备

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa000a2f2` 开始的大型单参数函数入口。
原厂从第一对象 `+48` 取分段节点，按节点 `+6` 半字得到动态
数据起点。它先把起点加 28 写入对象 `+64`，再把全局半字
`0x62fc8926` 加一。动态数据首字节的低 4 位被换算为 0 到 60、
步长为 4 的槽偏移；该偏移用来得到当前槽地址，同步缩减对象
`+68` 半字，并把对象 `+64` 改写为槽后 8 字节地址。最后从
全局地址 `0x62fc8788` 读取后续遍历的链首。

带索引字节读取指令的语义原文见：
[`0x002184..0x0021e1` 字节复制与循环冗余校验`](002184-0021e1-字节复制与CRC32.md)。

## 3. 精确入口公式

令第一对象为 `A`、分段节点 `N = 字(A+48)`、
动态数据起点 `D = N + 半字(N+6) + 12`：

1. 先写 `字(A+64) = D+28`；
2. 写 `半字(0x62fc8926) = 低16位(半字(0x62fc8926)+1)`；
3. 令 `P = (字节(D) << 2) & 60`，因此 `P` 只能为 0、4、8 直到 60；
4. 当前槽地址为 `D+P`；
5. 写 `半字(A+68) = 低16位(半字(A+68)-8-P)`；
6. 把第一步的结果改写为 `字(A+64) = D+P+8`；
7. 从 `0x62fc8788` 读链首，交给下一段继续判定。

- 已闭合：118 个源字节、41 条指令、分段节点动态起点、两次对象
  `+64` 写入、全局半字递增、槽偏移范围、对象 `+68` 缩减和全局链首。
- 槽的业务名称尚不能由本地证据确定；“槽”仅表示四字节步长的索引位置。
- 本段直接解引用 `字(A+48)`，本地没有空值检查。
- 下一字节 `0x00b368` 开始按链表是否为空执行两类判定。
