# `0x00b368..0x00b3e7` 全局节点链多层可选字段匹配

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段继续执行地址 `0xa000a2f2` 开始的大型函数。原厂沿
全局链首 `0x62fc8788` 指向的单向链表遍历，用当前动态槽和
动态数据起点的字段逐层检查候选节点。节点 `+40` 半字必须
非零并等于当前槽 `+2` 半字；节点 `+32` 字非零时，它必须
等于动态数据 `+16/+18` 拼成的字。节点 `+44` 字节最低位为零
就接受当前节点；为一时再执行两组可选限制。不满足时沿节点
`+0` 继续。

链表为空或遍历到尾时，原厂把动态数据 `+16/+18` 拼成字：
结果为 32 位全一值时清零第一对象 `+68` 半字并转入零结果路径；
否则转入下一段的无节点后续判定。

## 3. 精确匹配规则

令第一对象为 `A`、动态数据起点为 `D`、当前动态槽为 `S`、
当前候选节点为 `N`，并定义：

- `W16 = 半字(D+16) | (半字(D+18) << 16)`；
- `W12 = 半字(D+12) | (半字(D+14) << 16)`。

候选节点的顺序规则为：

1. `半字(N+40) != 0` 且 `半字(N+40) == 半字(S+2)`；
2. `字(N+32) == 0` 或 `字(N+32) == W16`；
3. `(字节(N+44) & 1) == 0` 时立即接受；
4. 否则，`半字(N+42) == 0` 或 `半字(N+42) == 半字(S+0)` 才能继续；
5. 最后，`字(N+36) == 0`、`W16 == 0xffffffff` 或 `字(N+36) == W12`
   任一成立就接受，否则转到 `字(N+0)` 的下一节点。

## 4. 能力边界

- 已闭合：128 个源字节、41 条指令、链空分流、两个动态组合字、候选节点
  的全部本地匹配规则、接受去向、下一节点回边和链尾后续分流。
- 本段只证明节点如何被接受，节点字段的业务名称保留未定。

- 下一字节 `0x00b3e8` 开始处理链表无匹配且 `W16` 不是全一值的路径。
