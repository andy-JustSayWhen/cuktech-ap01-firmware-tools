# `0x00b456..0x00b4bf` 可空对象报告门禁与组合标志调用

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的三参数函数。入口第二对象为空时，原厂不做
其他处理，直接返回入口第三参数。第二对象非空时，它的 `+0`
字或 `+8` 字为零都会以固定文字地址、数值 71 和零调用报告入口。

在两个字都非零的正常路径中，原厂把第三参数中值为 `0x0002`
的标志位提取为零或一。第三参数 `0x1000` 位为一时，再补入
`0x18`；该位为零时，先调用 `0xa0036938()`，返回非负时补入
`0x04`，返回负值时不补。随后调用
`0xa003e1f2(第二对象+8, 1, 组合标志)`，忽略该调用返回值，最后仍
返回入口第三参数。

值为 `0x0002` 的标志位提取语义原文见：
[`0x003730..0x0037d1` 系统时钟频率查询`](003730-0037d1-系统时钟频率查询.md)。

## 3. 正常路径的精确组合规则

令第二对象为 `B`、入口第三参数为 `F`。当 `B != 0`、
`字(B+0) != 0` 且 `字(B+8) != 0` 时：

1. 令 `C = (F >> 1) & 1`；
2. 若 `(F & 0x1000) != 0`，则 `C = C | 0x18`；
3. 否则调用 `Q = 0xa0036938()`；`Q >= 0` 时 `C = C | 0x04`，`Q < 0`
   时保持 `C` 不变；
4. 调用 `0xa003e1f2(B+8, 1, C)`；
5. 忽略第四步返回值，返回 `F`。

## 4. 能力边界

- 已闭合：106 个源字节、39 条指令、第二对象空值分流、两字段门禁、报告实参、
  正常路径标志组合、两个后续调用的已准备实参、返回值忽略和原第三参数透传。
- 入口第一参数在本函数指令中没有被使用。
- `0xa0019572`、`0xa0036938` 和 `0xa003e1f2` 本体尚未按顺序覆盖，因此只记录
  它们的直接调用证据和本地使用的返回值关系，不命名效果。
- 若字段门禁失败后 `0xa0019572` 返回，机器码会继续到 `0xa000a482`；
  但该调用之后的第三调用参数寄存器内容没有由本函数保存，因此本文不把
  正常路径的 `C` 公式扩展到这条路径，也不猜测报告调用是否返回。
- 下一字节 `0x00b4c0` 开始新的三参数函数。
