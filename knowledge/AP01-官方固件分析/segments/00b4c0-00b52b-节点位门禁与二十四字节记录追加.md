# `0x00b4c0..0x00b52b` 节点位门禁与二十四字节记录追加

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的三参数函数。原厂先从第一对象 `+0` 取节点，
只有节点 `+45` 字节等于 2，且节点 `+20` 字的 `0x10000000` 位为一
才继续。它从第一对象 `+8` 取第二层对象；该对象 `+20` 字按
无符号数大于 23 时，向它 `+16` 所指地址写一条 24 字节记录。

记录六个字依次是：固定值 24、零、固定值 28、入口第三参数、
节点 `+32` 字、入口第二参数 `+4` 字。写完后原厂把第二层对象
`+16` 地址增加 24，把 `+20` 长度减少 24。

写入后自动增加地址的指令语义原文见：
[`0x002822..0x0028c7` 熔丝区域0装载`](002822-0028c7-熔丝区域0装载.md)。
底层字节复制函数原文由 `0x00679c..0x006bd3` 五段连续覆盖，其入口见：
[`0x00679c..0x00682b` 底层字节复制入口`](00679c-00682b-底层字节复制入口与零至七字节路径.md)。

## 3. 精确记录布局

令第一对象为 `A`、第二参数为 `B`、第三参数为 `C`、
节点 `N = 字(A+0)`、第二层对象 `Q = 字(A+8)`、当前写地址
`P = 字(Q+16)`。写入门禁为：

- `字节(N+45) == 2`；
- `(字(N+20) & 0x10000000) != 0`；
- 按无符号数有 `字(Q+20) >= 24`。

门禁通过后的 24 字节记录为：

| 记录偏移 | 32 位值 |
| --- | --- |
| `+0` | 24 |
| `+4` | 0 |
| `+8` | 28 |
| `+12` | `C` |
| `+16` | `字(N+32)` |
| `+20` | `字(B+4)` |

写完后使 `字(Q+16)=P+24`、`字(Q+20)=字(Q+20)-24`。

## 4. 能力边界

- 已闭合：108 个源字节、43 条指令、三项写入门禁、六字记录布局、底层复制
  实参、地址推进、长度扣减和整个函数。
- 本函数在三条返回路径前没有统一设定返回寄存器，因此不声明返回值语义。
- 函数直接解引用 `字(A+0)`、`字(A+8)` 和 `B+4`，本地没有对这些地址做空值检查。
- 下一字节 `0x00b52c` 开始新的单参数函数。
