# `0x00b52c..0x00b5c7` 全局半字候选初始化回绕与链查重试

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的单参数候选半字生成函数。原厂先以入口参数
调用 `0xa01b0f4e`，再读全局半字 `0x62fda088`。该半字为零时，
以全局字 `0x62fc6c44` 对 `0x6d01` 取无符号余数，加 `0x1000`
后写入作为初值。

随后每轮检查当前半字是否在可推进范围内：范围内就加一，
否则改写为 `0x1000`。更新后的值作为本轮候选，先交换它的两个
字节，再以“入口参数、交换后半字、零”调用已通读的全局链查找函数
`0xa000a26a`。找到节点表示本轮候选已被匹配，回到循环继续；未找到时
在不另行准备参数的情况下调用 `0xa003ba8c`，再返回本轮未交换字节的候选半字。

双字节交换指令的唯一行为原文见：
[`0x0071ea..0x007227` 无线发送八字节前缀构造`](0071ea-007227-无线发送八字节前缀构造.md)。
本次原始指令 `0xad8a85f7` 与该原文编码只有寄存器字段不同：
它从当前候选寄存器读值，把交换结果写入第二调用参数寄存器。

## 3. 精确初始化与推进规则

令入口参数为 `A`、全局半字 `G = 半字(0x62fda088)`：

1. 先调用 `0xa01b0f4e(A)`；
2. `G == 0` 时，写
   `G = 低16位((字(0x62fc6c44) 无符号取余 0x6d01) + 0x1000)`；
3. 若 `无符号低16位(G-0x0fff) <= 0x6d00`，写 `G = 低16位(G+1)`；
   否则写 `G = 0x1000`；
4. 正常初值序列中，更新后候选范围为 `0x1000..0x7d00`，
   `0x7d00` 的下一轮回绕到 `0x1000`；
5. 令本轮候选为 `H = G`，令 `J = 交换H的两个字节`；
6. 若 `0xa000a26a(A, J, 0)` 返回节点，则回到第三步；
7. 否则不另行准备参数就调用 `0xa003ba8c`，并返回 `H`。

## 4. 能力边界

- 已闭合：156 个源字节、57 条指令、全局半字初始化、精确取余公式、推进与回绕、
  字节交换、已知链查实参、占用重试、未占用返回和整个函数。
- 链查使用交换字节后的 `J`，而本函数返回未交换的 `H`；
  前方 `0xa000a0fa` 函数会再交换返回值后写入对象 `+40` 半字。
- 本函数没有显式重试次数上限；若链查对每轮候选都返回节点，循环不会从本地退出。
- `0xa01b0f4e` 和 `0xa003ba8c` 本体尚未按顺序覆盖，因此不命名效果；
  两个调用的返回值在本函数中都没有被使用。
- 下一字节 `0x00b5c8` 开始新的函数。
