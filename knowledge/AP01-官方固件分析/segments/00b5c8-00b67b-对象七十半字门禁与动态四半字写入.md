# `0x00b5c8..0x00b67b` 对象七十半字门禁与动态四半字写入

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的两参数函数。第一对象 `+70` 半字为零时
直接返回。该半字非零时，原厂把它加 28 后取低 16 位，写入第一
对象 `+68`。分段节点来自第一对象 `+48`，按节点 `+6` 半字计算
动态数据起点后，原厂以八个寄存器参数调用 `0xa01a0630`。

调用后，原厂把全局半字 `0x62fc8900` 加一，并在动态数据起点
`+20..+27` 写四个连续半字：第二对象 `+40`、第二对象 `+42`、
交换字节后的“第一对象 `+70` 半字加 8”、零。随后调用已通读的
分段链调整函数 `0xa0009e8e(第一对象+48 所指链, 第一对象+68 半字)`，
再把全局半字 `0x62fc8928` 加一并返回。

双字节交换指令的唯一行为原文见：
[`0x0071ea..0x007227` 无线发送八字节前缀构造`](0071ea-007227-无线发送八字节前缀构造.md)。
分段链调整函数由 `0x00ae8e..0x00af5d` 三段连续通读，其入口见：
[`0x00ae8e..0x00aed3` 分段链累计与目标节点数换算`](00ae8e-00aed3-分段链累计与目标节点数换算.md)。

## 3. 八参数调用现场

令第一对象为 `A`、第二对象为 `B`、分段节点
`N = 字(A+48)`、动态数据起点 `D = N + 半字(N+6) + 12`、
`L = 无符号低16位(半字(A+70)+28)`。调用 `0xa01a0630` 时八个
参数寄存器依次是：

1. `D`；
2. `L`；
3. 17；
4. `A+36`；
5. 指向“值为 `字(B+36)` 的栈上局部字”的地址；
6. `字节(B+31)`；
7. `字节(B+30)`；
8. `N`。

## 4. 调用后精确写入

1. 写 `半字(0x62fc8900) = 低16位(半字(0x62fc8900)+1)`；
2. 写 `半字(D+20)=半字(B+40)`；
3. 写 `半字(D+22)=半字(B+42)`；
4. 写 `半字(D+24)=交换字节(低16位(半字(A+70)+8))`；
5. 写 `半字(D+26)=0`；
6. 调用 `0xa0009e8e(字(A+48), 半字(A+68))`；
7. 写 `半字(0x62fc8928) = 低16位(半字(0x62fc8928)+1)`。

## 5. 能力边界

- 已闭合：180 个源字节、60 条指令、对象半字门禁、长度公式、动态数据起点、
  八个调用参数、两个全局半字递增、四半字布局和已知链调整调用。
- `0xa01a0630` 本体尚未按顺序覆盖，因此只记录八参数现场；该调用的返回值
  在本函数中没有被使用。
- 本函数在两条返回路径前没有统一设定返回寄存器，因此不声明返回值语义。
- 非零路径直接解引用 `字(A+48)` 和第二对象字段，本地没有空值检查。
- 下一字节 `0x00b67c` 开始新的单参数函数。
