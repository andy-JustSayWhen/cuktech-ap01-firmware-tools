# `0x00b6a2..0x00b6c5` 对象七十二节点链多层字累加

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的单参数链表累加函数。入口对象为空时返回零。
对象非空时，原厂从对象 `+72` 读取单向链表首节点，沿每个节点
`+0` 的下一节点地址遍历。每轮从当前节点 `+132` 取第二层对象，
把该对象 `+8` 字加入 32 位累计值。链尾返回低 32 位累加结果。

- 文件偏移：`0x00b6a2..0x00b6c5`
- 执行地址：`0xa000a6a2..0xa000a6c5`
- 长度：36 字节
- 本段原始字节散列：`b4c50a5e40b559e0fa22ebb90435d101b78abd618f01dd39a2dcbc53d15b6103`

## 3. 精确累加规则

令入口对象为 `A`：

1. `A == 0` 时返回零；
2. 否则令 `S=0`、`N=字(A+72)`；
3. 当 `N != 0` 时，令 `Q=字(N+132)`，
   `S=低32位(S+字(Q+8))`，再令 `N=字(N+0)`；
4. 返回 `S`。

## 4. 能力边界

- 循环直接解引用 `字(N+132)`，本地没有空值检查。
- 节点和第二层对象的业务名称保留未定。
- 下一字节 `0x00b6c6` 开始新的函数。
