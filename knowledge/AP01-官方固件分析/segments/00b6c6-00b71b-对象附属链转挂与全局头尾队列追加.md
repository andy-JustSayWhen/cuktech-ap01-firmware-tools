# `0x00b6c6..0x00b71b` 对象附属链转挂与全局头尾队列追加

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的单参数入队函数。入口对象为空时，原厂以固定
文字地址、数值 291 和零调用报告入口。在正常非空路径中，原厂读取
对象 `+132` 的附属链地址；它非空时，调用已通读的逐节点转挂函数
`0xa00099bc(附属链)`。

随后原厂把入口对象 `+0` 的下一指针清零，并将它追加到全局结构
`0x62fc812c` 的单向队列。队首在结构 `+12`，队尾在 `+16`；空队列时
同时写头尾，非空时先把原队尾 `+0` 指向新对象，再更新队尾。
最后以 `0x62fc812c` 调用 `0xa00272cc`。

逐节点转挂函数的唯一原文见：
[`0x00a9bc..0x00a9d3` 原链逐节点受保护转挂循环`](00a9bc-00a9d3-原链逐节点受保护转挂循环.md)。

## 3. 精确入队规则

令正常非空路径的入口对象为 `N`、全局队列结构为
`Q = 0x62fc812c`：

1. 若 `字(N+132) != 0`，调用 `0xa00099bc(字(N+132))`；
2. 写 `字(N+0)=0`；
3. 若 `字(Q+12)==0`，写 `字(Q+12)=N`；
4. 否则写 `字(字(Q+16)+0)=N`；
5. 写 `字(Q+16)=N`；
6. 调用 `0xa00272cc(Q)`。

## 4. 能力边界

- 已闭合：86 个源字节、32 条指令、空值报告实参、附属链转挂调用、对象下一指针、
  全局头尾字段、空与非空队列追加、后续调用和整个函数。
- 本函数把 `字(N+132)` 交给转挂函数后，本地没有清零 `N+132` 字段。
- `0xa0019572` 和 `0xa00272cc` 本体尚未按顺序覆盖，因此不命名效果。
- 空入口路径的报告调用若返回，后续机器码把该调用的返回寄存器内容当作对象地址；
  本文不猜测报告入口是否返回，也不把该路径并入正常入队公式。
- 本函数在返回前没有统一设定返回寄存器，因此不声明返值语义。
- 下一字节 `0x00b71c` 开始新的函数。
