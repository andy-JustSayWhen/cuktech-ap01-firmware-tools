# `0x00b794..0x00b80b` 备选链字节筛选最小值选择与可取链重读

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合执行地址 `0xa000a71c` 开始的大型函数。前段全局可取链
`0x62fc6050` 为空时，原厂在本段从全局地址 `0x62fc8780` 读取
备选单向链首，沿节点 `+0` 遍历。节点 `+48` 字节必须为零；
节点 `+52` 字节必须为零或 5 至 9。在通过这两项筛选的节点中，
原厂保留 `+81` 无符号字节最小的一个；相等时保留先遇到的节点。

没有合格节点时，原厂在不另行准备参数的情况下调用 `0xa003ba8c`，
再返回空值。找到节点时，以它调用 `0xa000ace2`，然后重读全局可取链
`0x62fc6050`。重读仍为空时同样返回空值；非空时摘取其首对象，
回到前段共用的指针清理、320 字节填零和固定初始化路径，最后返回
初始化后对象。

非零条件移动指令的唯一行为原文见：

## 3. 备选节点筛选与选择

令备选链首 `H=字(0x62fc8780)`、当前节点为 `N`。候选必须满足：

1. `字节(N+48)==0`；
2. `字节(N+52)==0` 或 `5 <= 字节(N+52) <= 9`。

遍历所有合格节点，选出 `字节(N+81)` 按无符号数最小的一个；
比较仅在严格小于时替换，因此相等时保留先遇节点。

## 4. 选择后重读与返回

- 无合格节点：不另行准备参数就调用 `0xa003ba8c`，返回空值；
- 有合格节点 `S`：调用 `0xa000ace2(S)`，再重读 `0x62fc6050` 链首；
- 重读为空：转到无对象返回路径；
- 重读非空：按前段同样的头对象摘取规则处理，然后共用填零和初始化；
- 共同尾返回初始化后对象或空值。
