# `0x00b8fc..0x00b949` 对象附属头尾链逐节点摘取与字段清理

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个新的单参数函数。输入对象为空时立即返回；输入对象非空时，
读取其 `+236` 字所指结构并立即把该字段清零。若该结构存在，原厂反复
从其 `+8` 头指针摘取节点，并在摘到最后一个节点时同步清零 `+12` 尾指针。

每个节点的 `+4` 字是一个可空对象地址。地址为空时继续摘取下一个节点；
地址非空时，原厂清零该对象的 `+232` 字、`+236` 字和 `+48` 字节，调用
`0xa000ace2(该对象)`，然后继续摘取。头指针为空后，调用
`0xa002e0a0(附属结构)` 并返回。

## 3. 精确控制流

令输入对象为 `A`、附属结构为 `S=字(A+236)`：

1. `A==0` 时直接返回；`S==0` 时恢复现场并返回。
2. `S!=0` 时先写 `字(A+236)=0`，随后循环读取 `N=字(S+8)`。
3. `N!=0` 时写 `字(S+8)=字(N+0)`；若新头为空，再写
   `字(S+12)=0`。之后读取 `X=字(N+4)` 并写 `字(N+0)=0`。
4. `X==0` 时继续循环；`X!=0` 时写 `字(X+232)=0`、
   `字(X+236)=0`、`字节(X+48)=0`，调用 `0xa000ace2(X)` 后继续循环。
5. `N==0` 时调用 `0xa002e0a0(S)`，然后返回。
