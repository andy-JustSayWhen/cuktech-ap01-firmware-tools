# `0x00bc2c..0x00bca3` 分段链双端消费转交与对象字段归零

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的三参数函数。令第一对象为 `A`、第二对象为 `B`、
第三参数为 `C`，初始分段链首为 `P=字(A+48)`。若 `C` 非零，原厂
先调用已通读的 `0xa0009c4a(P, C)` 从链首消费，并把调用留下的链首
保存回局部变量。

随后令 `H=无符号半字(A+68)`、`T=字(P+8)`。当 `H<T` 时，原厂调用
已通读的 `0xa0009cc4(P, T-H)` 从链尾消费，并保存返回的新链首；
当 `H>=T` 时不做链尾消费。原厂接着读取当前链首 `+8` 的低半字作为
本函数返回值，以 `0xa01b0e10(B+144, &局部链首)` 转交链首，再清零
`A+48` 字、`A+60` 字和 `A+68` 半字，调用 `0xa0052262(3, B)` 后返回。

## 3. 精确链处理

令 `P=字(A+48)`：

1. `C!=0` 时执行 `P=0xa0009c4a(P, C)`；该函数的唯一原文见
   [`00ac4a-00acc3 分段链头消费与整节点转挂推进`](00ac4a-00acc3-分段链头消费与整节点转挂推进.md)。
2. 令 `H=无符号半字(A+68)`、`T=字(P+8)`；若 `H<T`，执行
   `P=0xa0009cc4(P, T-H)`；该函数的唯一原文见
   [`00acc4-00ad39 分段链尾消费与末节点逐轮转挂`](00acc4-00ad39-分段链尾消费与末节点逐轮转挂.md)。
3. 保存 `R=无符号半字(P+8)`，调用 `0xa01b0e10(B+144, &P)`。
4. 清零 `字(A+48)`、`字(A+60)`、`半字(A+68)`，调用
   `0xa0052262(3, B)`，返回 `R`。
