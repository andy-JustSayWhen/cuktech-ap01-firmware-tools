# `0x00bca4..0x00bce1` 二十项全局指针表半字与通配字查找

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的两参数查找函数。第一参数 `A` 是一个字地址，第二参数
为半字匹配值 `H`。原厂顺序扫描从 `0x62fc8958` 开始的二十个四字节
指针项，跳过空项，并要求候选对象 `+86` 半字等于 `H`。

半字命中后，候选对象 `+32` 字若等于 `字(A)`，或候选对象 `+32` 字
本身为零，原厂立即返回该候选对象；否则继续扫描。二十项均不命中时
返回空指针。

- 执行地址：`0xa000aca4..0xa000ace1`

## 3. 精确匹配规则

对索引 `I=0..19`，令 `N=字(0x62fc8958+4*I)`：

1. `N==0`：继续下一项；
2. `无符号半字(N+86)!=H`：继续下一项；
3. `字(N+32)==字(A)`：返回 `N`；
4. `字(N+32)==0`：返回 `N`；
5. 否则继续下一项。

循环结束仍未返回时，返回零。

## 4. 能力边界

- 已闭合：62 个源字节、22 条指令、全局表基址、四字节项宽、固定二十项
  上限、空项跳过、半字精确匹配、对象字精确匹配、零值通配、首命中返回、
  未命中返回和整个函数。
- 第一参数在半字命中后会被直接解引用，本函数没有本地空指针检查；
  本段只记录该原厂前置条件。
- 候选对象 `+32` 的零值通配只发生在 `+86` 半字已经命中之后。
- 下一字节 `0x00bce2` 是另一个新函数入口。
