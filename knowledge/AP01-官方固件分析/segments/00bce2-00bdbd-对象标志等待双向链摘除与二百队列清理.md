# `0x00bce2..0x00bdbd` 对象标志等待双向链摘除与二百队列清理

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是执行地址 `0xa000ace2` 开始的大型单参数函数前半。令输入对象为
`A`。原厂先调用 `0xa01b0f4e(A)`；若 `A+48` 字节非零则执行固定报告。
若 `A+136` 半字的 `0x04` 位为一，再调用 `0xa002cfbe(1, A+260)`：
调用返回非零时执行共同末调用并提前返回，返回零时继续清理。

继续路径先调用 `0xa002cfbe(1, A+56)` 和 `0xa000bece(A)`，再沿
`A+8` 头指针逐节点处理。每轮保存当前节点的下一指针，以
`0xa003c5be(字(A+140), 当前节点, A+8, A+12)` 调用后继续。

头链为空后，除非 `A+52` 字节等于 1，原厂会按 `A+0` 下一指针和
`A+4` 前一指针把对象从全局双向链 `0x62fc8780/0x62fc8784` 摘除，
再清零对象两个链字段。随后调用 `0xa000ae7e(A)`，并逐项摘取
`A+200/A+204` 头尾队列节点，清节点下一指针后调用 `0xa000c0d4(节点)`。

## 3. 链与队列规则

`A+8/A+12` 头尾链按如下循环处理：

1. 读取当前头节点 `N=字(A+8)`；
2. 保存 `Next=字(N+0)`；
3. 调用 `0xa003c5be(字(A+140), N, A+8, A+12)`；
4. 令 `N=Next` 并重复，直到为空。

若 `字节(A+52)!=1`，按 `Prev=字(A+4)`、`Next=字(A+0)` 从全局
双向链摘除：`Prev` 存在就写 `Prev+0=Next`，否则写全局头为 `Next`；
`Next` 存在就写 `Next+4=Prev`，否则写全局尾为 `Prev`。最后清零
`A+0/A+4`。

`A+200/A+204` 队列每轮摘头；摘到最后节点时同步清尾，清当前节点
`+0` 后调用 `0xa000c0d4(当前节点)`，直至头为空。
