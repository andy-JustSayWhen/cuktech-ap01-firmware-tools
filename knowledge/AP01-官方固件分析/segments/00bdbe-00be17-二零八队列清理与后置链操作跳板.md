# `0x00bdbe..0x00be17` 二零八队列清理与后置链操作跳板

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段接续执行地址 `0xa000ace2` 开始的大型单参数函数。原厂先逐项摘取
输入对象 `A` 的 `+208/+212` 头尾队列：每轮推进头指针，摘到末节点时
清尾，清当前节点下一指针，再调用 `0xa000c0d4(当前节点)`。

队列之后的地址 `0x00bde0..0x00be05` 是由后方控制流反向跳入的五个
小块，分别负责：从活动链中绕过非尾匹配节点、更新活动头尾、沿活动链
推进、把匹配节点接到另一条头尾链尾部，以及把输入对象接到全局回收链
旧尾。这些小块的跳入条件由下一段 `0x00be18` 后方指令决定，本段保存
每条写操作，但不单独把尚未出现的来源条件宣称为已闭合。

主顺序在 `0x00be06` 恢复：调用 `0xa000bac4(A)`，若 `A+236` 字非零，
再调用已经闭合的 `0xa000a8fc(A)` 附属头尾链清理函数。

## 3. 第二组队列

对 `A+208/A+212` 头尾队列，令当前头为 `N`：

1. 写 `字(A+208)=字(N+0)`；
2. 新头为空时写 `字(A+212)=0`；
3. 写 `字(N+0)=0`；
4. 调用 `0xa000c0d4(N)`；
5. 重复直到头为空。

`0xa000a8fc` 的唯一原文见
[`00b8fc-00b949 对象附属头尾链逐节点摘取与字段清理`](00b8fc-00b949-对象附属头尾链逐节点摘取与字段清理.md)。

## 4. 能力边界

- 已闭合：90 个源字节、33 条指令、`+208/+212` 头尾队列摘取循环、
  末节点尾清零、节点断链、两个主顺序调用，以及五个后置链操作块的
  逐条读写效果。
- 五个后置块的寄存器角色已由同一函数后方控制流核对，但其进入条件、
  活动链来源和追加完成路径要到下一连续段才整体闭合。
- `0xa000c0d4` 与 `0xa000bac4` 本体尚未按当前顺序覆盖，因此只记录调用
  地址、实参和本地控制流，不命名其外部效果。
- 当前大型函数尚未结束；下一字节 `0x00be18` 开始定位输入对象在另一
  对象附属活动链中的节点，并与本段后置小块接合。
