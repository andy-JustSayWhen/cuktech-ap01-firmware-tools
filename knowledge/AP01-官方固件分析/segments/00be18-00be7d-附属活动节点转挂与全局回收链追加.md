# `0x00be18..0x00be7d` 附属活动节点转挂与全局回收链追加

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合执行地址 `0xa000ace2` 开始的大型单参数函数。令输入对象为
`A`。原厂通过 `字(A+232)` 再取其 `+236` 字所指结构 `S`，在
`S+8/S+12` 活动头尾链中寻找首个 `+4` 字等于 `A` 的节点 `N`。

命中后，原厂把 `N` 从活动链摘除，清 `N+0` 下一指针和 `N+4` 对象
指针，再把它追加到 `S+0/S+4` 另一条头尾链。活动链头、中间、尾和
唯一节点四种位置分别与上一段的反向跳转块接合；未找到则跳过转挂。

最后，原厂把 `A` 追加到全局头尾链 `0x62fc6050`：清 `A+0`，把
`A+52` 字节清零，把 `A+4` 设为旧尾；非空链令旧尾 `+0` 指向 `A`，
空链则把全局头设为 `A`，两路都把全局尾设为 `A`。随后跳回共同末
调用 `0xa003ba8c` 并返回。

## 3. 活动链转挂

令 `P=字(A+232)`、`S=字(P+236)`，活动链为 `S+8/S+12`，另一条
链为 `S+0/S+4`。原厂在活动链中顺序寻找 `字(N+4)==A` 的首个节点。

- `N` 是活动头：写 `字(S+8)=字(N+0)`；新头为空时清 `S+12`；
- `N` 是中间节点：写 `字(Prev+0)=字(N+0)`；
- `N` 是活动尾：写 `字(S+12)=Prev`、`字(Prev+0)=0`；
- 随后清 `N+0/N+4`，把 `N` 追加到 `S+0/S+4` 链尾。

上一段的 `0x00bde0..0x00be05` 小块由这里反向跳入，其进入条件、寄存器
角色、字段写入和返回去向至此全部闭合。

## 4. 全局回收链与能力边界

全局回收链 `G=0x62fc6050` 的追加公式为：

- `字(A+0)=0`、`字节(A+52)=0`、`字(A+4)=字(G+4)`；
- 旧头非空时写 `字(字(G+4)+0)=A`，否则写 `字(G+0)=A`；
- 写 `字(G+4)=A`。
