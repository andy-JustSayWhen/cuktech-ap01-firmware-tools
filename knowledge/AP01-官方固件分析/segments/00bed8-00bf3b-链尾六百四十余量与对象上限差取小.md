# `0x00bed8..0x00bf3b` 链尾六百四十余量与对象上限差取小

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个两参数长度计算函数前半。令第一对象为 `A`、第二对象为 `B`。
若 `B+144` 分段链非空，原厂遍历到末节点，以
`640-无符号半字(末节点+6)-无符号半字(末节点+4)` 得到末段余量 `R`；
链空时先令 `R=0`。

随后调用已通读的 `0xa0009a76(1)` 得到非负计数 `C1`。`C1>0` 时
令 `R=R+C1*640`。`C1==0` 且分段链非空时保留原末段余量；若链也为空，
后方会调用 `0xa0009a76(0)` 并结合第一对象字段计算替代上限，该分支位于
下一段。

共同路径读取分段链首 `+8` 总量 `T` 和 `B+112` 上限 `L`：仅当
`T<L` 时产生候选差值 `L-T`，并把它限制为不大于 `R`；否则候选值为零。

## 3. 当前公式

若 `P=字(B+144)` 非空，遍历得到末节点 `N`：

`R=640-无符号半字(N+6)-无符号半字(N+4)`

若 `P` 为空：`R=0`。

令 `C1=0xa0009a76(1)`。其唯一原文见
[`00aa76-00aa95 全局有符号半字减二十四非负截断`](00aa76-00aa95-全局有符号半字减二十四非负截断.md)。

- `C1>0`：`R=R+C1*640`；
- `C1==0 && P!=0`：`R` 保持末段余量；
- `C1==0 && P==0`：进入下一段替代上限分支。

共同路径令 `T=P!=0 ? 字(P+8) : 0`、`L=字(B+112)`，得到：

`S = T<L ? min(L-T, R) : 0`

## 4. 能力边界

- 已闭合：100 个源字节、36 条指令、链尾遍历、两个末节点半字、六百四十
  余量公式、已通读计数调用、正值乘加、链首总量、对象上限差和首次取小。
- 末段余量使用无符号 32 位减法，本段没有在两个末节点半字之和大于
  640 时单独截零；只记录原厂算术事实。
- 当前函数尚未结束；下一字节 `0x00bf3c` 处理十二字节记录的额外限制、
  最终十六位封顶，以及 `C1==0 && P==0` 的替代上限分支。
