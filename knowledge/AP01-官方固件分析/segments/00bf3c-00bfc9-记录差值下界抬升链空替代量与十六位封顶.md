# `0x00bf3c..0x00bfc9` 记录差值下界抬升链空替代量与十六位封顶

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段闭合执行地址 `0xa000aed8` 开始的两参数长度计算函数。令第一对象
为 `A`、第二对象为 `B`，前段候选值为 `S`。

若 `B+148` 元素数非零，原厂调用 `D=0xa000afca(B+40)`，计算
`W=字(B+152)-D`；再调用 `Q=0xa000b1d0(B)` 并计算 `S'=S-Q`。
同时计算 `V=低十六位(无符号半字(A+28)-40-字节(A+25))`，随后执行
两次下界抬升：先令 `V=max(V,W)`，再把按有符号数为负的 `S'` 截为零，
最后令 `S=max(S',V)`。这两处是取较大值，不是取较小值。

若前段 `0xa0009a76(1)` 返回零且 `B+144` 链也为空，本段改调
`C0=0xa0009a76(0)`，令替代余量为 `min(V,C0*640)`，再回到前段共同
上限差计算。所有路径最终把返回值无符号封顶为 `65535`。

## 3. 完整返回公式

前段先得到链相关余量 `R`，再得到：

`S0 = T<L ? min(L-T, R) : 0`

其中 `T` 是 `B+144` 链总量，`L=字(B+112)`。若 `字节(B+148)==0`，
直接返回 `min(S0,65535)`。

若元素数非零，令：

- `D=0xa000afca(B+40)`；
- `W=字(B+152)-D`；
- `Q=0xa000b1d0(B)`；
- `V=低十六位(无符号半字(A+28)-40-字节(A+25))`；
- `S1=S0-Q`，若 `S1` 按有符号 32 位小于零则改为零；
- `S2=max(S1,max(V,W))`。

最终返回 `min(S2,65535)`。

前段计数为零且链空时，先令
`R=min(V,0xa0009a76(0)*640)`，再进入 `S0` 公式。
