# `0x00bff6..0x00c047` 四参数门禁半字输出与分级负值返回

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的四参数函数。令四个参数依次为对象 `A`、数值 `B`、
输出字地址 `C`、输入输出字地址 `D`。`C` 或 `D` 为空时进入固定报告。
正常路径要求 `字节(A+1)==1`、`B==20`、`字(D)>3`。

三项依次失败时分别返回 `-107`、`-92`、`-22`。全部满足时，原厂从
`字(A+4)` 所指对象读取 `+90` 无符号半字，以完整字写入 `C`，再把
`字(D)` 写为 4，返回零。

## 3. 精确返回与写入

在 `C!=0 && D!=0` 的正常路径中：

- `字节(A+1)!=1`：返回 `-107`；
- 否则 `B!=20`：返回 `-92`；
- 否则 `无符号字(D)<=3`：返回 `-22`；
- 否则写 `字(C)=无符号半字(字(A+4)+90)`、`字(D)=4`，返回 0。

失败返回均不写 `C` 或 `D`。

## 4. 能力边界

- 已闭合：82 个源字节、29 条指令、两个指针前置条件、三项顺序门禁、
  三个负返回值、半字来源、两个完整字写入、成功返回和整个函数。
- `C` 或 `D` 为空的报告路径建立了栈帧、改写了参数寄存器，却没有在
  本函数可见代码中恢复栈帧或原参数便直接落入正常路径；因此本段不声称
  报告调用返回后能安全续接，该路径依赖报告目标的后续本体证据。
- 正常路径读取 `A+1/A+4` 前没有本地空指针检查；成功路径还会直接读取
  `字(A+4)+90`。
- 下一字节 `0x00c048` 是另一个新函数入口。
