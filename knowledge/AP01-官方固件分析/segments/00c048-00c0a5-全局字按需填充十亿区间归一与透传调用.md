# `0x00c048..0x00c0a5` 全局字按需填充十亿区间归一与透传调用

返回总账：[`AP01 原厂固件逐字节与逐指令通读总账`](../原厂固件逐字节与逐指令通读总账.md)

本段是一个完整的单参数函数。原厂读取全局字 `G=字(0x62fc8bac)`。
若 `G` 非零，直接调用 `0xa000bbd2(入口对象, G)` 并透传返回值。

若 `G` 为零，原厂先调用 `0xa003c228(0x62fc8bac, 4)`，然后重读全局字，
计算它无符号除以 `2,000,000,000` 的余数。余数大于 `999,999,999`
时保持不变；否则加 `1,000,000,000`。所得值写回全局字后，再调用
`0xa000bbd2(入口对象, G)` 并返回该调用结果。

## 3. 归一公式

仅当入口读取的 `G==0` 时：

1. 调用 `0xa003c228(&G, 4)` 并重读 `G`；
2. `R=G mod 2,000,000,000`；
3. `G=R<=999,999,999 ? R+1,000,000,000 : R`；
4. 写回 `G`。

因此该按需归一路径写回范围为
`1,000,000,000..1,999,999,999`。

## 4. 能力边界

- 已闭合：94 个源字节、34 条指令、全局地址、零值门禁、四字节填充
  调用、无符号取模、十亿分界、条件加法、全局写回、后续调用和透传返回。

  交给后续调用；区间保证只属于入口值为零时执行的按需归一路径。
