# AP01 硬件接口与驱动证据

## 1. 处理器与基础外设

主程序可按 32 位 RISC-V 指令正确反汇编。固件工程路径使用 `AP01_BL618`，底层驱动路径包含 `bl616`。固件中直接出现下列驱动类别：

- 直接存储访问、串口、定时器、模数转换、脉宽调制；
- 串行闪存、加密单元、随机数、电子熔丝；
- Wi-Fi、BLE、看门狗；
- 串行外设接口和通用输入输出。

对应设备节点包括：

| 类别 | 设备节点 |
| --- | --- |
| 模数转换 | `/dev/adc0`、`/dev/adc1`、`/dev/adc4` |
| 屏幕 | `/dev/fb0` |
| 通用输入输出 | `/dev/gpio3`、`/dev/gpio12` |
| 旋钮输入 | `/dev/input0` |
| 更新与固件槽 | `/dev/ota`、`/dev/fw1`、`/dev/fw2` |
| 数据与资源 | `/dev/data`、`/dev/resource`、`/dev/reserve` |
| 脉宽调制 | `/dev/pwm0` |
| 串口 | `/dev/ttyS0`、`/dev/ttyS1`、`/dev/ttyS2`、`/dev/ttyHCI0` |
| 保护与安全 | `/dev/watchdog0`、`/dev/efuse`、`/dev/random`、`/dev/crypto` |

设备节点证明固件注册了对应软件接口，不证明每个接口都在产品外壳上暴露给用户。

## 2. 屏幕

固件包含：

- `jd9853_spi_init` 屏幕控制器初始化；
- `/dev/fb0` 帧缓冲设备；
- 320×240 的完整页面资源；
- LVGL 图形界面、PNG 解码器、GIF 解码器和二进制图像解码器；
- 屏幕亮度与熄屏控制。

固件直接证明设备画布为 320×240。屏幕物理尺寸、亮度数值和面板材料不由当前固件字节直接证明，本文不写入这些数值。

## 4. 底座触点与充电数据

固件模块包括：

- `PogoPinMng/UartComm.c`
- `EsUnitProtocol.c`
- `UsbIfaceMng.c`
- `UsbIfaceOta.c`
- `FactoryTestMode.c`
- `MiIotMng.c`
- `UiIFaceMng.c`
- `WeatherApi.c`
- `BuzzerMng.c`

由这些模块和相关可读记录可确认：

1. 屏幕通过底座触点侧串口与电能基站通信；
2. 模数转换通道用于识别触点、温度和端口状态；
3. 通信帧包含循环冗余校验；
4. 屏幕可读取端口电压、电流、功率、状态、温度和电池管理数据；
5. 固件处理 C1、C2 端口以及 PD（USB 供电协商规则）、PPS（可细调电压电流的供电规则）、 UFCS（融合快速充电规则）和 QC（高通快速充电规则）等充电协议信息；
6. 固件包含端口开关、放心充和自定义功率模式相关界面与控制记录。

`UsbIface` 在本固件中属于充电接口数据管理模块，不是已证明的 AP01 外露刷机接口。

## 5. 其他实体部件

- 蜂鸣器由 `BuzzerMng.c` 管理；
- 背光使用脉宽调制调节；
- 工厂测试使用 `/dev/gpio3` 输入和 `/dev/gpio12` 输出；
- 看门狗用于检测程序失去响应；
- 电子熔丝和加密设备为设备身份与安全能力提供底层接口。

上述结论来自原厂驱动文字、设备节点和调用关系的交叉核对。
