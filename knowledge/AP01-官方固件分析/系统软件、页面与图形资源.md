# AP01 系统软件、页面与图形资源

返回主文档：[`AP01 官方固件分析`](AP01-官方固件分析.md)

## 1. 系统软件

固件中存在以下直接组件证据：

| 组件 | 在设备中的作用 |
| --- | --- |
| NuttX | 任务、设备、文件系统和命令环境 |
| NSH | NuttX 自带的设备命令环境 |
| LVGL | 绘制屏幕页面、控件、动画和图片 |
| libuv | 处理异步任务、定时和网络事件 |
| mbedTLS | 加密、证书与安全网络连接 |
| `miio-client 4.0.4.1` | 米家设备通信 |

固件启动应用记录包括 `lvgl_ui_main`、`mible_mesh_common_bt` 和 `miio_client`，
分别对应图形界面、米家蓝牙相关任务和米家设备通信。

## 2. 文件系统与配置

固件包含只读文件系统、临时文件系统、FAT 文件系统和 LittleFS。直接路径包括：

- `/etc`
- `/data`
- `/resource`
- `/data/sysconfig.bin`
- `/data/wapi.conf`

`/data/sysconfig.bin` 的原厂持久化字段包括：

- `ShowType`
- `TimeShowType`
- `ScreenSave`
- `ScreenOff`
- `ScreenBackLight`
- 配置校验值

固件含 `SysSettingsInit`、`SysSettingsWrite`、`sysconfig.bin Reset` 和
`FactoryRestore` 相关代码。由此确认原厂设置会写入设备闪存，恢复出厂设置会重置系统设置。

当前字段中没有一级页面显隐配置。

## 3. 原厂一级页面

固件直接存在以下创建函数：

| 页面 | 创建函数 |
| --- | --- |
| 时钟 | `lv_page_ui_time1_create` |
| 功率 | `lv_page_ui_power1_create` |
| 天气 | `lv_page_ui_weather1_create` |
| 日历 | `lv_page_ui_date1_create` |
| 设置 | `lv_page_ui_setting_create` |
| 虚拟形象 | `lv_page_ui_virchar_create` |

窗口管理代码包含添加窗口、读取窗口数、按序号切换当前窗口等操作，证明这些页面由统一的
一级窗口导航管理。

固件中确认存在：

- 功率详情、端口列表、模式选择、充电协议助手和放心充；
- 时间设置、日期详情和天气详情；
- 屏幕亮度、版本信息、在线更新和恢复出厂设置；
- 屏幕常亮、屏幕保护、操作指南；
- 开机引导、设备检测、弹窗和屏保页面。

与设置相关的原厂中文文字包括：

- `屏幕常亮`
- `屏幕保护`
- `操作指南`
- `屏幕亮度`
- `版本信息`
- `恢复出厂设置`

## 5. 图形资源统计

对完整固件逐字节扫描并实际解码：

| 格式 | 扫描结果 |
| --- | --- |
| PNG | 200 个文件头，其中 199 个可完整解码，1 个是程序数据中的偶合字节 |
| GIF89a | 10 个可完整解码 |
| JPEG（常见照片格式） | 未找到可解码资源 |

199 张 PNG 中，195 张带有可识别的 LVGL 资源描述，声明数据总量为 639,058 字节；
另外 4 张是连续存放的可解码资源。图片包括品牌标志、二维码、天气图标、数字、功率仪表、
操作引导和完整页面。

## 6. 对第三方画面的直接约束

1. AP01 设备画面必须按 320×240 制作。
2. 原厂软件直接具备 PNG 和 GIF 解码能力。
3. 参考项目当前真机加载链路只验证了 GIF89a、320×240、至少两帧。
4. 参考项目的 256KB 是当前网络接收和三个临时内存槽的实现限制，不是原厂解码器上限。
5. 采用 PNG 静态资源、不同动图体积或新的内存布局前，必须完成设备端加载实现与真机验证。

案例证据：[`2026-07-25 全量静态分析记录`](cases/2026-07-25-1.0.2_0031全量静态分析.md)
