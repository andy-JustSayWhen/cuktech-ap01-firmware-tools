## 证据使用规则

1. “固件直接证明”只用于能从当前已校验固件中复查的事实。
2. “参考项目已真机验证”必须能指向参考项目中的代码、日志或验证记录。
3. 固件中没有出现的能力写成“未在本次固件中发现”，不得据此断言硬件绝对不存在。
4. 固件含有实现代码但尚未做真机破坏性测试时，分别记录“代码存在”和“真机未验”，
   不把两者合并成成功结论。
5. 固件版本变化后，所有地址、尺寸、校验值和修改方法全部重新分析。
