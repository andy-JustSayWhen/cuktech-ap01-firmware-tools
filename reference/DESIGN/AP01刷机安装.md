# AP01 刷机安装技术实现

本文实现 [`SPEC-INSTALL-001`](../SPEC.md#spec-install-001-按来源执行安装和验收)，并说明当前项目怎样执行各刷机子 SOP。固件选择、来源判定、需要执行的步骤和验收标准只以 [`如何刷机`](../../SOP/如何刷机.md) 及其子文档为准；本文只记录对应的项目代码、调用顺序和输出。

## 1. 子 SOP 与实现的对应关系

| 子 SOP | 适用情况 | 项目实现 |
| --- | --- | --- |
| [`官方固件刷机流程`](../../SOP/官方固件刷机流程.md) | README 标为官方，或用户明确说明来自官方 | `tools/ota_https_serve.py` 提供临时固件服务，`tools/ota_dispatch.py` 直接下发安装 |
| [`ap01-1.0.2_0031-opt刷机流程`](../../SOP/ap01-1.0.2_0031-opt刷机流程.md) | 看板服务地址已写入或需要写入个人固件 | 个人固件制作入口生成固件，`app/ap01_firmware.py firmware-install` 回读临时固件服务后下发并轮询 |
| [`ap01-1.0.2_0031-opt-setting刷机流程`](../../SOP/ap01-1.0.2_0031-opt-setting刷机流程.md) | 设置阶段固件 | 按该子文档转交的流程处理 |
| [`如何部署服务端`](../../SOP/如何部署服务端.md) | 看板个人固件安装后 | `tools/deploy-agents-dashboard.ps1` 或 `tools/deploy-agents-dashboard.sh` 复制并启动独立服务 |

## 2. 代码职责

| 位置 | 职责 |
| --- | --- |
| `app/ap01_firmware.py` | 提供固件状态查询、个人固件构建和第三方固件安装入口。 |
| `features/firmware_installation/install.py` | 选择唯一 AP01、读取安装地址、核对第三方固件读回内容、下发安装并轮询状态。 |
| `features/official_firmware_source/xiaomi_cloud.py` | 使用本机登录态查询设备和转发设备安装指令。 |
| `tools/ota_https_serve.py` | 在本机 443 端口按 `/miio_fw/<固件文件名>` 提供临时自签 HTTPS（网页使用的加密连接）文件服务。 |
| `tools/ota_dispatch.py` | 对官方固件选择唯一 AP01 后直接发送一次 `miIO.ota`（米家固件升级指令）。 |

## 3. 官方固件直接安装

官方子 SOP 已确认固件来源、目标设备唯一且空闲后，启动 `ota_https_serve.py`。随后 `ota_dispatch.py` 读取指定文件的长度和校验值，选择账号内唯一 AP01，并将下列参数发送给设备：

- 临时服务地址；
- 文件校验值和文件长度；
- 允许设备接受本机自签 HTTPS 服务的参数；
- 同版本重刷所需的强制安装参数。

此路径不进行本机从临时服务读回文件。`ota_dispatch.py` 只负责下发，下载、安装、重启和重新上线由官方子 SOP 的状态查询与屏幕验收确认。

## 4. 第三方看板个人固件安装

看板个人固件使用 `firmware-install`。它在发送设备安装指令前，先由当前电脑从临时服务读回文件，与本地个人固件逐字节比较；不一致时停止。比较通过后，代码选择唯一 AP01，发送安装指令，并轮询下载、安装、重启和重新上线状态。

该入口的实际参数由看板子 SOP 提供：固件文件、登录态文件、临时服务地址和自签 HTTPS 参数。它不读取或保存看板服务地址；看板服务地址只存在于个人固件制作时读取的 `env/agents-dashboard.env`。

## 5. 结果记录

每次下发都在 `artifacts/install-records/` 写入带时间的记录文件。

| 路径 | 记录必须证明的内容 |
| --- | --- |
| 官方直接安装 | 设备接受指令；后续状态查询证明下载、安装、重启、重新上线和空闲。 |
| 第三方看板个人固件 | 临时服务读回内容与本地文件一致；设备接受指令；观察到安装和重启。 |

命令报错、记录被截断或设备未重新上线时，不得宣布刷机成功；保留记录并按 [`刷机失败案例及解决办法`](../../knowledge/刷机失败案例及解决办法.md) 处理。

## 6. 服务端部署

看板个人固件的服务端不随固件安装程序复制。设备安装完成后，按 [`如何部署服务端`](../../SOP/如何部署服务端.md) 在当前服务电脑使用对应系统的一键程序部署。部署目录独立于项目仓库，登录状态不进入部署目录。
