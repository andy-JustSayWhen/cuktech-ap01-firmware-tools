# `ap01-1.0.2_0041-opt.bin` 技术实现

本文实现 [`ap01-1.0.2_0041-opt.bin 需求简述`](../BRIEF/ap01-1.0.2_0041-opt.bin.md) 和 [`ap01-1.0.2_0041-opt.bin 功能规格`](../SPEC/ap01-1.0.2_0041-opt.bin.md)。0031 看板功能的业务规则、画面和连续页面事件规则仍以 [`0031 技术实现`](ap01-1.0.2_0031-opt.bin技术实现/ap01-1.0.2_0031-opt.bin技术实现.md) 为唯一原文；本文件只记录 0041 的不同事实。

## 1. 原厂功能复用检查

分析输入为只读 `ap01-1.0.2_0041.bin`。直接证据、调用过程和可安全使用范围见 [`0041 页面与旋钮接入分析`](../../knowledge/AP01-官方固件分析/1.0.2_0041 页面与旋钮接入分析.md)。0041 的页面调度、萌宠局部回调、设置列表和原厂函数地址均已重新定位；构建器必须对每个新位置断言原字节，任何不一致立即停止。

官方新增功能的代码和资源不属于批准修改区间。页面过滤只拦截原有一级页面调度号 4、5、7；不改变插件设置、夜间模式、蜂鸣器或按键返回的原厂分支。

## 2. 完成条件

构建器必须以 0041 基线重新计算文件尾恢复校验，输出与原厂的差异只能落在批准区间；完成自动测试和连续页面事件模拟后才可写出只读成品。离线通过不替代真机验收。

## 3. 个人固件与取数

公开成品不含服务地址，不能直接安装。个人构建器只从 `env/agents-dashboard.env` 读取地址，在单独输出目录制作 `ap01-1.0.2_0041-opt-personalized.bin`；地址只进入该文件和构建记录，不得写入仓库、文档或公开成品。

个人固件继续使用原厂页面定时回调作为启动点。0041 对应回调地址装入指令位于文件偏移 `0x5e0f2` 与 `0x5e0fc`，构建器断言其原字节为 `37f50aa0` 与 `13052526`，仅将回调入口改为看板包装函数。包装函数先启动独立定时器，再调用原厂回调；看板取数直接调用 0041 原厂网络函数，不修改原厂天气、插件设置、夜间模式、蜂鸣器或按键快速返回分支。

临时固件服务、上传后回读和单次安装按 [`0041 优化固件刷机流程`](../../SOP/ap01-1.0.2_0041-opt刷机流程.md) 执行。只有个人构建、服务检查、回读和严格页面模拟全部通过，且唯一设备仍空闲时，才可下发一次安装。
