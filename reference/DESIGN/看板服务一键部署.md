# 看板服务一键部署

本设计实现 [`SPEC-TOOLS-006`](../SPEC.md#spec-tools-006-看板服务一键部署)。代码组织采用 [`Architecture.md`](../Architecture.md) 规定的 `features/agents_dashboard`。

## 1. 范围

刷机只部署当前电脑。地址表中的其他电脑不是本次刷机步骤，由用户在对应电脑上自行运行一键部署程序。部署结果存放在仓库外；项目仓库仅作为复制来源。

## 2. Windows

`tools/deploy-agents-dashboard.ps1` 复制 `features/agents_dashboard`、其图标和 `fonts` 到目标目录，生成 `run-bridge.ps1`，并以“AP01 Agents Dashboard”登记当前用户登录自启动任务。传入 `-Start` 时，脚本启动服务并检查本机健康状态。

## 3. macOS

`tools/deploy-agents-dashboard.sh` 复制与 Windows 相同的服务代码和字体到目标目录，生成登录自启动文件，先做语法检查再登记当前用户登录自启动服务，随后检查本机健康状态。它只接受当前项目的文件作为复制来源，不复制用户登录状态和临时结果。

## 4. 共同行为

两个脚本均默认使用各自系统的用户应用数据目录，允许传入目标目录、端口和刷新周期。目标目录已有部署文件或端口已被占用时停止，防止覆盖未知服务。完成判定和用户命令见 [`如何部署服务端`](../../SOP/如何部署服务端.md)。
