# Feature：查看周剩余额度详情

| 项目 | 当前值 |
| --- | --- |

本项目采用 FCMA 架构，详细内容见 [`Architecture.md`](../../Architecture.md)。看板数据和导航
公共合同见 [`SPEC.md`](../../SPEC.md)。

## 1. 用户目标

AP01 用户可以查看当前周剩余额度、重置时间和每张可用重置卡的完整时间信息。

## 2. 前端入口与显示

- 用户在 AGENTS 看板概览按下并松开旋钮后，首先显示本 Feature；
- 页面显示：
  - 本周剩余进度条；
  - 本周剩余百分比；
  - 下次重置倒计时；
  - 下次重置时间；
  - 可用重置卡数量；
  - 每张重置卡的发放时间、到期时间和过期倒计时；
- 页面不提供“使用重置”操作；
- 参考图中的其他按钮、字段或状态不进入本 Feature。

## 3. 用户操作与结果

- 第一次进入 AGENTS 详情区域时，用户直接看到本页面；
- 用户向右旋转时，由应用入口显示“查看今日消耗详情”；
- 用户向左旋转时，由应用入口显示“查看近 30 天消耗详情”；
- 用户按下并松开旋钮时，由应用入口返回 AGENTS 看板概览；
- 本 Feature 只输出自己的显示结果，不直接切换或调用其他 Feature。

## 4. 服务端与设备端表现

- 所有字段读取公共周额度数据结果；
- 百分比、进度条和重置卡数量必须来自同一次成功结果；
- 每张重置卡的发放、到期和倒计时必须互相对应；
- 服务端生成完整页面后才替换最后一次成功页面；
- 刷新失败时继续显示本 Feature 最后一次成功页面；
- 单个字段无法准确取得时显示“无法获取”，不得估算。

## 5. 独立状态与公开结果

本 Feature 独立拥有当前周额度详情画面和最后一次成功画面。公开输入是公共周额度数据结果，
公开结果是一份完整的周额度详情画面及其是否可用。

## 6. 公共能力依赖

- 周额度公共数据读取与统一能力；
- 时间和倒计时格式能力；
- 画面合成与格式校验能力；
- 最后成功结果保存能力；
- 应用入口导航能力。

## 7. 禁止依赖

- 不调用概览、今日消耗或近 30 天消耗 Feature；
- 不读取其他 Feature 的内部状态；
- 不实现或展示 Brief 没有要求的重置操作；
- 不把无法取得的重置卡数据编造成零张。

## 8. 异常表现

| 场景 | 用户可见结果 |
| --- | --- |
| 周额度百分比无法取得 | 进度条和百分比位置显示“无法获取” |
| 重置时间无法取得 | 倒计时和重置时间显示“无法获取” |
| 重置卡明细无法取得 | 数量和明细区域显示“无法获取” |
| 本轮刷新失败 | 保留最后一次成功页面 |

## 9. 静态验收

- 页面字段与 Brief 完全一致；
- 进度条和百分比使用同一份数据；
- 每张重置卡包含发放时间、到期时间和过期倒计时；
- 页面没有“使用重置”按钮；
- 缺失值和刷新失败符合公共合同；
- 没有对其他 Feature 的直接调用。

## 10. 真机验收

1. 从概览进入详情，确认首次显示本页面；
2. 核对百分比、进度条、重置时间和重置卡数据；
3. 验证多张重置卡可以完整显示或按 design 规定浏览；
4. 制造单字段无法取得状态，确认显示“无法获取”；
5. 中断刷新，确认保留最后成功页面；
6. 左右旋转和按压，确认应用入口按公共导航合同组合页面。
