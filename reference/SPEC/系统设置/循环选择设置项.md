# Feature：循环选择系统设置项

| 项目 | 当前值 |
| --- | --- |
| 规范状态 | 已定稿 |
| 验证状态 | 未实现 |
| 当前交付阶段 | 固件功能 SPEC |

本项目采用 FCMA 架构，详细内容见 [`Architecture.md`](../../Architecture.md)。公共合同和需求
归属见 [`SPEC.md`](../../SPEC.md)。

## 1. 用户目标

AP01 用户可以在系统设置菜单中持续向任一方向旋转旋钮，不需要反向旋转就能从列表末端回到
开头，或从开头回到末端。

## 2. 前端入口与显示

- 前端入口是 AP01 系统设置菜单和物理旋钮；
- 当前选中项继续使用原厂选中效果；
- 循环发生后，新选中项必须立即显示为当前选中项；
- 本 Feature 不新增独立按钮、页面或提示框；
- 除列表边界行为外，原厂设置项名称、顺序和确认操作保持不变。

## 3. 用户操作与结果

- 用户向左旋转一格，选择前一个设置项；
- 当前位于顶部时继续向左旋转，跳到菜单底部；
- 用户向右旋转一格，选择后一个设置项；
- 当前位于底部时继续向右旋转，跳到菜单顶部；
- 连续旋转多格时，每个有效旋钮事件只移动一个设置项并持续循环；
- 按下并松开旋钮时，继续执行当前设置项原有的进入或确认行为。

## 4. 设备端表现

- 本 Feature 只处理系统设置菜单的选中位置；
- 输入是当前有效设置项列表、当前选中位置和旋转方向；
- 输出是新的有效选中位置；
- 设置项数量为一时，向任一方向旋转仍保持该项选中；
- 没有有效设置项时不产生越界位置；
- 菜单内容变化后，循环范围以当次实际有效列表为准；
- 本 Feature 不修改设置项自身的业务规则。

## 5. 独立状态与公开结果

本 Feature 只拥有当前设置菜单选中位置，不拥有任何设置项的业务状态。公开结果是一次旋钮
事件处理后的有效选中位置。

## 6. 公共能力依赖

- 原厂旋钮事件输入能力；
- 系统设置有效列表能力；
- 当前选中效果显示能力。

循环索引计算可以作为无业务逻辑的公共能力复用，但“只在系统设置菜单启用”的业务规则属于
本 Feature。

## 7. 禁止依赖

- 不调用“开关原厂一级页面”Feature；
- 不调用 AGENTS 看板 Feature；
- 不读取或修改具体设置项的内部状态；
- 不改变一级页面轮换行为；
- 不把旋钮按压改造成新的确认规则；
- 不把一个方向的循环实现依赖另一个方向的处理结果。

## 8. 异常表现

| 场景 | 用户可见结果 |
| --- | --- |
| 设置列表只有一项 | 旋转后仍选中该项 |
| 设置列表临时变化 | 当前选择校正到新的有效列表范围 |
| 连续快速旋转 | 按有效事件顺序逐项循环，不产生无效位置 |
| 输入事件无法识别 | 保持当前有效选择，不误触发设置项 |

## 9. 静态验收

- 顶部左旋会选择底部；
- 底部右旋会选择顶部；
- 中间位置左右旋各移动一项；
- 单项列表保持有效；
- 空列表不产生越界；
- 按压行为没有被本 Feature 改写；
- 没有对其他 Feature 的直接调用。

## 10. 真机验收

1. 从任意中间设置项连续左旋，确认跨过顶部后从底部继续；
2. 从任意中间设置项连续右旋，确认跨过底部后从顶部继续；
3. 快速连续左右旋转，确认每个有效事件只移动一项；
4. 在循环后的选中项按下并松开，确认原厂进入或确认行为正常；
5. 验证设置保存、一级页面轮换和原厂其他旋钮交互没有异常。

旋钮物理动作与原厂事件证据见
[`AP01 物理旋钮原厂功能映射表`](../../../knowledge/AP01-物理旋钮交互设计/AP01-物理旋钮原厂功能映射表.md)。
