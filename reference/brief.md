# 酷态科 10 号电能基站 AP01 第三方固件制作与刷机工具

本文档只记录开发者的开发需求草稿，整理后用于完善SPEC系列文档。

SPEC用于完善design系列文档。SEPC规定了功能的前后端表现，design规定了技术上如何实现SPEC，直接决定代码怎么写。

## 1. 项目目标

开发酷态科 10 号电能基站 AP01 屏幕的第三方固件制作和刷机工具。

本项目不仅供个人使用，还要能够分享给其他用户，让零基础用户便捷地使用。项目、固件等发布内容不得泄露 Codex 卡密、米家登录态、AP01 设备信息、米家账号信息等本项目开发者的敏感内容。

项目优先在本机 macOS 上跑通，同时为 Windows 通用做好准备，避免开发 Windows 版本时大量推倒重写。技术栈优先考虑跨平台的，而非原生开发。

WIN、macOS平台的用户，需要刷机时，只需通过 Chrome访问 WebUI刷机工具。

## 2. MVP

本项目的 MVP（最小可用版本）是：

1. 下载并通读小米云提供的 AP01 官方最新固件，据此了解官方如何制作固件，分别沉淀固件制作规范、刷机安全文档（防止变砖、变砖可救），这两类文档，必须包含工作流，而不只是注意事项；
2. 基于官方最新固件`ap01-1.0.2_0031.bin`，制作优化版固件`ap01-1.0.2_0031-opt.bin`；
   完整优化版完成前，先制作只包含系统设置菜单首尾循环的阶段固件`opt-setting.bin`，用于
   恢复门禁通过后的独立真机验证；
3. 使用优化版固件完成一次刷机；
4. 固化文档。维护固件制作规范、刷机安全文档；
5. 固化为 Windows 和 macOS 通用、零基础用户可以操作的 AP01 WebUI 刷机工具；
6. 其他用户在 WebUI 中简单操作即可完成刷机。

优化版固件`ap01-1.0.2_0031-opt.bin`只完成下列开发需求，不全面重写原厂固件。

## 3. 优化版固件开发需求

### 3.1 支持隐藏原厂一级页面

在系统设置菜单内新增“开关一级页面”选项，通过复选操作决定是否显示日历、天气、萌宠等
原厂一级页面。

### 3.2 新增 AGENTS 看板一级页面

新增一个名为“AGENTS 看板”的第三方一级页面，展示和刷新 Codex 使用信息。

服务端提供 Codex 使用数据并生成图片，AP01 每 5 分钟取得一次数据或图片到RAM并显示。图片优先使用AP01支持的且体积最小的格式，非必要，无需生成GIF。

断网或服务端不可达时，AP01 显示最后一次成功取得的数据，不在屏幕上报错。

服务端支持：

- Windows 电脑；
- macOS 电脑；
- Linux NAS；
- Linux 云服务器。

服务端在系统重启后自动运行。首次刷机后，AP01 可以按顺序尝试多个服务端；当前服务端不可达时，自动尝试下一个服务端。

所有需要的图片等视觉元素，首次由 Codex 自动打开网页端 GPT，调用 image2 生成效果图。效果图审阅通过后，只删除实时变化的数据文字，保留标题和视觉底图，由服务端把实时数放入底图的文字标题槽位内，与底图A合成新图B，屏幕端取的图是B，不是A。

brief提供的几个附件图片，只是数据参考图。只用于Codex更好地决定同名数据的前端展示字段，brief未提及但参考图中出现的数据，不必在服务端获取或前端显示。

四张看板页面中的数据不显示小数点。Token 消耗必须根据数值自动选择易读单位，并保证千亿
以下的数值可以完整放入预留位置且不会造成其他内容错位。

表示剩余额度、命中率等“数值越高越好”的比例指示，必须符合低值警告、高值良好的直觉；
具体色彩方向只见看板效果图评审文档。

#### 3.2.1 一级页面：概览

概览显示三个区块：

- 圆环：本周剩余额度；
- 普通数值：今日消耗、近 30 天消耗；
- 曲线：近 7 天消耗。

圆环只用于本周剩余额度百分比。今日消耗和近 30 天消耗没有百分比总量，不使用圆环。

#### 3.2.2 二级页面

二级页面共三个：

1. 周剩余额度详情
   - 本周剩余：进度条和百分比；
   - 下次重置：倒计时和重置时间；
   - 可用重置次数（重置卡张数）；
   - 每张重置详情：过期倒计时、发放时间和到期时间。
2. 今日消耗详情
   - 总消耗 Token（模型处理文字时计算用量的单位）；
   - 请求数；
   - 总成本；
   - 输入、输出和缓存命中。
3. 近 30 天消耗详情
   - 近 30 天累计消耗；
   - 最长任务时长；
   - 活动洞察；
   - 常用插件。
   - 活动洞察和常用插件各使用一个能表达本组含义的组图标；数据行不重复绘制图标或圆环。
   - 两组数据行的字段名、数值和单位使用同一种文字颜色，不用颜色区分具体数值。

#### 3.2.3 物理旋钮交互

上述一级页面和二级页面支持原厂级物理旋钮交互。原厂交互见
[`AP01 原厂各页面物理旋钮交互实现`](../knowledge/AP01-官方固件分析/原厂各页面物理旋钮交互实现.md)。

- 在 AGENTS 看板一级页面按下并松开旋钮，进入二级页面；
- 第一次进入二级页面时显示“周剩余额度详情”；
- 在二级页面左右旋转，循环切换三个详情页；
- 在二级页面按下并松开旋钮，返回 AGENTS 看板一级页面。

### 3.3 优化系统设置页的旋钮交互

原厂系统设置菜单左旋只能到顶部，右旋只能到底部。优化后，左右旋都能循环选择菜单项：

- 左旋到顶部后继续左旋，跳到菜单底部并继续向上选择；
- 右旋到底部后继续右旋，跳到菜单顶部并继续向下选择。
