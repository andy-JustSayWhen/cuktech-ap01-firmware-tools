# AGENTS 看板真实数据图设计核验

## 结论

最终状态：通过。

核验输入为
[`效果图-真实图-四页对照.png`](效果图-真实图-四页对照.png)，每组左右两图均保持
320×240 相同画布；左侧是已确认效果图，右侧是本机真实数据图。

## 对照结果

| 检查面 | 结果 | 证据 |
| --- | --- | --- |
| 布局 | 通过 | 四页内容顺序、主次关系、分区与效果图一致；没有新增卡片网格或页面外框 |
| 字体 | 通过 | 统一使用 MiSans，并按效果图评审第 2 节落实四级字重；主数值、单位、标题和数据行层级清楚，没有裁切或重叠 |
| 数值 | 通过 | 四页不显示小数点；Token 数值与单位分开；四位数、万和亿单位均未挤压相邻字段 |
| 颜色 | 通过 | 33% 剩余额度显示红橙色，96% 命中率末端显示绿色；绝对 Token 数值没有圆环 |
| 图标 | 通过 | 活动洞察使用折线活动图标，常用插件使用拼图片图标；两者不再使用圆环，数据行不重复放图标 |
| 内容 | 通过 | 周额度、两张重置卡、今日新增输入/输出/缓存、六项活动统计与五项插件均来自指定真实来源 |
| 固定画布 | 通过 | 四张成品均为 320×240、RGB（不带透明通道的彩色图片） |

## 不适用项

这些页面是 AP01 固定画布的服务端光栅图，不包含鼠标、键盘、触控、悬停、焦点、响应式宽度
或动效，因此网页交互与多视口检查不适用。PNG 在真机固件中的加载仍属于后续设备验证，不计入
本次设计核验结论。
